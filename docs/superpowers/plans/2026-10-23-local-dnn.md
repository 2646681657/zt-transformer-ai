# Local DNN Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement task-by-task, with independent backend implementation and final read-only review.

**Goal:** Real local CPU training, validation, model artifacts and independent preview, never optimizer integration.
**Architecture:** Frozen validated JSON bundle -> Python CLI -> isolated job/report/model; Qt owns QProcess lifecycle and user presentation.
**Tech Stack:** Qt6/C++17; isolated Python3.12 + PyTorch CPU + NumPy.
**Spec:** docs/superpowers/specs/2026-10-23-local-dnn-design.md

## Global Constraints

- Preserve dirty worktree, no engine/optimizer changes; no test data in user stores; no production eligibility.
- Model/test results must be actual runs; missing dependencies or insufficient groups are failures, not success.
- Backend CLI: `trainer.py probe`; `trainer.py train --bundle PATH --output DIR --epochs N --cancel-file PATH [--test-only]`; `trainer.py predict --model PATH --sample PATH`.
- JSONL stdout events: `{"event":"progress","percent":n,"message":"..."}`; completion is exit0 plus complete `report.json`/`model.json`, not a progress line. predict returns `{"predictions":{"metricKey":number...}}`; error exit nonzero; cancelled exit2. Model root `format=ZTBLD-ResidualModel`, `version=1`, `status=experimental`, `productionEligible=false`, `testOnly=bool`.

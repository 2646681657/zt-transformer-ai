# 粗搜＋一轮细搜实施计划

> 执行技能：executing-plans。用户已批准本批设计；不新增或运行测试程序，使用 Release 编译、静态审查和人工验收。

## 目标与边界

保留默认单轮网格，新增显式可选的两阶段模式。粗搜仍遍历原网格；取材料成本最低的三个可行方案（不足三个取实际数量）作为细搜中心。连续尺寸在中心左右各一档，步长为原步长的一半；匝数、层数保持整数一档；圆线保持冻结表内相邻一档。所有邻域裁剪到原始搜索边界，固定变量不变。完整调用现有电磁引擎及原订单约束，不改变公式、不放宽标准、不推断其他铁芯形状。

## 实施步骤

1. 设置中加入模式和保守总预算（最多100000组合）；整数坐标表示半步网格，避免浮点键去重。两轮与不同中心的重复组合只计算一次。
2. 后台完成粗搜后生成唯一细搜列表。没有粗搜可行方案、人工停止或没有新组合时明确记录原因；原最佳方案保留。暂停、停止、冻结输入继续有效。
3. 循环参数界面加入模式下拉，保存选择；进度标明粗搜/细搜。统计报告分轮计划、引擎调用、可行/失败/约束剔除、缓存去重、粗搜成本和最终改善。总量与分轮量一致，人工停止结果注明未完成。
4. Release 编译（BUILD_TESTING=OFF），只读代码审查；修正重要问题。制作独立预览程序并备份桌面快捷方式，保留旧程序。提交本地分支，等待验收后再上传及PR。

## 人工验收重点

- 单轮模式保留原数量及行为；两轮最佳成本不高于粗搜最佳成本（不保证严格改善）。
- 仅打开一个连续变量，观察半步新方案且不超出原边界；固定变量、订单标准不变。
- 仅整数或圆线参与时不插值、不产生重复行；可能没有新增组合。
- 无可行粗搜方案不进入细搜、不放宽标准；停止和暂停保持可用，统计实际处理量准确。
- 本批是一轮局部细化，不宣称全局最优或完整多轮迭代；不人为增加计算时间。

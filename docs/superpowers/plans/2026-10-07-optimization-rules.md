# 寻优规则第一批实施计划

> 使用 executing-plans 在当前会话逐项执行；用户已批准本批范围。

**目标：** 固定订单输入，明确四个网格变量的参与开关和边界，以内置基价材料合计选优，报告真实评估及淘汰统计。

**架构：** OptimizationSettings 共享有效范围、组合数和校验；Worker 持有运行输入快照，通过跨线程 summary 返回真实统计；主界面配置和统计入口消费同一规则。成本继续包含铁芯、导线、油和油箱，不改变引擎公式。

**技术：** C++17 / Qt 6 / MinGW。分支 codex/optimization-rules。

**约束：** 不新增或运行自动测试，不运行 GUI 自动化；仅 Release 编译和静态审查，由用户验收。保留方案弹窗。验收前不推送或创建 PR。单轮四变量网格不是自适应、多轮或多线程算法。

## 实施

- [x] 设置与约束：IOptimizer.h 增加四个默认 true 的开关、有效范围、plannedCount()、validationError(base)；范围 0..5、尺寸步长 1..50 mm，边界 D>0、直线段>=0、低压匝数>0、W12>=2。固定变量保留配置但实际范围为零。SchemeConstraints.h 记录未校核项和失败项名称，保持原过滤规则。
- [x] 执行与目标：OptimizationResult.h 提供 optimizationMaterialCost(result) 并共享于方案表和最优比较；GridOptimizer.cpp 验证后搜索，返回 planned/evaluated/accepted/invalid/constraintRejected/elapsed/reasons/skippedChecks。实际评估等于三种分类之和，停止未遍历的不计淘汰。理由计数可重叠，分类计数不可重叠。
- [x] 主界面：EnterCalcPage 循环参数增加参与勾选、实时实际上下界和组合数；冻结运行输入、设置与标准，运行时禁止修改搜索设置。新增寻优统计入口，展示目标、边界、计数、未校核项和淘汰原因。保存开关到 QSettings；默认组合数仍为135，全部固定为1。
- [x] 交付：Release 编译、diff 静态检查及只读审查，修正发现的问题；复制独立 preview exe，备份并更新桌面快捷方式，记录校验值。交付人工验收步骤，等验收通过后才上传。

## 人工验收

1. 循环参数：全部固定显示1组合；逐个参与时其余变量的上下界不变；非法下界阻止保存/启动。
2. 默认搜索135组合；已启用指标通过后按材料合计选择最低成本，统计与方案表数量一致。
3. 停止较大搜索后：实际评估<=计划，实际评估=入库+计算失败+约束剔除，剩余未评估不算剔除。
4. 指标标准值为0时列出未校核，不称全部合格；多项违反时原因计数允许大于剔除组合数。
5. 主设计订单信息不被搜索改写；方案弹窗布局保持原样；桌面入口加载新预览。

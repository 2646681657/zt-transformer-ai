# DNN自学习第一批：本地样本与接口基础

用户已确认先搭框架、真实数据后补。本批交付可操作的样本管理和训练数据交接入口，而不是已训练的模型。

- 现有自学习对比保留，增加学习样本、训练与模型页签。不更改计算、寻优、合格判定或报价公式。
- 六项指标：空载损耗W、负载损耗W、阻抗%、油顶温升K、高压温升K、低压温升K。缺失值用null；损耗/阻抗须大于0，温升允许0。禁止非有限值和字符串数字。
- 样本包含稳定样本ID、产品/试验编号（用于未来分组隔离训练验证）、来源、试验日期、完整CalcInput快照、公式版本和六项原公式结果。旧TestReport的0值存在缺失歧义，不自动转换。
- 本批范围固定油浸/箔绕/叠片硅钢/椭圆/T形轭/双绕组/多层圆筒/50Hz/75℃，完整计算成功才可建样本。输入导入必须完整、类型正确且原公式结果可重算核对。未实测样本可作为草稿保存，不能导出为训练行。
- JSON v1交换模板，提供界面填写六项可选实测值。整批导入先校验、再合并、原子落盘；同ID同内容跳过，同ID冲突拒绝，产品编号+日期重复也拒绝，避免两套方案库重复计数。损坏本地库不覆盖。
- 训练交接包包含有标签的样本、分组编号、原值/实测/残差、数据摘要SHA256、指标及单位、输入schema和公式版本。没有标签不导出，不模拟训练成功。
- 训练/模型管理首批是接口状态和元数据契约：无数据/待接入训练后端/尚无模型；未接入推理运行时，不允许启用或回退，不返回修正值。真实训练、验证门槛、模型部署在后续批次实现，不安装GPU依赖、不启动外网服务。
- 独立本地self_learning目录，QSaveFile原子写入，所有错误向用户显示；测试使用QTemporaryDir及测试模式，不读写真实用户方案/样本。

验收：缺失值往返不变、严格导入/去重/冲突回滚、无标签拦截、训练包残差正确、无模型不修正、原引擎回归及GUI初始状态。

# 本地DNN第二批（用户已批准CPU路线）

Python/PyTorch CPU独立虚拟环境，通过Qt QProcess异步调用本地脚本，读取第一批交接包。六项目标分目标训练小型两隐藏层MLP，学习实测减原公式残差。缺标签不补0；产品编号规范化后分组留出验证；输入及输出归一化仅拟合训练集；固定种子、保存最佳验证轮次与MAE/RMSE及原公式误差基线。每个目标至少5个独立有标签产品（仅是运行门槛，非上线标准），不够的目标跳过，无可训练目标则失败。

Qt训练入口选择明确的python.exe和trainer.py路径（用户本地配置，不硬编码开发目录），保存后进程启动前实际检查依赖。训练任务独立UUID目录，bundle快照由C++验证导出。STDOUT逐行JSON进度；STDERR收集有限长度错误；支持取消：创建cancel标记，后端逐轮检查，超时只终止自有训练进程。失败/取消不发布模型。不阻塞主界面，不触碰原计算和寻优。

模型/报告保存到独立本地任务目录；模型版本含时间/UUID、特征顺序、训练集统计、原公式版本、数据摘要、适用范围、独立组划分、标签数量、验证误差及权重。权重使用安全JSON张量表示，不加载任意pickle。模型状态始终experimental，禁止启用、回退、用于寻优。允许选定当前样本查看独立预测，与原值并列；特征不完整/超训练范围/结构或版本不匹配则拒绝。

测试合成数据只在测试临时目录生成；synthetic/testOnly标识贯穿模型/报告且productionEligible=false。UI不自动造数据混入用户样本库。用户训练默认真实来源，仍为待工程验证，不能把完成训练称为上线或已达精度。

本批不提供自动增量更新、服务器部署、GPU安装、生产模型发布、跨结构泛化或寻优联动。Python依赖仅装项目build/self-learning-runtime。所有旧工作保留，验收前不提交/推送。

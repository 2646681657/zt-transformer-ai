# 散热面积与温升有效性校验：人工验收

## 程序改动

- 引擎 `calcThermal` 在除法前检查油箱总散热面积 O48、高压散热面积 AC47、低压散热面积 AK47：按原公式取整后的值必须有限且大于0。不使用微小替代分母，不自动补油道，不修改公式或取整。
- 油箱、高压、低压热负荷在进入0.8次幂前必须有限且非负。高压层间间隙的 W12-1 分母及间隙结果增加引擎保护；界面已有 W12 至少为2的规则保持不变。
- 检查油面/油顶层、两侧表面/对油/总绕组温升必须有限且非负。AC51/AC52/AK50 原始修正只检查有限性，保留负值及原有分支，不把负修正直接判为失败。
- 失败时通过既有设计输入计算提示/状态栏指出具体项目和单元格；终止后续成本计算，失败候选仍由既有寻优流程排除。这是数值有效性检查，不是新增温升限值或散热结构合格判定。
- 不改变方案文件结构、布局提示、支持的形状与线圈类型，不新增界面参数。

## 请检验的位置

1. 关闭旧程序，从桌面快捷方式重启。用上一版可成功计算的正常方案，检查损耗、阻抗、散热面积、油顶层温升、两侧绕组温升及成本与上一版一致。正常超温但有限的方案仍按既有性能限值筛选，不应被本批数值检查直接禁算。
2. 建议用输入副本核验零低压散热面积：产品保持10kV，专业模式“八 绕组工艺”将低压5组油道宽和高全部改为0；“六 主空道”主空道宽改2.5mm、纸板厚保持1mm，实际主空道3.5mm。原 AK47 公式此时为0，应明确提示“低压绕组散热面积 AK47”无效，不应成功输出无穷温升或正常成本。若前面的其他校验先报错，先恢复其它参数，保留此组合再核验。
3. 同一副本将主空道宽恢复3.5mm、纸板厚1mm，实际主空道4.5mm。虽然低压油道全部停用，但 AK47 的主空道表面项可参与，应不再仅因油道全部为0报错；能否满足损耗/温升等限值仍由原规则决定。
4. 恢复原低压油道及主空道值，重新计算，确认失败提示不影响恢复后的正常计算。方案弹窗重算与主输入页采用相同引擎保护；寻优不会把无效温升候选当成有效方案。
5. 以前确认过负 AC52/AK50 修正的有效方案继续核验：AC52 原始负修正仍在原结果项中显示；AK50 保留既有计算行为，并未新增原始值显示。实际合成温升仍按原有规则计算，本批不把“修正项为负”等同于散热无效。

# 启动默认方案库

设计输入侧栏“从方案库中选择”下新增“保存为默认参数”和“默认方案选择”。默认方案单独存放于应用数据目录下schemes/startup_schemes.json，不混入我的方案库、记忆库或寻优设置。

预置名称：

- 内置基准方案｜SB20-630kVA：从原启动默认参数完整采集，保留原始AN3=0.7及自动空载电流来源。
- 复核第一组｜SB22-400kVA：已复核400kVA原计算单参数。
- 复核第三组｜SB20-630kVA：已复核第三组630kVA原计算单参数。

保存时核对当前输入，保存完整CalcInput、性能标准及来源、材料、工艺和结构配置；名称可编辑，可勾选“设为启动默认方案”。自定义同名方案经确认可更新。选择窗口标记当前“启动默认”，显示完整型号和电压，“设为默认并加载”立即回显并持久化，下次启动恢复。普通界面编辑不会自动改写快照。

内置三项禁止覆盖或删除，自定义项可删除；删除当前启动项时将下次启动项恢复为内置基准。原始基准保留已有正常/专业显示偏好，自定义方案恢复保存时模式及结构选型。变压器类型对话框按当前默认选型预选，避免确认时将其覆盖为初始选型。

持久化采用单个QSaveFile原子提交。库损坏、格式不匹配、默认项丢失或结构信息不完整时提示并回退内置基准，原文件保留。写入失败不应用选择，不改动原库。启动加载不自动寻优，1000万预算及循环参数仍走独立原有设置。

- 界面自动操作验证三项预置、选择第一组并立即加载、保存并设为默认、重新构建设计页还原完整参数、切换第三组并再次重启还原。数值、手工指标来源和工艺参数保持一致，旧手工指标只规范化查表标识。

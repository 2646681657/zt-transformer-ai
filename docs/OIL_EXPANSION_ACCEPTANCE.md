# 油膨缩能力独立参考校核：人工验收

## 原表依据及边界

只读核对 SB20-M-630-10计算单.xlsm 的“计算单”页，不重算、不执行宏、不修改工作簿：

- N53：`ROUND(C24 * 0.0007 * 50, 2)`，膨胀需求，kg。
- N54：`ROUND(0.06 * S46 / 100 * S45 / 100 * 2 * (S48 + S49) * 0.9 * S51, 2)`，膨缩能力，kg。保留原表两次 `/100`。
- P54：仅 N54 严格大于 N53 才合格，两者取整后相等仍不合格。
- 原表仅在波纹油箱分支提供这些结果。程序仍沿用现有支持范围，不新增片散油箱等算法。

固定参考温差为 50K，膨胀系数为 0.0007，不改成实际温升或环境温度。原表缓存需求18.8、能力21.94仅记录原工作簿状态，不是程序所有输入的验收目标。

使用程序已有总油重、波纹深/高及长短边数量；原表数量公式使用固定节距41mm，程序继续使用原有可编辑节距，不改已有数量计算。Kp沿用现有波纹系数表的阶梯查表规则，不改为插值。目前内置波纹深数据闭区间为80～330mm；范围外、缺少有效Kp或校核输入无效时显示“需人工核对”，不把默认0当成有效结果。外部引用表未随本工作簿提供，本批使用程序现有数据表，因此明确标为计算单参考，不宣称完成结构认证。

## 程序改动位置

- 计算结果新增独立油膨缩数据，在原有油重计算结束后生成；不更改电磁、损耗、重量、温升公式。
- 结果面板新增“油膨缩校核”页，显示参考状态、需求、能力、余量及采用参数。原有五个结果页保持顺序。
- 打印输出及结果文本导出包含该参考校核。无有效依据时不给出伪数值。
- 不新增输入参数，不作为寻优合格过滤条件；参考不合格不等于整体计算失败，温升合格也不代表膨缩合格。

## 人工验收位置

1. 关闭旧程序，从桌面快捷方式重新启动。使用原来可成功计算的输入重新计算，在结果“油膨缩校核”页核对需求、能力和余量。需求应等于总油重×0.0007×50取两位小数；能力按上述N54公式取两位小数。能力严格大于需求显示“合格（参考）”，否则“不合格（参考）”。
2. 同一输入与上一版比较损耗、阻抗、重量及温升，应不因新增校核而改变。参考温差仍为50K，与“温升”结果分开。
3. 专业模式油箱波纹参数中调整波纹高/深，重新计算，核对新参考结果。修改这些输入也会通过已有公式影响油重及散热，属于原有联动，不要求修改输入后旧结果仍相同。
4. 在其余输入仍可成功计算的前提下，波纹深改为70或340mm，重新计算：本校核应显示“需人工核对”及Kp范围说明，而不是有效的合格/不合格或零值。原有其他适用范围及曲线保护仍可能独立阻止计算。
5. 打开打印预览、导出结果文本，核对校核状态和N53/N54数值与当前结果一致。修改输入后先重新计算，打印的是计算结果快照。
6. 参考不合格或需人工核对不得作为本批新增的寻优排除条件；既有性能约束仍照常筛选。

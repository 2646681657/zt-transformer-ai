## 范围与结论

直接读取 `SB20-M-630-10计算单.xlsm` 的“计算单”“线圈型式”“Sheet1”“成本测算”公式和已保存的缓存值，追踪到界面、CalcInput、引擎、方案约束和报价模块。

这是一轮静态对照，不是全公式数值认证。没有执行 Excel 重算、宏、引擎自检或测试程序，没有修改 Excel、程序公式、桌面快捷方式。本报告中的“确定”指源码或公式关系明确，不代表已经完成界面复现及数值验收。

原工作簿引用外部 `D:\计算单模型\计算用数据表（椭圆）.xls`。本轮没有打开该外部文件重新计算；已有缓存只能作为历史样本，不能证明输入改变后的结果。项目中的“电磁计算单公式导出.md”来自 C++ 引擎，不能充当独立正确性依据。

结论：已有基础电量、椭圆几何、铁芯叠积、绕组、损耗、阻抗、波纹油箱温升和重量成本计算链；主要问题集中在输入传递、算法适用范围及部分绕组/温升分支。不能笼统地说引擎全部错误，也不能把默认样本接近当成所有选型都正确。

## 第一批：输入一致性与适用范围

### A1. 方案参数弹窗没有完整沿用主页面的输入同步链（确定，高优先级）

位置：`qt-app/src/gui/pages/EnterCalcPage.cpp`，`onSchemeSelected` 中约 1596–1677 行；`ParamTableWidget.cpp` 的 `getParams` / `saveToInput`。

- 弹窗用 `m_params` 与 `original.input` 初始化。型号额定值来自前者，而绕组设计变量来自后者，导入不同容量/电压的方案时存在显示与实际输入分离风险。
- 弹窗 `recalc` 只调用 `saveToInput`，没有像主页面一样把 `getParams()` 的容量、高低压电压同步到 CalcInput。即使点击“计算”，编辑型号中的额定值也可能不参与本次重算。
- `dirty` 只监听 `QTableWidget::itemChanged`。型号 QLineEdit、材料 QComboBox、调压 SpinBox 是独立控件，不保证触发这个信号；硅钢片变化可能通过片厚单元格间接触发，但不应依赖这种副作用。“确认”仅在 dirty 时重算，因此有漏保存风险。
- 弹窗没有沿用主页面的联结组别与牌号预检；不支持的接线可能保留旧布尔值继续算。

建议：收集输入采用一致的显式入口；弹窗初始化从该方案的额定值与接线回显；明确跟踪控件修改或确认时统一收集并重算。性能约束是否允许弹窗修改，也应明确，不能显示可编辑却不使用。

人工验收：方案选择 → 行内“选择” → 分别修改容量、电压、材料、分接；比较“直接确认”与“先计算再确认”；保存并重新打开方案确认输入。非法接线不得静默沿用旧接线。

### A2. 型号不完整/非法时仍可能使用上一次有效数值（确定）

位置：`ParamTableWidget.cpp:252`，`parseCompositeModel`；`getParams` 读取缓存字段。主页面进入计算仅检查形状、接线、牌号。

容量/电压解析失败会保留旧数值；低压仅回车提交。比如显示 `0,4` 或 `abc` 并回车，解析失败后旧低压仍存在。删除逗号兼容不等于阻止非法型号进入计算。未按回车的低压也可能显示新值、实际仍用旧值。

建议：保留用户要求的分隔符增量保存交互，但在计算/确认边界校验整条型号完整性和提交状态。非法输入给出具体提示，不自动转换逗号，也不静默计算旧值。

人工验收：有效 `SB20-M-630/10-0.4`；未完成低压；非法 `0,4`；负数和非数字。明确哪些状态可计算、哪些被阻止。

### A3. 标准损耗联动缺少适用条件与无匹配处理（确定）

位置：`qt-app/src/core/ModelStdTable.h:60`、`ParamTableWidget.cpp:296`。

- 表的源码声明仅对应 10kV 油浸三相双绕组叠铁芯系列，但界面查表仅传系列和容量，没有高压电压、铁芯类型等适用条件。
- `table(series)` 对除 SB22-M/SB13-M 之外的任何系列都回退到 SB20 表。未知系列、非晶系列等不能由这一回退推断为支持。
- 非标准容量查不到时直接返回，已有标准值保留且缺少无匹配提示。
- 初始显示的默认“标准值”530/5210 接近历史设计结果，而原表 M9/L9 是 510/4960；初始化未统一查表，可能第一次编辑型号后才切换标准值。
- 空载电流标准值未做容量联动。原计算单 O9 通过容量查外部表后减 0.34；项目虽有 `noLoadCurrentStd()` 数据查询，本次检索未发现业务调用。不能未经确认直接复制 -0.34 到新联动。
- 阻抗标准值保留手工值是已有明确决策；不应在此轮自动改为 4.5%。

建议：识别已收录系列，检查当前标准表适用范围；无匹配时明确进入非标/手填状态并提示旧值来源，避免强行套用。初始化、型号编辑、接线变化采用一致口径。这里只核查程序取表逻辑，不作国标现行符合性认证。

人工验收：SB20-M/SB22-M/SB13-M；未知系列；非标准容量；10kV 改成其他高压等级；切换铁芯类型；确认原有阻抗设置不被意外覆盖。

### A4. 结构选项与实际算法没有一一对应（确定）

位置：`OptimizeCalcPage.cpp:610`、`StructureConfig.h`、`GridOptimizer.cpp:161`。

绕组方式、铁芯类型、高压线圈结构写入 StructureConfig，但 GridOptimizer::start 不使用该参数；CalcInput 也没有铁芯类型和双分裂拓扑。高压线圈 `hvCoilFormIdx` 在引擎中被使用，却没有从 Ribbon 的 `hvCoilStructure` 同步。选择“两段圆筒式”不能据此认定已换用对应算法。

椭圆形截面限制已经存在，但“椭圆形”不代表所有铁芯材料、铁芯结构和绕组形式均已支持。

建议：先建立并显示当前已验证的支持组合，不支持的组合阻止计算或明确仅为配置展示；双分裂、卷铁芯、非晶结构不能继续无提示套用原链路。高压两段结构接入前先补齐 B3 的散热分支。

人工验收：切换双绕组/双分裂、多层/两段线圈、叠铁芯/卷铁芯/非晶，确认有效状态与提示一致。圆形、长圆形、半椭圆和类椭圆继续保持禁算，不推测算法。

## 第二批：明确的公式分支差异

### B1. 高压叠绕根数没有完整计入导体总截面（确定）

Excel：计算单 Y15=`AB13*AB14`，AA15=`U15*Y15`；X16、X19、W21 和 AA45 都直接或间接使用 AA15。

程序：`ElectromagneticEngine.cpp:368`、`:693`、`:712` 仅乘 `hvParallelCount`，没有乘 `hvStackCount`；AA45 也使用单根截面。`hvStackCount` 主要只改变 AA25 的轴向尺寸分支。

因此 AB14=1 时差异隐蔽，改为 2 时电密、电阻损耗、重量和相关成本/温升不能认为与原表一致。

建议：明确单根与总有效截面，按原表统一用于电密、电阻、重量及附加损耗。并绕变化时 AA45 的总截面口径也一并检查。

人工验收：AB13/AB14 分别取 1、2，按 Excel X16/X19/W21/AA45 对照，不能只看成本变化。

### B2. 圆导线分支未实现（确定）

Excel：X13=Z13 时 U15 使用圆面积、X14 使用圆线规格查表、Z21 使用圆线绝缘增重表。

程序：截面积始终是矩形扣圆角，绝缘尺寸始终裸尺寸加增厚，导线增重仍走扁线公式；部分成本与负载损耗却已经根据宽=厚切换分支。`wireByBareWidth()` 已有数据接口但未发现引擎调用。

建议：先明确并限制首版高压扁导线范围；后续验证原圆线表完整性后再实现，不把宽厚相等当作已完整支持圆线。

人工验收：高压裸宽=裸厚时，应明确提示不支持，或在圆线算法交付后逐项对照 U15/X14/Z21。

### B3. 高压温升分支与原表有明确差异（确定）

位置：`ElectromagneticEngine.cpp:904`、`:940`、`:954`。

- 原 AC47 对高压 >12kV 添加内表面散热项，并在 AC9=2 时使用 `AC30-AA29`；程序只用 AC30，缺少这些分支。
- 原 AC51 在绝缘间隙 >0.64 时增加修正项；程序没有计算 AC51。
- 原 AC52 将主空道第二油道 AG43 是否存在纳入计数；程序固定写成 0，在 >12kV 时有差异。
- 原 Y53 对负 AC52 不相加，而程序始终 `ac49+ac52`，可能低估某些输入组合的温升。

建议：逐项按 AC47、AC51、AC52、Y53 恢复分支，并保留 Excel 的分段取整。先处理这一块，才允许宣称两段线圈和更高电压等级的温升已支持。

人工验收：10kV 原样本；>12kV；间隙 <=0.64 与 >0.64；油道变化使 AC52 变负；两段线圈在确认映射后单独验收。

### B4. 算法支持边界尚未明确（确定存在固定假设，规则需确认）

- 频率显示/导入保存在 TransformerParams，未传 CalcInput；磁密使用 450 常数、附加损耗使用 50 常数，不能宣称支持任意频率。
- 计算折算温度可编辑并保存，但电阻使用固定 75℃系数，没有温度折算输入；环境温度和海拔也未发现影响主电磁/温升链。
- 原表有片散油箱分支，当前引擎是波纹油箱链；不能因为有油箱尺寸输出就声称支持片散或干式温升。
- 硅钢曲线在磁密超出数据边界时返回端点值，缺少超范围提示，可能掩盖不适用的寻优点。

建议：第一阶段明确固定 50Hz、75℃及已验证结构范围，不让不支持的参数显示为已生效；要扩展时另行确认公式与有效范围。曲线越界与查表失配应给出明确状态。

## 计算单自身需要确认的地方

这些问题不是直接修改程序的依据，必须与设计人员确认。

1. 分接 L3/N3 可输入，但 V5/AA5 是固定乘 1.05/0.95，未引用它们。当前程序级数×百分比是用户明确要求的改进，不应倒退为固定 ±5%。
2. Sheet1 I26=0.48488、O26=0.466735 为手填/常量，标签却写23RK085，计算单 P14 选择18SQGD065。程序按实际牌号曲线插值，需确认哪一套数据是正式依据。
3. 低压附加损耗 AJ45 是 `=0`，温升 AK48 却引用空白 AS45；程序让同一个 lvExtraLoss 同时参与两处。非零输入的工艺定义需要确认。
4. 计算单 D52 只引用前三组油道，而其他几何/散热公式使用五组；不能仅按说明文本改公式，要确认是否为特定工艺。
5. W12 虽标“每层匝数”，却被 W9/W10/W11 和 Y9 当作层数使用。程序字段 hvTurnsPerLayer 也沿用这个名称。需要确认命名后统一界面/输出，不能仅凭名称重写公式。

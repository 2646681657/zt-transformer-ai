# 寻优统计报告导出人工验收

分支 `codex/optimization-report-export`，基于已合并PR57的dev。只增加已有统计文字的保存入口，不改变寻优、公式、性能约束、价格或方案弹窗。

## 程序改动位置

计算主页 → 优化计算 → 寻优统计 → 窗口底部“导出报告…”。

- 本轮结束或停止后可导出；运行中或尚无统计时沿用原提示，不伪造报告。
- 保存为UTF-8纯文本，默认文件名“寻优报告_日期-时间.txt”，日期时间仅为建议文件名的保存时刻，不声称本轮启动时刻。保存路径、文件名可自行选择，缺省扩展名为txt，已有目标文件由保存对话框确认覆盖。
- 文件正文直接采用统计窗口打开时的同一份文字快照，不补实时设计值，不从当前选中方案重新计算。冻结订单、标准、价格、范围、分轮数量、停止原因、失败/淘汰原因、触边及裕量等原窗口已有内容全部保留。
- 取消选择路径不创建文件；导出按钮不关闭统计窗口。只有写入全部内容且提交成功才报告成功。
- 原子保存，不启用直接写入回退；打开、写入、最终保存失败均明确报错。失败时不直接截断已有报告，旧目标内容保留。
- 文件仅供留档或人工比较，不包含恢复任务协议，不支持载入重放计算。不宣称覆盖尚未评估候选、全局最优或制造安全保证。

## 建议人工验收

1. 关闭旧程序，从桌面重新打开，完成一次寻优，打开统计，底部应出现“导出报告…”，关闭按钮仍正常。
2. 导出到自己选择的目录，用记事本打开，核对中文、百分号、±等文字无乱码；内容应与统计窗口一致，包含本轮价格、标准、搜索范围、真实数量及前两批触边和裕量说明。
3. 点击导出后取消，不应出现新文件，不应关闭统计窗口或改变方案。可以再次点击导出，默认建议名含保存时刻，仍可改名。
4. 给同一报告路径导出两次，已有文件应要求确认覆盖；取消覆盖保留旧文件。只选择用于验收的报告文件，不覆盖其他重要数据。
5. 单轮、多轮、人工停止以及无可行候选场景，导出的结论和未评估/未校核说明应与窗口一致，不能把暂停、提前停止或缺指标改写为全部完成/全部合格。
6. 后来修改设计、价格或标准但不重新寻优，旧统计及导出正文应仍对应旧轮次。重新寻优后，新统计导出新轮次，不补入旧候选。
7. 如自然遇到不可写目录或文件被占用，检查是否明确报错、不显示成功，原有报告不被截断；无需故意破坏数据或更改系统权限来验收。

不创建或运行测试程序、自动测试、GUI自动化，不启动程序代验收。仅Release编译与独立只读静态审查。验收前仅本地提交，不上传或创建PR；独立预览、旧程序和旧快捷方式备份保留。

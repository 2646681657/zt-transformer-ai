# 绕组匝数分布与性能偏差验收（2026-10-14）

上一批原表布局、字段去重和折叠区已通过用户验收，PR61已合并。本批位于 `codex/sheet-turns-performance`，待用户验收后提交。

## 改动位置及口径

| 原计算单位置 | 新显示内容 | 数据来源 |
| --- | --- | --- |
| AA9 | 第一段匝数 | W9段层数×Y9每层匝数 |
| AA10 | 中间段匝数 | W10段层数×Y10每层匝数 |
| Y11、AA11 | 末层剩余匝数及末段合计 | 最大分接匝数减前两段分配，W11仍使用现有固定1层 |
| AK10 | 低压末段剩余匝数 | 实际低压匝数减现有AF10:AJ10分配；停用段按当前计算口径计0 |
| H10 | 电阻损耗合计 | 已有高压和低压电阻损耗之和 |
| I10 | 附加损耗显示合计 | 已有高压附加项加当前低压附加输入；圆线仍不将此合计加入负载损耗 |
| L11、M11、O11、R11 | 负载损耗、空载损耗、空载电流、阻抗电压相对标准的百分比偏差 | 当前方案冻结的标准与已算出的实际值 |

偏差按原表 `(实际−标准)/标准×100` 计算，取两位小数。正值表示高于标准，负值表示低于标准，不能当成寻优裕量或合格结论。标准为0显示“不适用：标准值为0”，负值或非有限标准显示无效，来源未确认时显示原因，不使用默认标准替代。

数值单元格仍只读。悬停偏差可见实际值、标准及口径；末层或段层数非正时有核对提示。引擎增加的仅为弹窗明细输出与显示计算，不改变电磁公式、实际匝数、油道分支、损耗合成、筛选规则及寻优目标。明细仍只在弹窗请求时采集。

新增明细版本标志。旧快照没有本版字段时，打开弹窗自动重算；单元格预先保留，结果刷新不重建控件。折叠区继续保持原行为。

## 桌面验收

退出旧程序后，从桌面ZTBLD打开，方案选择 → 点击任一方案行“选择”。

1. 右上绕组层数区：AA9+AA10+AA11应等于最大分接匝数V8；修改W12总层数后，段层数、每层匝数和末层剩余数自动更新。检查结果单元格不能编辑。
2. 低压分段区：修改低压实际匝数AH8，AF10:AJ10和AK10应更新，总分配应等于AH8。将端部侧油道设为0时，停用段显示不适用，剩余按当前分配规则更新；全部停用时AF10为全部匝数，AK10为0。
3. 左上性能表：L11/M11/O11/R11显示百分比。改一个标准值，该指标的偏差应按公式更新，实际电磁计算结果不因仅改标准值而改变。标准设0时显示不适用，恢复正值后恢复百分比。
4. H10和I10不再显示“—”。修改低压附加损耗时，扁线分支维持原合成规则；圆线分支I10可显示合计，但L10不因此将其计入。悬停I10查看说明。
5. 检查连续编辑、折叠区展开收起、确认保存与取消不保存保持正常。

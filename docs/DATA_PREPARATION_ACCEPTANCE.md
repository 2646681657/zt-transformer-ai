# DNN第四批：数据分区、质量检查和批量填写

## 操作顺序

进入“自学习”后依次使用“学习样本 → 数据准备 → 训练与模型”。原有实测对比保留。本批不修改原公式、寻优、合格判定、报价和打印。

1. 在学习样本中选择方案、建立设计样本并保存。新产品和旧版未标用途的样本均为“待分区”，不自动训练。
2. 在数据准备页选择产品并设置“训练用 / 独立测试保留 / 暂不使用 / 待分区”。同一规范化产品编号的全部试验日期一起改变，不用重复试验凑独立产品数。给同产品新增试验继承已有用途，新产品仍待分区。
3. 数据质量检查只显示问题，不自动删除、不填0、不猜测单位或设定异常值精度门槛。固定物理上下文不一致时，应人工分开准备，不能混合训练。
4. 六项目标分别显示训练标签数、训练产品数、保留测试标签数/产品数和训练缺测数。每目标至少5个有标签训练产品仅表示可尝试训练，不是企业精度或上线门槛。
5. 导出CSV实测填写模板，用Excel/WPS打开。只用于已有完整设计样本的实测、来源、日期、用途等更新，不创建缺少设计参数的新设计。
6. 填写后另存为UTF-8 CSV，点击导入并预览核对。界面显示各列固定映射和“旧值 → 新值”。全部有效时才可确认整批保存；任何错误或并发修改均不写入整批。

## CSV列和规则

`sample_id`为样本ID；`snapshot_sha256`绑定导出时完整样本（包括设计、基线、实测和用途），不要修改。其余文本列：`product_id`、`scheme_name`、`source`、`tested_on`、`purpose`。日期格式YYYY-MM-DD。

用途代码为`unassigned`、`training`、`independent_test`、`excluded`。同产品所有记录用途必须一致，不能只改部分试验造成训练/测试混用。

六个实测列：`noLoadLoss_W`、`loadLoss_W`、`impedance_pct`、`oilTopRise_K`、`hvWindingRise_K`、`lvWindingRise_K`。单位分别为W、W、%、K、K、K；未测留空，温升允许真实的0。损耗和阻抗须大于0。小数点使用英文点，不接受公式、千位分隔或非有限值，不自动把kW换为W。

导出文本单元格统一前置一层单引号，避免Excel吞掉前导0、长编号或执行公式；导入去掉该保护层。原文字本身的单引号会多保留一层。不要改样本ID或摘要，也不要删除、改名或重复表头。

导入支持CSV引号、逗号、多行文本和UTF-8 BOM，文件最多16MiB。未知ID、过期摘要、单位表头不符、非法数值、重复ID/产品日期、用途冲突均拒绝，不跳过坏行保存其他行。

## 兼容与并发验收

- 打开旧样本不自动写文件；旧用途缺省读取为待分区，实测值保留。只有明确保存/分区/导入时更新文件，历史模型不重写。
- 训练只冻结训练用途；独立测试只冻结保留测试用途。用途不是独立性证明，历史训练/验证产品仍由现有泄漏检查拦截。
- 多窗口：另一窗口改变样本或用途后，旧窗口启动训练/独测必须拒绝缓存，先重新读取。冻结时使用与样本写入相同的锁核对本地完整快照。
- CSV预览后，另一窗口改了任何待更新样本，确认保存必须整批拒绝；未涉及的其他样本不被覆盖。
- 取消导入、放弃预览、样本库损坏或锁被占用时，不写入数据。

## 必须区分的四类状态

### 已接入显示或记录

- 现有电气、几何、绕组、损耗、油箱、重量、温升、阻抗结果与对应说明已在原单位置或明确折叠区显示；结果显示已接入不代表所有选型算法已支持。
- AG12/AJ12内排尺寸、H16/M16历史记录可保存；空白表示未录入。AK12截面、AN14弦高及K19/K20是独立参考，不直接进入损耗、温升、整机判定或寻优筛选。
- 固定扣减5mm²、4mm等参考工艺依据仍需确认，不因界面已有显示就视为制造验证完成。

### 当前分支不适用或条件留空

- E27、F27、Q52、Q53在当前波纹油箱分支按原条件留空，不能据此认为片散/储油柜算法已经存在。
- U44/U45/AB45圆线分支留空；AB12合计一致留空；部分油道分段、温升修正说明按条件留空。这些不应被填成示例数值来消除空白。
- 内排两项全空为未录入，单项空为待补全；无效记录使参考不可用，不用0冒充。

### 算法或工艺口径仍待补

| 类别 | 当前限制/缺口 | 后续工作边界 |
|---|---|---|
| 联结组别 | 已支持Dyn11/Yyn0；Dd/Yd未支持 | 追踪原单相电量、匝数、损耗和标准列的条件分支，再单独迁移验收 |
| 心柱 | 已支持椭圆形；圆形/长圆形等未支持 | 从原单追踪几何、叠积、截面、磁密、重量及后续引用；不靠椭圆推测其他形状 |
| 铁轭 | 当前T形轭；同心柱未支持 | 先核对与心柱形状/分级叠厚的依赖，再确定迁移顺序 |
| 线圈结构 | 当前多层圆筒式；分段式未开放 | 追踪两段串联定义、匝层、段间距及后续温升/阻抗分支 |
| 油箱与储油柜 | 当前波纹油箱链，无独立储油柜模型 | 补齐配置/容量/重量/充油和排油依赖后，才能替换D18/C23状态 |
| 低压附加项 | AJ45固定0与AS45/程序现有输入口径未确认 | 单独核对负载损耗与热负荷两条用途，不直接把固定0覆盖现有输入 |
| 标准来源 | 内置模式仅匹配项目已有损耗表；非标手工 | 不等同完整国标认证；其他标准/指标数据的适用范围需逐项核实 |
| 项目其他结构范围 | 干式、低压线绕、卷铁芯/非晶、双分裂等受现有适用范围限制；50Hz/75℃限定 | 这些是项目级后续能力，不宣称全部都能从当前单份计算单直接恢复 |

# SW 参数化出图

## 功能说明

主界面“优化设计 → SW参数化出图”用于根据 SOLIDWORKS 模型中的尺寸参数，
自动生成新的参数化模型、工程图和 PDF。

当前版本支持：

- `.SLDPRT` 零件模板和 `.SLDASM` 装配体模板
- `.DRWDOT` 工程图模板
- 按 SOLIDWORKS 完整尺寸名批量写入毫米参数
- 自动重建模型
- 自动生成前视、俯视、右视和等轴测视图
- 尝试导入模型中标记的尺寸
- 输出参数化模型、`.SLDDRW` 工程图及可选 PDF

## 前置条件

1. Windows 已安装并激活 SOLIDWORKS 桌面版。
2. 模型模板中的尺寸已经命名并可由 SOLIDWORKS API 驱动。
3. 已准备 `.DRWDOT` 工程图模板。

## 使用步骤

1. 登录软件，进入“优化设计”，点击“SW参数化出图”。
2. 选择 `.SLDPRT` 或 `.SLDASM` 模型模板。
3. 选择 `.DRWDOT` 工程图模板。
4. 选择输出目录并填写输出文件名。
5. 在参数表中填写 SOLIDWORKS 完整尺寸名和值。
6. 点击“开始参数化出图”。

完整尺寸名示例：`D1@Sketch1`。尺寸名必须和模板中的名称完全一致。
界面输入长度统一使用毫米，调用 SOLIDWORKS API 时会自动换算为米。

## 输出文件

假设输出名称是 `S11-1000-10`，输出目录中会生成：

- `S11-1000-10.sldprt` 或 `S11-1000-10.sldasm`
- `S11-1000-10.slddrw`
- `S11-1000-10.pdf`（勾选“同时导出 PDF”时）

## 注意事项

- 本功能不会覆盖原始模型模板。
- 第一次使用前建议先在 SOLIDWORKS 中手动打开模板，确认模板没有重建错误。
- 自动尺寸布局依赖模板中“标记用于工程图”的尺寸；复杂图纸仍可能需要人工整理。
- 项目通过 Windows PowerShell 调用 SOLIDWORKS COM API，因此只能在 Windows 上运行。

# 方案计算单字段归位与折叠区验收（2026-10-14）

## 本次改动

“高级工艺参数”和“校核指标与说明”默认收起，点击标题展开或收起。折叠仅隐藏行，不重建控件，不更改绑定或丢失编辑值；自动计算仍更新折叠区内的结果。

以明确的“结果名称 → 计算单地址”对应表移除下方重复的基础电量、匝数、绕组尺寸、损耗、重量、温升和阻抗等结果。已归位的输入不重复出现。原单中已展示的前15级片宽/叠厚不再重复列在下方。

高压导线形状归位 AC13，相间距基础归位 B28。圆线规格选择及自定义绝缘增厚仍留在高级区，因它们是程序增加的显式选择控件，不能当作原表公式结果冒充输入。

新增67个“计算单”地址的已有中间量输出：段层数、低压分段匝数、高压辐向/轴向组成、层间绝缘张数、各侧平均宽长、油道折算厚、油箱几何链、箱体分件厚度和重量、排油与油重分项、散热面积及单位面积热负荷。全部读取现有引擎的局部变量或输入快照，不修改其计算公式、筛选指标或寻优目标。

中间量仅由方案弹窗请求。默认的两参数引擎入口不采集中间量，因此寻优候选不生成这些明细映射。旧方案没有明细快照时重新计算；新地址在初次构表时就预留，自动刷新不会重建表格。

Sheet1 中的实际截面、磁密和分项铁芯重量仍在校核区，名称明确标注 Sheet1，避免与“计算单”中的 J23（箱底油空）、O24（油箱高）混用。

## 桌面验收步骤

关闭旧程序，双击桌面 ZTBLD，方案选择 → 行内“选择”。

1. 滚动到原计算单底部，应只看到“高级工艺参数”和“校核指标与说明”两个收起的标题，不再直接铺开长列表。
2. 核对上方油道折算厚 M29:M38、平均宽长 AB36/AB39/AK33/AK34、绝缘张数 X41/X42、箱体厚度与分件重量等位置出现当前计算结果。
3. 展开高级区修改工艺参数，收起再展开，值应保留；相关上方结果自动更新。原输入范围和校验保持有效。
4. 已在上方展示的电压、电流、匝数、重量、温升等结果不在下方重复列出；校核区内仍可看到 Sheet1 的实际截面等独立数据。
5. 切换扁线/圆线后，展开高级区选择有效圆线规格，确认结果正常刷新；取消后重开方案仍保持原值。
6. 核对源表 Sheet1 的截面等名称不与“计算单”的同地址混淆。确认保存、取消不保存、连续编辑无抖动。

验证方式为 Release 编译和静态检查；按用户要求不编写、运行测试程序或GUI自动化。待用户验收后再提交PR。

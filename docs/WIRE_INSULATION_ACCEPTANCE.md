# 高压导线绝缘种类联动：改动和人工验收

## 程序改动位置

- `ParamTableWidget.cpp/.h`：普通设计输入的“五 绕组参数”增加绝缘种类下拉和增厚值。专业模式不再显示另一份增厚输入。预设值不可手改，“自定义”可编辑；在同一次编辑中切换到预设再返回自定义，恢复之前有效的手填值，不重建参数表。
- `CalcInput.h`：新增类型字段及共享映射，增厚数值仍为引擎唯一计算来源。不一致的类型/数值作为自定义保留，增厚必须有限且≥0。
- `SchemeStore.h`：保存类型及增厚。旧方案没有类型字段时显示自定义并保留原数值，不仅凭相同数值反推种类。未知种类或种类与增厚冲突时也保留数值为自定义。
- `CalcResult.h`、`ElectromagneticEngine.cpp`、`EmResultPanel.cpp`：结果页和打印增加实际类型、增厚、X14/Z14绝缘线尺寸。没有改写电磁或温升公式，联动值进入既有尺寸、匝长、损耗及温升计算链。

## 原表依据及边界

只读核对 `SB20-M-630-10计算单.xlsm` 的计算单 U14、X14、Z14。原表明确规定扁线 ZB-0.3/ZLB-0.3 增厚0.35mm，ZB-0.45/ZLB-0.45增厚0.50mm，其余分支增厚0.15mm。本批只开放明确的QZB-2/130和以上四种，不把原表默认分支当作任意未知导线已经支持。

类型并不自动更改铜/铝材料。材料仍由既有下拉独立设置，本批未增加型号和材料的工艺互斥规则。增厚是总尺寸增加量，绝缘宽=裸宽+增厚、绝缘厚=裸厚+增厚，不能再乘2。圆线继续禁算，其他铁芯形状及两段线圈仍不开放。

## 用户检验位置

关闭旧程序，从桌面ZTBLD快捷方式重新打开新预览。

1. 设计输入“五 绕组参数”中切换QZB-2/130、ZB-0.3、ZLB-0.3、ZB-0.45、ZLB-0.45，右侧增厚应依次为0.15、0.35、0.35、0.50、0.50mm，且只有值可联动，参数名称仍不可修改。
2. 选择自定义并填写0.27mm，切换到预设再切回自定义，应恢复0.27mm。自定义填负值或非数字时计算应明确拒绝，不能默默用旧值计算。
3. 计算后在结果“绕组”页核对类型、增厚和X14/Z14。例如裸宽2.05、裸厚5.52时，三组预设绝缘尺寸分别为2.20×5.67、2.40×5.87、2.55×6.02mm。其他参数相同，重新计算后核对绕组尺寸及“温升”页变化，不能要求取整后的每项都变化。
4. 保存方案后重新加载：五种预设类型分别恢复，自定义值恢复。加载旧方案应显示自定义并保留原增厚（即使原值恰好0.15/0.35/0.50也不改成预设）。不要覆盖原始旧方案进行验证，可另存副本。
5. 在普通输入、专业模式和方案参数弹窗分别核对：只出现一份增厚输入，回显、计算、打印输出一致，切换类型不应造成整张表重建或屏幕抖动。
6. 确认铜/铝材料不随绝缘种类自动切换，圆线/两段线圈/非椭圆截面的限制仍保留。

本批仅编译和静态复核，不新增/运行测试程序，不修改或重算Excel文件。程序效果由用户验收后再上传并创建PR，不自动合并。

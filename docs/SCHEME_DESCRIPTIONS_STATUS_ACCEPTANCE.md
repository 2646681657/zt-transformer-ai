## 原表与引擎发现的差异（未修改数值算法）

> 本节记录PR64版本的发现。第4/5级油道加权顺序已在后续批次按用户确认修正，当前口径见 `SCHEME_DUCT_WEIGHTING_ACCEPTANCE.md`；其他条目不因本批修正而视为全部解决。

1. 原Excel的M32/M33采用“相间侧×AK33平均宽＋端部侧×AK34平均长”；M37/M38同样交换AB36/AB39的宽长权重。当前引擎全部五级仍用“相间侧×平均长＋端部侧×平均宽”。第4、5级说明和数值格的悬停提示明确标注待核对差异。两侧尺寸相等时数值一致，不相等时可能影响漏磁厚、阻抗及相关量；不能仅凭默认配置断言算法完全一致。下一批需单独核对工艺意图和数值算法。
2. 原E39拼接文字仅列前三个油道，M39的真实数值公式累加全部五级；现引擎也累加五级。这里按实际数值口径显示五级，避免复制过时文字。
3. 原AD48文字只写低压电阻损耗，AK48实际公式加AS45低压附加项；程序显示实际热负荷口径。高压U48也显示引擎实际电阻与附加损耗。
4. 原W39说明文字包含五级，但AB39数值仅引用前三项。此位置仍待后续核对，不能把字符串示例直接当成算法。
5. 原U52文字中的散热计数列五组端部油道，但AC52真实数值公式和现引擎只列前三组。这里显示实际数值公式中的计数，不把过时拼接文本当作算法。

低压内连接排、旧单位铁损/工艺记录、储油柜、铁轭辅助项、N50高度比、AJ45/AS45等真实未接入或含义待定项保持原有标识。

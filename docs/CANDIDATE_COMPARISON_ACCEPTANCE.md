# 第五批：DNN候选方案旁路对比

## 入口与用途

完成计算或寻优后，进入方案列表，在“方案库比较”区域点击“DNN旁路对比”。寻优运行期间不启动对比。窗口冻结当前可见候选，按当前列表顺序展示；隐藏及未保留方案不纳入，不代表全部搜索空间。超过16MiB的快照整批拒绝，不截断。

每个候选展示六项原公式指标、模型独立修正值、差值及推理失败原因：空载损耗、负载损耗、阻抗电压、油顶层温升、高压绕组温升、低压绕组温升。原材料成本仅供对照，不由模型修改。

没有模型或运行环境时保留原值并解释原因。已审核默认模型也仅用于独立展示；实验及测试模型须显式勾选允许实验对比，并持续显示标识。目标未训练、结构不匹配、超出训练范围等保留对应空值和原因，不补零、不隐藏整行。

## 不变的正式计算

本窗口复制原始输入与计算结果，不重新计算原值，不修改筛选、排序、合格判定、已确认方案、产品报价或打印。修正值不回写计算引擎；差值不代表精度改善。现有残差模型依赖原公式结果，不能据此宣称寻优加速。

## 本地记录与失效

记录位于用户自学习数据目录下的 `comparisons/<任务UUID>/`。保存冻结输入、任务状态和独立结果。只有子进程成功、全部行与模型/报告/输入摘要核验通过、审核状态仍有效时，才显示成功记录路径。

取消和失败会清空上次修正值；可重新启动。模型、训练报告或已审核默认状态发生变化时清空修正展示。取消只停止本窗口启动的后台进程。

## 用户验收点

1. 计算或寻优结束后打开入口，原方案数量、顺序、成本不变。
2. 无模型时不能启动，但六项原公式值仍可查看。
3. 选择实验模型，勾选许可后启动；测试模型结果带“仅测试预测”标识。
4. 查看成功目标和失败目标；失败显示空值与原因，原值仍保留。
5. 再次启动后取消：旧修正值清空，可以重试。
6. 关闭对比窗口后确认原方案、报价和打印内容保持原值。

测试仅使用临时合成数据及真实CPU训练，不写入企业样本库，不证明实际工程精度。

# 心柱、铁轭选型数据贯通与旧方案兼容

日期：2026-10-21。基点：`b8f8df8`；沿用已附加的 `scheme-sheet-layout` 独立工作区。

## 本批范围

本批不改变已验收的方案计算单布局，不迁移圆形/长圆形、同心柱铁轭的整机公式，也不开放这些选项的完整计算、确认或寻优。原有独立几何叠积预览与AI说明草稿修改保留，不把后者的云端效果当作本批验证结论。

1. `CalcInput` 增加心柱、铁轭选型；方案JSON、我的方案库、记忆库、上次方案及输入相同性比较共用该数据。
2. 原有心柱枚举数值保持不变，JSON `coreShape` 使用0圆形、1长圆形、2椭圆形、3半椭圆形、4类椭圆形；`yokeShape` 使用0同心柱、1T形轭。禁止重排这些持久化编号。
3. 仅缺字段的旧文件默认椭圆形/T形轭。显式空值、字符串、布尔、非整数、越界编号等转为未知标记-1，后续保存仍无效，不能变为可算的默认值。
4. 设计输入页从可见Ribbon选型收集数据；加载方案时恢复该方案心柱按钮及铁轭配置。当前页面选型不能覆盖被加载的旧方案默认选型。
5. 弹窗F4/F5从本方案输入恢复，切换时更新其隐藏参数表而不重建编辑器。F5下方底层单元格文字同步当前铁轭类型，不再固定写T形轭。
6. 弹窗仍只有重算成功才能确认；取消不写回原方案。没有新增“保存未计算草稿”入口，不能把JSON能表达选型误称为未支持结构已经可以确认保存。
7. 主界面适用范围检查、整机引擎、引擎截面预览与旧打印计算入口都保留对应拦截。切换圆形不清空直线段或椭圆角，不推测工艺规则。

## 检查位置与人工验收

### 设计输入页

- 在上方铁芯结构栏切换圆形/长圆形，再切普通/专业模式，选型应保持，不应自动变回椭圆形；原几何输入不应被清零。
- 选用已有可计算旧方案或推荐方案后，心柱应恢复该方案的椭圆形，而不是沿用当前圆形按钮。既有未支持结构禁算规则不变。

### 方案选择 → 行内“选择” → 计算单弹窗

- 第4行F4心柱、第5行F5铁轭仍在原位置，下拉外观与整表布局不变。
- 切圆形/长圆形或同心柱时，应提示当前整机算法未接入，不得重新给出一套椭圆/T形轭的成功结果。
- 切回椭圆形/T形轭后应可恢复原有自动计算；其他输入不应丢失。
- 修改参数后取消，再打开原方案，原有参数及选型应保持；确认成功后再打开，应恢复已确认的方案。

### 保存兼容

- 可计算方案按既有路径保存、加载后，心柱/铁轭与原方案一致。
- 旧方案缺少新字段按椭圆/T形轭处理；新文件损坏字段不能静默回退为可计算结构。
- 本批未支持选型仍不允许通过当前界面确认或保存为已计算方案；这些分支的完整算法留待下一批。

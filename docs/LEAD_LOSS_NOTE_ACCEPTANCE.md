# 引线损耗作用说明：人工验收

## 改动及范围

- 专业模式“九 损耗系数（高级）”将引线损耗名称标注为“未参与”，右侧常驻说明“仅记录，未参与计算”，名称/值悬停可看完整说明。
- 保留leadLoss_W输入绑定、数值编辑、方案存储及导入，不新增限制，不清空旧值。参数名称仍不可编辑。
- 计算结果保留本次引线损耗输入快照，仅用于显示，不进入任何损耗或温升公式。结果“绕组”、结果文本导出和打印明确列出记录值及未参与状态。
- 打印以计算结果快照为准：修改输入但未重新计算时，旧结果的记录值不变。
- 修正CalcInput中将该字段标为原表J10的误导性注释；审查记录指出原表J10为杂散系数，不是引线损耗W值。不将此值擅自加到负载损耗或温升。
- 不改寻优损耗筛选、报价和已有电磁算法。仍需专业人员确认引线损耗定义及与已有附加/杂散损耗是否重复，后续再决定算法。

## 请检验的位置

1. 关闭旧程序，从桌面重新启动。专业模式“九 损耗系数”应看到引线损耗未参与提示；值仍能改，名称不能改。悬停可读说明。方案参数弹窗同样使用共享输入表，应显示提示。
2. 选一个此前能成功计算的输入，引线损耗分别设为0和100W，两次重新计算：结果“绕组”显示各自记录值和未参与说明；空载/负载损耗、阻抗、温升及成本应不因这一个记录值改变。
3. 结果文本导出和打印预览应有记录值及未计入说明，数值与结果页一致。只修改输入为200W、暂不计算时，已生成结果及打印仍应保留上次计算快照；重新计算后更新为200W。
4. 在方案参数弹窗编辑记录值，确认并重开，以及保存方案库后重新导入，该值应保留；取消编辑不提交。旧方案字段行为保持不变，不覆盖原文件。
5. 寻优仍只使用已有损耗结果/性能约束，该记录值不改变本批的合格筛选；此前验收的油膨缩、独立工艺系数及曲线范围保护继续保留。

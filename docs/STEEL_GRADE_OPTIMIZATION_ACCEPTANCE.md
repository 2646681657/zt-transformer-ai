# 硅钢牌号联合寻优人工验收

分支 `codex/steel-grade-optimization`，基于已合并PR52的dev。用户已批准：候选牌号显式勾选、与现有尺寸搜索组合，片厚联动，沿用完整引擎及曲线越界保护，按牌号统计可行数量和最低材料成本。默认固定当前牌号，不改公式、价格或方案弹窗布局。

## 程序改动位置

- 计算主页 → 优化计算 → 循环参数设置：新增“硅钢牌号参与寻优”（首次默认关闭）。开启后点击“勾选候选牌号…”进入独立勾选窗口，显示片厚、现有曲线磁密范围。
- 只有数据库唯一收录、片厚格式有效、至少2个升序正磁密点且铁损/磁化容量为有限正数的牌号可列为有效候选。零值也不作为有效正磁密点数据（加载器的缺失数值会成为0），避免把缺数据当零损耗材料。不制造曲线、不外推。曲线范围不是材料保证值。
- 设置实时显示已选数、有效参与数、参与清单与组合预算。开启却未选任何牌号时拦截，不自动补当前牌号。可只选其他牌号；基准设计本身仍须通过现有输入校验。
- 保存参与开关和选择名称；有效运行清单每次启动重新核对。旧选择失效时明确报错，勾选窗口保留失效项供取消，不静默删掉。选择窗口取消不改当前选择，外层取消不持久化。
- 寻优统计：增加按牌号的计划、已处理、引擎调用、可行、失败、约束/线型剔除、未处理与最低可行成本。无可行项明确显示“无”，不能当作0元方案。

## 组合、联动和成本口径

粗搜组合数=原尺寸/线规组合数×勾选有效牌号数。牌号成为独立分类坐标，参与跨轮去重；相同尺寸但不同牌号不能误判为重复。每个组合同步牌号与其片厚，再调用现有完整引擎，重新计算几何/实际磁密、铁损、磁化容量、空载电流以及后续损耗、温升和材料合计；不同牌号不保证每个显示值都变化。

一轮/多轮细搜沿用全体已评估可行方案最低材料成本的3个中心；保持各中心的牌号，仅细化原尺寸/离散线规，不把名单顺序当物理邻近。不保证每个牌号都有细搜中心，但粗搜会覆盖全部勾选牌号。原固定变量、上下界、订单、标准、线型、暂停/停止规则保持不变，总保守预算仍最多100000组合。

牌号对应的曲线磁密越界，仍由原引擎拒绝计算，不取端点替代、不放宽约束。不合格候选不能入库或当细搜中心。单个牌号无可行候选不阻止其他有效牌号按原约束处理。

所有牌号的钢材仍统一使用17元/kg内置基价（另沿用原重量损耗系数和舍入），不是不同牌号的实际采购成本比较，不宣称实际采购最优或全局最优。没有新增牌号价格、报价来源或制造校核。

## 建议人工验收

1. 关闭旧程序，从桌面快捷方式重新打开。循环参数看到新增参与开关，首次关闭时仍固定当前牌号，原单轮及细搜模式可用，原组合数不变。
2. 打开开关，先不勾选：保存/启动应提示至少选择一个有效候选。打开候选窗口选择2个有效牌号（内置表可选18SQGD065和20R070，片厚分别0.18、0.20 mm，曲线均为0.40～1.92 T；使用外部数据时以实际列表为准），确认清单只含勾选项；当前基准不会自动补入。
3. 选择单轮模式，固定其他九项，只打开牌号：2个牌号计划应为2组合。每个牌号1次实际处理（可能计算失败或约束剔除），不能因为尺寸相同只算一次。
4. 原四变量默认范围、其他尺寸和圆线关闭、2个牌号时，粗搜为270组合。仅低压箔厚±1步、2个牌号时为6组合。预算随牌号数相乘，超上限明确拦截。
5. 比较不同牌号候选的牌号、片厚、磁密、铁损/空载电流和成本；片厚应随牌号前两位联动。可以出现成本相同，不是错误。价格仍标注17元/kg统一基价。
6. 用一轮/多轮模式检查细搜不生成未勾选牌号，跨轮输入不重复；细搜中心为全体最低成本3个可行方案，不要求每个牌号都细搜。
7. 统计各牌号数量相加=总量；每个牌号计划=已处理+未处理，调用=可行+失败+约束剔除，已处理=调用+线型预检；无可行方案不显示0成本最优。暂停/停止后保留真实实际数量。
8. 保存后重开保留开关与选择；取消候选窗口和取消外层窗口均不保存新选择。取消参与后固定当前设计输入牌号，原候选名称保留供以后使用。
9. 若有外部曲线数据管理需求，可检查失效旧选择必须显式取消；曲线范围外的候选按原引擎提示失败，不能取端点替代。无需为验收故意破坏原数据。

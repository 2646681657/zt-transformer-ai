## 刷新与安全边界

参数提交、牌号/接法/绝缘/材料等下拉、已提交的产品型号与调压输入改变后，先清除旧预览显示，200毫秒合并连续事件再更新。只写固定结果单元格，不重建表格、移动焦点或自动改变实际匝数。

预览在独立参数副本和隐藏验证表上进行；隐藏表默认不开启主页面新行或定时计算，避免递归。当前数字单元格原始文本逐项传入验证表，不能因格式化丢精度或因非法值回退旧值。额定值与当前已提交缓存须一致，低压额定电压仍按回车提交。不会因预览改变原页面的标准模式、损耗指标、手工叠厚或实际匝数。

经现有统一参数收集及支持范围校验、几何预检后，调用原 `calcElectromagnetic` 获取本次完整结果；前端不另算片数、截面、磁密、重量或铁损。原引擎及方案弹窗文件相对基点不改。

任一输入未完整/非法、指标来源待确认、算法不支持、曲线越界或完整计算失败时，六个值均显示“不可用”，备注与悬停提示说明原因，不显示上一次有效结果。有效预览也不表示指标已合格；完整计算的其他阶段失败时，这三行同样不会宣称当前输入有效。

## 人工验收

关闭旧程序，从桌面 ZTBLD 重新打开，进入设计输入页“**四 铁芯参数**”。

1. 默认有效输入时三行应可见且不可编辑；进入计算页核对截面、磁密、重量与空载损耗使用相同输入的引擎口径。设计磁密与实际磁密允许不同，不要求强行相等。
2. 更换同片厚硅钢牌号：截面、磁密或重量可能不变，但曲线范围及铁损按所选牌号重新计算。不同片厚牌号可能影响片数取整后的实际截面与重量，不要求每个显示值必然变化。
3. 修改铁芯直径、直线段、椭圆角、接缝数、补充片叠厚，提交单元格后观察三行更新；修改实际低压匝数应影响磁密/铁损，但不能被推荐值覆盖。与曲线范围不相容时应“不可用”并说明原因。
4. 产品型号低压电压改变但未回车时，不能显示为已采用新电压；回车后按新额定值刷新。字段清空或输入非数字、调压输入不完整时，不能使用旧缓存冒充当前有效值。
5. 换到未支持形状、Dd/Yd 或分段时，应“不可用”，仍禁止进入计算；恢复支持组合后恢复预览。快速连续切换不应抖动整页或改变手工参数。
6. 非标模式下修改牌号/几何仍保留手工指标；普通/专业切换、导入及方案回填后三行正确恢复。方案计算单弹窗不插入这三行，原布局及自动计算不变。

# 可继续联动的计算单Excel导出

## 本轮完成的依赖核查

原模板含4张表：计算单400条公式、成本测算26条、线圈型式471条、Sheet1有392条，合计1289条。
10个下拉均为表单Drop控件，由线圈型式的链接单元格驱动。原文件虽为xlsm但无vbaProject.bin，未发现VBA宏。不能用普通表格工具往返重存，以免丢失表单控件、VML和绘图关系。

外部文件引用须按公式语法识别，不能把公式字符串中的方括号说明算作外链；初步扫描37条含方括号公式，其中包含展示文字，需要在实现时精确解析。查表目标主要为Sheet1和能效与硅钢性能。

已比较外链缓存与现有计算用数据表.xls：Sheet1的2281个缓存值一致；能效与硅钢性能1135项中1134项一致，P54缓存125、现有表1.608。此差异单独记录，不能悄悄以缓存或现有数据替代对方。

## 实施方式

1. 原模板复制导出，完整保留公式、控件、绘图、格式和打印区。
2. 建立程序输入到原单及线圈型式链接单元格的映射。下拉必须同时同步链接索引、控件选择状态与公式，不能把公式结果格写成常量。
3. 查表数据内置到导出工作簿，以工作簿内引用替换外链。核查P54来源差异对相关牌号分支影响；其余数据逐项复核。
4. 弹窗增加输出Excel，先采集当前编辑并校验；不替用户确认方案。选定路径后导出独立副本，原模板和已打开文件不写入。
5. 验收覆盖：Excel正常打开无修复提示，控件10个完整，外链依赖清除，修改下拉/关键参数可重算，默认候选输入和结果对比并列记录差异。

本轮仅执行只读梳理和保存审计记录；尚未新增按钮或声称完整联动导出已完成。

# 设计输入：指标来源模式与方案恢复验收

2026-10-06，分支 `codex/design-standard-source`，基点 `d6e4cde`。本批为指标来源和保存链，不改变电磁公式，不调整方案计算单弹窗布局。

## 程序位置与边界

- `ParamTableWidget`：主设计页“二 性能指标”增加“指标来源模式”固定行下拉。内置标准只匹配既有损耗表，不是全部国标指标认证；阻抗、空载电流、偏差、温升仍为手工指标。非标不自动覆盖任何指标。
- 手改内置模式的任一损耗值会转非标，修改型号、容量、接法仍保留手工值。切回内置前提示将替换三项损耗；取消保持原模式和值。规格不适用内置表时阻止切回，不用相邻规格代替。
- `TransformerParams`、`PerformanceCriteria.h`、`CalcInput`：明确来源模式，并携带14项指标快照及型号、来源键。该快照仅是保存/校核元数据，不参与电磁实际值公式。
- `SchemeStore`：共用JSON编解码新增版本1的 `performanceCriteria` 对象，保存损耗、阻抗、空载电流、允许偏差、三项温升。覆盖我的方案、记忆、上次方案、批量方案；旧数据未改变、未删除。未知版本、模式或不完整字段标为来源未确认，不默默采用内置模式。
- `OptimizeCalcPage`：方案回填恢复指标；来源待确认不能直接计算或保存。导入基础参数入口支持JSON，旧批量文件可选一条回填主设计页，再确认来源与指标、保存新方案。老文件不被修改。
- `EnterCalcPage`：成功计算后采用已校验的方案指标；旧批量文件含待确认来源时，在清空现有方案表之前拒绝重算并说明如何核对。新文件逐条按自己的快照恢复校核参数。

独立静态审查补充：方案选择先在局部候选上校验，失败不替换当前输入；寻优启动也先收集并确认指标来源，再清空方案表。损坏型号不能带着已确认来源回落为SB20。14项指标使用可往返的 double 精度回填，避免隐藏表格重载改变校核边界。

## 人工验收位置

关闭旧程序并从桌面 ZTBLD 重新打开；进入**设计输入 → 二 性能指标**。

1. 选择“非标（手工指标）”，填入容易识别的三项损耗、阻抗、空载电流、偏差及温升。修改产品容量、系列或 Dyn/Yyn，确认这些指标不变；相电量按接法正常变化，实际匝数不自动改。
2. 切回“内置标准（损耗表）”，选择“否”应保持非标和值；选择“是”应匹配三项损耗，其他指标不变。`SB20-M-160/10-0.4` 的既有表：Dyn 负载1850W，Yyn负载1760W；630kVA两列均4960W。
3. 内置模式手改一项损耗，应转非标并保留该值。切到未收录系列/容量时不假匹配；从非标切回内置应说明不适用并保留原模式。
4. 保存为“我的方案”，换成其他指标后重新加载，确认原模式、型号系列、14项指标恢复。再检查进入计算记录的“记忆库”“上次方案”，以及新版批量文件重载。指标变化只影响校核，不应直接改变同一组电磁设计输入的实际损耗/尺寸。
5. 通过“导入基础技术参数表”选择旧JSON方案文件，多条时选择一条。旧文件未保存指标，页面只能保留当前手工值作为待核对草稿，不能声称这些就是旧方案原指标；提示来源待确认，进入计算或保存被拦截。明确选择内置/非标并核对后，方可保存新版方案。原文件保留。
6. 普通/专业模式切换后模式与指标不丢失。打开方案计算单弹窗，确认布局未新增该下拉或长明细，自动计算及确认/取消保持。
7. 可填阻抗指标 `6.123456789` 等较长小数，保存重载后数值应保留。计算页尝试加载旧方案时应拒绝并保留当前有效输入，不能将旧方案与上一个方案的指标混合后直接寻优。

未将计算单 O9 的 `−0.34` 作为默认算法；未接入来源适用性待核实的空载电流数据库；未开放 Dd/Yd、其他心柱形状或分段算法。内置标准不适用时保留原损耗值并提示人工核对，不能视为已匹配。

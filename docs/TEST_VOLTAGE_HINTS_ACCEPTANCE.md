## 程序改动

- 设计输入“一 输入信息”：新增高低压试验电压只读行。依据已提交的额定电压：高压输入其后的“-”提交；低压按回车提交。编辑尚未提交时仍显示之前提交值的提示。
- 计算结果“绕组”、打印输出：增加参考值、来源和说明；来自本次计算结果快照，不随尚未重新计算的输入修改而改变。
- TestVoltageHints.h 共用映射；不存为用户输入，不参与电磁、损耗、温升或寻优公式，不作为绝缘合格判定。
- 原有计算入口的结构、频率、温度限制不变。提示有值不表示该配置支持完整计算。

## 计算单原始边界

高压按顺序比较上限（kV）：≤1：AC5；≤3.6：LI40AC18；≤7.2：LI60AC25；≤12：LI75AC35；≤24：LI125AC55；≤40.5：LI200AC85。超过40.5显示“需人工核对”。

低压严格小于1kV：AC5；恰好1kV及更高显示“需人工核对”。非法、非正、非有限电压不提供提示值。符号沿用原计算单，非最新版标准认证。

## 请检查

1. 桌面快捷方式启动新版本，默认 SB20-M-630/10-0.4：高压 LI75AC35，低压 AC5；参数名称和值均不能编辑。鼠标悬停可查看来源说明。
2. 修改型号并提交，观察高压各上限1、3.6、7.2、12、24、40.5，以及略高于上限时的下一档；40.6显示人工核对。低压0.99为AC5，1为人工核对。
3. 使用已支持、可成功计算的配置，查看“绕组”页及打印预览的参考值和说明；新输入必须重新计算才更新结果快照。
4. 保存再打开方案，确认提示重新按额定电压生成。旧方案也无需新增字段或迁移。
5. 对比相同输入的旧版损耗、阻抗、磁密和温升，确认没有因提示行产生变化。选择其他铁芯形状等未支持配置，仍应禁止计算。

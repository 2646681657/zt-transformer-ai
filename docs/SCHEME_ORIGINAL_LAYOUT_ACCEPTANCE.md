# 原计算单布局预览验收（2026-10-14）

> 补充区整理和已有中间量接入后的验收以 `SCHEME_FIELD_CONSOLIDATION_ACCEPTANCE.md` 为准；本文件保留原布局说明。

本文件替代 SCHEME_CALCULATION_SHEET_ACCEPTANCE.md 中旧的“三分区12列”布局说明。

## 本次范围

方案选择 → 行内“选择” → 方案计算单。采用 SB20-M-630-10计算单.xlsm 的“计算单”工作表 A3:AL54 的行列位置和合并区域，顶部保留复合型号编辑区域。左右两页并排；不包含 AM 列以后的参考区和椭圆图。为非对称调压三数扩大了原分接范围的编辑区域。W12 标题按引擎实际含义显示为“总层数”，原表写的“每层匝数”不沿用。

原表只有位置、标签和合并区域进入程序，不携带原示例数值或 Excel 公式。原公式依旧由现有计算引擎执行；已有结果按明确地址映射。计算单以外及 Sheet1 的参数和详细结果集中在下方补充区。弹窗展示完整的已有高级参数，主设计输入页的普通/专业模式不改。

新增输出低压轴向高度及高压油道层序：均复制现有引擎中已经算出的变量，不更改公式。旧结果没有本版布局快照标志时自动重新计算，重算前显示“待重新计算”，不显示默认零。

## 明确未完成的数据项

这次是原表布局及已有结果接入，并非所有中间量均已支持。未接入的原表数据格显示“—”，悬停可见源地址和说明，既不使用示例缓存，也不当成零。

典型未接入项包括部分箱盖/箱沿/箱壁重量分项、层数与匝数分布中间过程、平均宽长展开式、部分油道折算厚和散热中间量。部分量在引擎内部可能已有局部变量；是否仅需输出或需要补算法须逐项确认。“—”不能被解释为已算出或已合格。

P12、S12 保持原表“小圆心角”“大圆心角”标签，其数值仍使用原有 180−2×椭圆角、2×椭圆角计算结果，不修改引擎内部历史成员名和公式。

## 从桌面验收

先退出旧程序，再双击桌面 ZTBLD。进入方案选择，点击任一方案的“选择”。

1. 弹窗为原表左右并排布局：左侧重量、铁芯、油箱、阻抗；右侧绕组、电量、绝缘、油道、温升。窗口不足时可以横向、纵向滚动，不缩小字号。
2. 对照同一方案核对：高压线/相电压、匝数、绝缘尺寸、电阻、铁芯截面、损耗和重量。参数名只读、结果只读；浅绿输入可改。
3. 修改铁芯直径、硅钢牌号、低压匝数和高压裸线尺寸，相关计算值自动更新；连续输入不丢焦点，不发生表格重建或抖动。
4. 修改产品型号，低压电压后按回车；修改调压正级数、负级数、每级百分数，核对最高/额定/最低分接电压。
5. 专门检查 J23 箱底油空与 J26 垫脚高、P12/S12 圆心角、几何叠厚与实际截面的口径。不同工作表的同名单元格不混用。
6. 输入不完整或不合法时显示未更新提示；补全后恢复。确认仅保存当前方案；取消后重开应保留原值。
7. 滚动到补充区，原先的限值、偏差、工艺参数和结果仍可查阅；检查主设计输入页与打印页布局保持原样。

按用户要求仅做 Release 编译和静态检查，不新增或运行测试程序、GUI 自动化。桌面程序部署前备份旧 exe，用户验收后再提交 PR。

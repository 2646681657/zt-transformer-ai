# 寻优规则第一批人工验收

本批在 `codex/optimization-rules` 实施，沿用现有电磁公式、约束过滤和内置价格，不改方案选择后的计算单弹窗。

## 程序改动位置

- 计算主页 → 寻优计算 → 循环参数 → 循环参数设置：四个变量分别可勾选参与寻优，未勾选保持当前基准。显示步长、范围和实际上下界。容量、电压、联结组别、性能标准及允许偏差不是寻优变量。
- 同组新增“寻优统计”：本轮结束或停止后显示冻结订单和指标、搜索边界、计划组合数、实际计算数、入库数、计算失败、约束剔除、未评估、耗时和原因。
- 默认目标仍为内置基价材料合计最低，包含铁芯、高低压导线、油和油箱；与方案表第二成本列一致，报价调价不影响选优。未启用指标标为“未校核”，不称为全部指标合格。

## 请验证

1. 关闭并重新打开桌面程序。打开循环参数设置：四项取消勾选时计划组合数为1，上下界一致；只打开某一项时只有这项边界扩大。保存后重开程序检查开关保留。
2. 默认四项参与，范围2/1/1/1时为135组合。按开始运行，完成后查看寻优统计：实际计算135，实际计算=入库+计算失败+约束剔除。方案表新增数量应等于入库数。
3. 若有入库方案，按方案表“内置基价成本/材料合计”升序排序，最低值与统计最低材料合计一致（注意显示精度）。没有候选时统计明确无最优方案，不把上次结果当本轮最优。
4. 较大范围运行后点击停止（可先暂停再停止）：实际计算不超过计划，未评估=计划-实际计算，不计入淘汰；停止时的最低值仅是已计算候选的最低值。
5. 在自定义标准模式下，某项标准填0后重算：统计应列为未校核；其他指标仍按标准和偏差过滤。淘汰原因可有多项，原因次数合计可能大于约束剔除组合数。
6. 修改步长/范围使搜索下界直径<=0、直线段<0、低压匝数<1或W12<2，应阻止保存/启动。运行中不能修改循环参数、快速计算、打开方案库或修改候选；结束后恢复这些操作。查看方案后弹窗布局应保持原样。

本批是单轮四变量网格，不是完整自适应多轮寻优，不新增其他形状算法，不实现真实多线程。统计暂为本次运行内存记录，不新增方案库文件格式。

仅执行 Release 编译和只读审查；未创建或运行自动测试及 GUI 自动化，由用户验证实际效果。验收前不推送、不创建 PR。

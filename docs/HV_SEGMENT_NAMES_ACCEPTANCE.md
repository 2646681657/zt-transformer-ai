# 分段圆筒式命名与工艺提示：人工验收

## 原表依据与本批范围

上批只读核查了原计算单的下拉控件及批注：高压控件的列表为“线圈型式!B2:B3”，链接“线圈型式!C2”，AC9引用C2；第二项“分段式”对应2。AC10批注明确按串联计算，Y9批注明确“若是分段则两段算一层”。当前保存的AC9仍为1，没有分段数值参考结果。

本批统一显示名称为“分段圆筒式（两段串联）”，补充工艺口径提示。不更改计算公式、层数、匝数、方案JSON字段或枚举值，不自动除以2，不开放分段或其他高压线圈计算，不推测其他铁芯形状算法。

## 程序改动位置

- 设计输入顶部高压线圈结构按钮：两行显示完整名称，悬停说明原计算单批注及禁算原因。
- 设计输入第五节“高压总层数W12”行：名称、数值、备注都可悬停查看W12/Y9口径；选分段时备注显示“两段串联、两段算一层；暂不开放计算”。切换只更新固定行，不重建表格或写回数值。
- 正常/专业模式帮助区：均增加工艺说明，避免把名称统一理解为算法已开放。
- 计算结果“绕组”明细及共用设计结果表：实际型式仍来自本次结果快照；增加工艺参考说明，单段结果不能被标成分段。
- 计算页产品结构说明、界面拒算和引擎拒算文案同步；仍保留原来的条件与严格方案型式读取边界。
- core/HvCoilFormNotes.h只集中维护显示文字，不改变支持范围、转换层数或参与数值计算。

## 请验收的位置

关闭旧程序，从桌面ZTBLD重新启动。

1. 设计输入顶部第二种高压线圈结构应显示“分段圆筒式（两段串联）”，悬停提示明确“两段算一层”及尚未开放计算。
2. 第五节W12行的备注随选型变化；悬停名称/数值/备注能看到Y9自动计算规则。记下或修改W12后反复切换：值不应翻倍、减半或恢复默认，也不应出现整表剧烈抖动。参数名称保持不可编辑。
3. 切换正常/专业模式后工艺提示保持；返回单段时备注恢复单段输入说明。
4. 选择分段，点击“进入计算”或“校验算单”仍被阻止，提示尚缺分段参考算例。不能仅因已找到工艺批注而开放计算。
5. 恢复多层圆筒式并使用原可算参数：绕组明细应显示AC9=1、多层圆筒式，新增工艺参考不应改变每层匝数或原数值结果。设计结果表同名项目应一致。
6. 先选分段再采用原单段方案，按钮与W12说明均应回显单段；未知/无效型式方案仍不得默认为单段计算。

# DNN第三批验收：独立测试、模型比较与展示审核

## 入口与边界

在原“自学习”窗口进入“训练与模型”页，向下滚动到“独立测试与模型比较”和“企业审核标准与默认独立展示模型”。本批只影响样本表中的DNN修正展示列，不替代原公式，不改变寻优、合格判定、材料成本、报价或打印。

## 检查顺序

1. 无数据/无模型时：测试按钮、默认模型预测、启用和回退不可用；误差门槛不应自动填数值。
2. 有真实训练模型后：选择未参加其训练或验证的产品，勾选需要比较的模型，点击“冻结所选产品并比较模型”。所有版本使用同一冻结测试包；同产品换日期/样本ID仍不能绕过产品组泄漏检查。
3. 结果表：原公式与DNN误差、标签数/独立产品数、覆盖率、失败原因均可查看；缺失标签不填0。越界或缺目标不能被悄悄排除后算作全覆盖；原公式零误差不计算百分比改善率。
4. 企业标准：仅勾选要审核的目标，填写企业确认的最大MAE、最大RMSE、最大绝对误差、最少独立产品数及是否不得劣于原公式。填写来源、策略版本并确认后保存。此处没有推荐合格值，不要以流程测试数值当企业标准。
5. 审核：选择上方模型版本与对应独立比较记录，填写本地审核人和理由。没有完整证据、标准不通过、测试/合成模型均不能审核。审核通过后还需另行点击“设为默认独立模型”。姓名仅为本地审计记录，不是账号认证或电子签名。
6. 独立展示：点击“使用已审核默认模型独立预测”，原公式列保持不变，DNN列标注审核展示及版本。结构、固定物理参数或特征范围不符合时，不显示修正值，不用0或旧结果代替。
7. 停用/回退：停用清除默认模型与旧展示，不删除模型/样本；只有仍符合当前策略与完整性检查的历史已启用版本可回退。无有效历史时禁用回退。
8. 多窗口/变更：其他窗口修改标准后，旧窗口必须提示标准变化，重新载入后才能继续；不允许用屏幕上的旧标准审核新的策略。模型、报告或测试包被修改后，原审核不能继续使用。

## 数据与限制

测试包、比较报告和任务记录位于本地self_learning/review/test_runs；审核、策略和切换审计在review/registry/registry.json原子快照中，独立于原samples.json。并发写入使用文件锁，写入失败不能切换默认模型。

临时合成样本仅用于自动化验证训练/测试/取消/阻断流程，永不获得正式启用资格。当前没有企业真实独立测试产品和已确认误差门槛，不宣称已证明生产精度。用于比较/挑选模型的测试集已经参与选择，最终工程验收应补充新的独立产品。

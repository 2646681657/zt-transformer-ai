# 绕组总有效截面批：改动与人工验收

本批对应计算单审查 B1 及 B2 的扁线范围限制。基于已合并 PR #22 的 dev 开始，修改电磁引擎实际公式；不实现圆导线或新温升分支，不扩展铁芯形状。按用户要求不新增/运行测试程序，不执行程序内的对拍自检。

## 依据与公式范围

只读核对 `SB20-M-630-10计算单.xlsm` 的计算单工作表，未修改文件、执行宏或重新计算。原表缓存仅是原始1×1输入的缓存，不是四组输入重新计算的证据。

- U15：单根扁导线扣圆角截面，先ROUND到3位。
- Y15=AB13×AB14；AA15=U15×Y15：并绕、叠绕共同计入总截面。
- X16：相电流/AA15，ROUND到3位。
- X19：75℃材料电阻率×额定长度/AA15，ROUND到6位。
- W21：三相最大分接长度×AA15×材料密度，ROUND到整数。
- Z21：绝缘增重按U15单根截面计算，再作用于W21；仍保留原表的单根分母及整数舍入。
- AA45：平方表达式中的截面改用AA15，保留原系数和2位舍入；AC45仍按电阻损耗×附加损耗率计算。

未改变导线布局、匝长、油道、绝缘工艺及温升计算公式。根数变化仍可能通过原有几何链改变匝长和温升，不应将电阻变化简单理解为严格按根数反比例。2×1和1×2虽有相同总截面，不代表其全部结果必须相同。

## 程序层面的改动位置

- 设计输入页/方案参数弹窗：五 绕组参数，裸线宽厚行增加“仅扁导线”备注，根数行说明总截面公式。
- 电磁计算结果的绕组组及输出打印：区分单根截面U15、总有效截面AA15，并显示高压电密X16、电阻X19、裸导线重W21、绝缘导线重Z21和附加损耗率AA45。
- 共享输入检查与电磁引擎入口：宽=厚按原表识别为圆线并拒绝；非正/非有限裸尺寸、非正根数及扣圆角后无效截面拒绝计算。方案库与寻优同样不能绕过引擎入口。

实现文件：`qt-app/src/engine/ElectromagneticEngine.cpp`、`qt-app/src/core/CalcInput.h`、`CalcResult.h`、`CalculationApplicability.h`、`qt-app/src/gui/widgets/EmResultPanel.cpp`、`ParamTableWidget.cpp`。

保留原 `hvWireSection_mm2` 字段为单根截面，新增 `hvEffectiveSection_mm2` 与 `hvBareWireWeight_kg` 输出字段；不改变既有输入方案JSON格式。

## 人工验收步骤

1. 关闭旧程序，从桌面重新打开。选油浸式/箔绕，保留已支持的结构组合，用SB20默认输入，高压裸宽2.05、裸厚5.52。
2. 只更改并绕/叠绕根数，分别运行1×1、2×1、1×2、2×2。检查单根截面始终10.953mm²；总有效截面依次10.953、21.906、21.906、43.812mm²。这些只是按公式可直接核对的截面值，不是运行程序得到的验证结果。
3. 对每组在Excel中使用相同输入并重算，逐项对照X16、X19、W21、Z21、AA45及AC45；在结果页或输出打印查看对应标签。不只比较成本或总损耗。1×1按公式口径应保持上一版，仍需你实际核对。
4. 在方案选择参数弹窗改根数，直接确认，再打开该方案，检查输入保存、结果刷新；取消编辑时原方案保持不变。
5. 将裸宽、裸厚均设2.05，进入计算/确认方案应提示圆线未支持并拒绝。恢复扁线后可继续。根数设0或裸尺寸非正同样应拒绝。
6. 可再以铝导线重复四组输入，按原表铝电阻率、密度及附加损耗系数核对。观察重量、成本、阻抗及温升的连带变化，但本批没有修复后续温升分支缺口。

效果和数值仍待用户人工验收。验收通过后推送并创建PR，不自动合并。

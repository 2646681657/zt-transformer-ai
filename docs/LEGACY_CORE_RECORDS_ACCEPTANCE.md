## 与实际计算区分

原H16、M16是原单保留的人工记录，不能直接拿当前查表单位铁损、心柱工艺系数或铁轭工艺系数替代。本批只保存和回显文本，不解析成计算变量，不改变引擎、结果结构或寻优空间。

默认空白表示未录入；旧文件缺少字段时仍为空白。不使用工作簿示例0.76、1.13，不因牌号/磁密改变自动覆盖记录。允许保存未完成的记录文本，不因此阻断原有整机计算；当前真正参与计算的系数、牌号等原有校验不放宽。

只改变两项原单记录时，原有铁损、磁密、重量、温升、成本和寻优筛选应保持不变。改变硅钢牌号等真正的设计参数时，当前计算仍正常联动，但这些人工记录不自动变成查表值。

本批不改变数值明细版本：两处为每次弹窗构建时直接绑定的输入，而非需要新增结果快照的字段。后续已确认K19/K20来自内排弦高与几何叠厚查表，不是独立铁轭输入，见 `CONNECTION_BAR_CHORD_REFERENCE_ACCEPTANCE.md`；不擅自填已有补充片宽或叠厚。

1. 设计输入 → 铁芯参数，找到两个新记录，默认应为空；与上方真实心柱/铁轭工艺系数行明显区分。
2. 输入你需要保留的记录，计算后打开方案弹窗，核对第16行H16、M16同步显示；可编辑值，不能编辑名称。
3. 弹窗修改后确认并重开应保留；修改后取消并重开应恢复取消前的值。清空后重开应保持空白，不回退原单示例值。
4. 项目保存重载、普通/专业模式切换应保留记录；旧项目不应凭空出现0.76或1.13。
5. 改硅钢牌号时记录不自动覆盖；只改记录时不改变现有铁损、温升和成本。当前实际参与计算的两个工艺系数仍可按原规则修改和校验。

## 桌面验收

退出旧程序，从桌面ZTBLD打开，方案选择 → 方案行“选择”。前54行的行号与原计算单一致。

1. 油箱尺寸区（23—27行）：F25应等于F23+F24；H26应等于H23+H24+H25；J27应等于J23+J24+J25+J26。修改侧/端净空、波纹高/深，核对相关分量和尺寸更新，S23/Q25应分别跟随S46/S45。
2. 左侧中心距链（31—48行）：B31:B35跟随低压相间侧油道宽度AG28:AG32；B40:B44跟随高压相间侧X30:X34。某个宽度改为0时对应链项应为0；B48应等于B49−B47。
3. 右侧27行：W27应等于W28−W26，AA27应等于AA28−AA26。修改总层数或层间绝缘厚，结果应自动更新，不能编辑结果值。
4. 右侧绝缘排列（40—42行）：将总层数W12由奇数切到偶数再切回，AC40/AC42的X标记应交换，另一个格明确留空。当X41与X42不同，V42/AB41/AB42按对应奇偶分支更新；张数相同时显示值可能相同。
5. 阻抗区：Q29/Q31应显示当前计算值；Z35按W12−Z30−Z31−Z32核对。L51应显示6，相关单元格悬停可看口径。
6. 原有连续编辑、折叠区展开收起、确认保存、取消不保存应保持正常。电压等级标记按已支持配置核对，不需要为检查而切换到不支持的配置。

# 参考磁密与推荐低压匝数：改动和人工验收

## 程序改动位置

- `ParamTableWidget.cpp/.h`：将“低压参考磁密(T)”移到普通“五 绕组参数”，右侧只读显示推荐匝数。铁芯输入、叠片系数、专业模式补充片叠厚、参考磁密和已提交的低压额定电压改变后更新。只更新单元格，不重建表格。非法输入、无解几何或不支持的截面/铁芯/频率/联结组别显示不可用及原因。
- `ElectromagneticEngine.cpp/.h`：增加推荐接口，复用现有椭圆铁芯叠积几何获取心柱截面，不运行全套损耗/温升计算。结果计算和输入预览共用一个推荐公式。主计算链仍以 `lvTurns` 为实际匝数，不以推荐值覆盖。
- `CalcResult.h`、`EmResultPanel.cpp`及打印：记录实际计算时的参考磁密、推荐值及参考匝电压；“绕组”结果页及打印明确区分实际和推荐匝数。已计算结果保留当时输入快照，编辑输入后需重新计算才刷新结果和打印。
- 使用已有 `refFluxDens_T` 保存字段，无需改变方案文件格式；推荐值不另存为手填输入，加载后重新派生。

## 计算单依据

只读检查 `SB20-M-630-10计算单.xlsm` 的计算单 AM8/AN8、AH5/AH6、F14，及 Sheet1!D23。AN8为 `ROUND(AH6/ROUND(AM8*F14*10/450,4),0)`。星接相电压先按AH6取整数，再计算参考匝电压并取四位，最后匝数取整数；不强制向上取整，不提前将心柱截面按显示精度截断。

原表缓存：参考磁密1.7T，心柱截面375.44cm²，低压线电压400V、相电压231V，推荐16匝；原表实际填18匝。缓存仅用于对照，不表示本次运行程序验证了样本结果。铁芯截面继续按目前引擎及工艺输入推导，不在此批修复审查中待确认的T形轭参数联动。

该公式按当前50Hz范围使用，不因此支持任意频率、其他铁芯形状或新绕组结构。参考磁密无效或取整后的参考匝电压为0时仅推荐不可用，不用0充当有效推荐；参考磁密为有限的非正数时不会替换实际匝数，实际电磁链仍可以独立按原输入计算。空白/非数字依旧由统一收集校验阻止提交。

## 用户检验位置和步骤

关闭旧程序后从桌面ZTBLD快捷方式重新打开。

1. 输入页“五 绕组参数”应显示可编辑参考磁密和只读推荐匝数，专业模式底部不再重复一份参考磁密。默认同样输入可对照原样本推荐16、实际18，推荐值不能直接编辑，名称仍不能编辑。
2. 固定其他参数，将参考磁密从1.7改为1.6、1.8，推荐值应按公式更新（整数取整可能使小改动后保持相同）。实际低压匝数不应被修改。重新计算后，若仅改参考磁密，实际磁密、损耗和温升应保持原值，只有推荐信息变化。
3. 修改铁芯直径、直线段长、椭圆角、叠片系数，或专业模式T形轭补充片叠厚，核对提示中的心柱截面与同输入计算结果一致；无解时推荐显示不可用而非上一个有效值。改变产品型号中的低压电压并回车提交后，推荐应使用新电压。
4. 修改实际低压匝数：计算结果须采用手填匝数，推荐仍由参考磁密和几何、电压决定，不反过来跟随实际匝数。结果“绕组”页及打印同时显示实际和推荐，避免混用。
5. 参考磁密为0/负值、铁芯几何非法、非50Hz/非椭圆配置时，检查推荐不可用提示，不显示有效整数或沿用旧值。原有不支持结构的主计算限制仍保留。
6. 保存为新方案后重新加载、切换普通/专业模式、打开方案参数弹窗，核对参考磁密和手填匝数保留，推荐重新派生且与相同输入的结果一致。不要覆盖用于对照的原方案。

按约定只编译、静态复核和只读公式核对，不新增/运行测试程序，不修改/重算Excel。效果由用户验收后再上传并创建PR，不自动合并。

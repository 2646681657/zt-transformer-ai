# DNN自学习框架第一批验收

## 如何进入

桌面原有ZTBLD快捷方式 → 优化设计 → 进入计算后的功能区 → **自学习管理**。

保留“原有实测对比”，新增“学习样本”“训练与模型”。这不是已训练DNN；本批没有训练器、推理器、上线模型或预测精度结果，不修改电磁计算/寻优/报价。

## 建立第一条数据

1. 在“学习样本”点击“选择方案”，从已有方案库/记忆库选方案。选择只更换下一条样本来源，不改当前正在编辑的样本。
2. 点击“从所选方案新建”，填写真实产品/试验编号和日期。编号用于未来防止同一产品泄漏到训练集和验证集，请保持一致。
3. 实测六项可分批补录：空载损耗W、负载损耗W、阻抗%、油顶/高压/低压温升K。没测就留空，不要用0占位。实际温升0可以保存；损耗和阻抗必须大于0。
4. 有实测值时必须填写来源，例如试验报告编号及测量条件。无实测也能先存草稿。
5. 点击“保存当前样本”。关闭重开后点击样本列表可继续补值、清空错误值、修改来源，不新增重复记录。

## 导入、导出与模板

- 选中已保存且无未保存编辑的样本，可“导出当前样本/填写模板”；样本库也可整体导出。JSON格式为`ZTBLD-LearningDataset`、version1。
- 每条包含id、productId、schemeName、source、testedOn(YYYY-MM-DD)、scope、engineVersion、完整input、六项baseline和六项measured。缺实测使用JSON `null`，数值不加引号。不要手改input、baseline、scope和engineVersion。
- 批量新增产品可复制模板条目，使用新的唯一id和真实产品编号/日期，保留与该产品实际设计一致的完整设计快照。不同设计须从相应方案重新导出，不可只改标签冒充新设计。
- 相同id+相同内容重复导入会跳过（包括同一文件内部的重复）。相同id但内容不同会拒绝整批，**不会自动覆盖**；补录已保存草稿请在界面打开并保存。相同产品编号+试验日期不同id也拒绝，避免从两个库重复采样。
- 模板是JSON交换格式，本批不直接读取Excel、旧版TestReport或试验报告PDF。数据后补时可按实际来源再增加转换器；旧实测值不自动导入是为避免0值缺失歧义。

## 训练与模型

- 显示每个目标的已保存实测标签数量。数量不等于独立产品数，更不表示已满足训练量或上线精度。
- 有至少一项真实标签才能导出训练交接包。包内包含输入schema、公式版本、结构范围、指标单位、标签/缺失项、原公式值、残差`实测-原公式`、SHA256摘要及规范化productGroupId（编号去首尾空格并忽略大小写），供后续训练后端按组切分。
- 导出只包含已保存数据，不代表训练已开始/完成；草稿无标签行排除，部分标签保留null。
- 当前明确为“尚无模型/后端未接入”。开始训练、启用、回退按钮禁用；DNN修正列为“尚无模型”。本批**不提供实际模型版本登记、训练任务执行、验证评估、发布或回退操作**，这些是后续批次，不以空壳按钮冒充已完成能力。
- 默认只在本地保存，不上传，不安装GPU软件，不连接A6000服务器。

## 数据安全及边界

- 实际保存路径显示在样本页底部，是Qt应用数据目录下`self_learning/samples.json`，与原方案库独立。
- 保存采用进程间锁+冲突检查+QSaveFile原子替换；写入失败、冲突、库损坏均不覆盖原文件。每库上限16MiB，超限整批拒绝且原文件不变。不要手动删除正在使用的`.lock`文件。
- 首批范围：油浸/箔绕/叠片硅钢/椭圆心柱/T形轭/双绕组/多层圆筒/50Hz/75℃；不接受圆形/长圆形等局部计算预览作为整机训练样本。
- 10%原有对比提示不是制造合格标准，也不是未来模型验证门槛。

## 建议验收点

1. 原有实测对比仍可打开；原方案计算与寻优结果不变。
2. 保存一条全空标签草稿，重开仍在，训练包导出仍禁用。
3. 补一项实测和来源后保存；该项计数增加，其余留空，训练包导出可用。
4. 填负损耗、0阻抗或文字数值，保存被拦截；0温升可保存。
5. 相同文件重复导入不重复计数；冲突文件提示错误且原数据不变。
6. 修改样本后切换或关窗提示放弃/取消；取消保留编辑，确认放弃恢复原值。
7. 没有模型时仍显示“尚无模型”，不能启用或用虚构修正值参与寻优。

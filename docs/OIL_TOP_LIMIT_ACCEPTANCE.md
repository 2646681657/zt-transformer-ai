# 油顶层温升限值可见性：人工验收

## 本批改动

- 设计输入“一般/专业模式”的“三 温升限值”均显示油顶层温升限值，不再只在非晶配置显示。共享参数表也用于方案参数弹窗。
- 名称不可编辑，限值可编辑；备注及悬停说明明确用于方案校核/筛选，不改变温升计算值。沿用原规则：限值≤0不校核此项。
- “性能要求”的温升限值摘要把“油面”更正为“油顶层”。真实油面温升结果仍使用“油面”名称，不混改。
- 继续使用现有 oilTopTempRise_K 字段、默认60K、会话读写及校核链路；不修改温升公式、不开放未支持结构。现有方案库文件仅保存CalcInput，不保存性能限值；本批不新增持久化字段。重新导入方案库时使用当前会话的限值，不能声称恢复了文件中的限值。

## 人工验收位置

1. 关闭旧程序，从桌面快捷方式重启。在已支持的椭圆叠铁芯配置，检查“三 温升限值”新增的可编辑值；切换一般/专业模式均应可见，参数名称不可改。
2. 修改为55K并进入计算，检查“性能要求”摘要及方案参数弹窗中的55K；在方案选择的参数弹窗修改后确认，再次打开该方案应保留所改值（当前会话内）。修改后取消应保持之前值。不要把关闭重启或导入方案库后的值作为本批文件持久化验收。
3. 查看“性能要求”摘要，应该显示“油顶层”，不是“油面”。
4. 对同一个已能成功计算的方案记录油顶层温升R，分别把限值设置为明显低于R和高于R的正数。单方案校核的油顶层超限项应随之变化，实际温升不变。其他损耗/阻抗等超限项可能仍存在，不保证整体方案通过。
5. 寻优使用很低的正限值时，应按新限值过滤；放宽后重新寻优，观察筛选变化（其他约束仍生效）。不要用不同寻优结果的温升变化判断公式是否修改。
6. 可选：0K沿用原有不校核语义；非数字或留空在计算/确认时应被已有数值校验阻止。未支持配置仍不能计算。

只编译和静态复核，不新增/运行测试程序。界面、存取及筛选效果由用户验收，通过后上传分支并创建面向dev的PR，不自动合并。

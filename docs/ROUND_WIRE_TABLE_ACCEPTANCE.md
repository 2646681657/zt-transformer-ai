# 计算单圆线表限定支持与人工验收

## 本批范围

基于 `SB20-M-630-10计算单.xlsm` 的原公式及已保存外部表缓存，补齐高压圆导线分支。不是增加铁芯形状算法，其他铁芯形状、两段高压线圈等既有限制不变。

随项目提供的线规表有57条规格，裸直径0.45～2.75mm，裸直径、绝缘后直径、增重百分比与计算单外部缓存的Sheet1 O49:Q105逐项一致。外部原始文件 `计算用数据表（椭圆）.xls` 尚未提供，缓存表没有区分材料和绝缘等级的元数据，因此不宣称适用于所有圆线材料或绝缘等级。

首版只允许有效表内精确规格。原Excel LOOKUP会向下取档，本程序有意收紧：不向下取档、不插值、不越界。数据库导入后仍要求规格升序、唯一，所有直径、绝缘后尺寸及增重数据均为有效正数，且绝缘后尺寸大于裸直径；无效表整体禁用圆线。

## 程序改动

- 设计输入第五节增加“高压导线形状”和“圆线裸直径(mm)”下拉框。圆线模式用同一裸直径填写宽厚并锁定这两个格，绝缘种类显示“圆线表（计算单缓存）”，增厚由表值计算并只读。
- 切回扁线恢复当前会话中原扁线宽厚、绝缘种类及自定义增厚。切换只更新固定行，不重建表格或改变行数。
- 旧方案仍按宽=厚识别圆线。不受支持的导入直径保留原值并显示“未收录”，不能静默换成另一规格计算；须主动选择支持规格。
- 引擎独立校验圆线表和规格，非界面调用也不能绕过限制。
- U15圆截面积先取三位小数，再乘并绕×叠绕得到AA15；电密、电阻、裸重量沿用既有公共链路。
- X14/Z14取表内绝缘后直径；Z21取表内Q列增重率，按已取整的W21计算并取整。
- 圆线AA45/AC45在原表为空，数值结果按0。AB48高压热负荷仅用Y20/AC47，不再带入扁线附加损耗。
- 圆线L10采用ROUND((Y20+AH20)*(1+J10),0)。低压附加损耗输入不进入此处，但仍沿用既有低压热负荷口径，AJ45/AS45区别未在本批推测或修改。
- 引擎材料成本和报价既有圆铜/圆铝加工费分支保留，绝缘重量更新后自然传递至材料数量。铜/铝密度、电阻及价格差异沿用原表，不自行新增绝缘表分类。
- 结果明细及设计结果表增加实际导线形状、裸直径、圆线表增重率、数据适用说明和圆线附加损耗说明。说明来自本次结果快照，不读取后来修改的输入。

## 人工验收位置

先关闭旧程序，再从桌面ZTBLD启动。

### 1. 设计输入第五节

1. 默认扁线宽2.05、厚5.52及绝缘选择保持原行为。
2. 选择“圆线（计算单表）”，从下拉框选择2.00mm：宽厚均为2，不能手填；增厚应为0.12mm，绝缘后直径说明为2.12mm，增重说明为1.44%。
3. 改选其他表内直径，宽厚和绝缘说明同步更新；连续切换不得出现表格重建、行数变化引起的剧烈抖动。
4. 切回扁线，原宽厚和绝缘种类恢复。另选自定义增厚，手填0.23后切换圆线，再切换普通/专业模式后切回扁线，应仍为0.23，原宽厚也保持。
5. 扁线模式手填宽=厚后计算，应提示改选圆线表规格，不自动切换。

### 2. 计算结果的绕组与温升明细

在满足其他既有计算边界的方案中采用2.00mm圆线：

- 高压单根截面U15应为3.142mm²（数学公式取三位，并非运行本程序得到的测试值）。并绕/叠绕均为1时AA15同为3.142。
- X14、Z14均为2.120mm，实际增厚0.120mm，增重率1.44%。
- Z21应等于ROUND(W21×1.0144,0)，注意使用界面显示的已取整W21。
- AA45、AC45均按0显示，附有原表空值说明；AB48应等于ROUND(Y20/AC47,1)。
- 杂散修正前损耗合计应等于高压电阻损耗+低压电阻损耗；L10最后取整到整瓦。
- 在专业模式修改低压附加损耗时，圆线L10不直接增加该项，低压热负荷仍会变化。切回扁线时则恢复原损耗合成方式。
- 如因既有几何、温升、油道等边界拒算，应按具体提示处理；本批不会为了让任意圆线方案可算而取消其他校验。

### 3. 方案保存、回显与边界

1. 保存一个表内圆线方案，重新打开：形状、直径及结果说明正确，不能回显为QZB固定增厚。
2. 导入宽厚同为2.05、2.0000001或大于表上限的方案：保留原值，显示未收录并禁止计算；切换普通/专业模式或保存后再次打开仍须保持未收录，不能因显示舍入变成2.00；主动选表内规格后才可进入计算。
3. 对比原扁线方案，本批不应改变其原有数值结果。
4. 检查方案明细、设计结果表以及材料报价：圆线说明一致，数量引用绝缘后重量，不误称为固定增厚扁线。

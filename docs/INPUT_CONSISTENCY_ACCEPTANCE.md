# 输入一致性批：改动与人工验收

本批对应 CALCULATION_SHEET_AUDIT.md 的 A1、A2。只修改界面输入收集和结果数据传递，不修改电磁、温升公式，不增加其他铁芯形状算法。不新增或运行测试程序，效果由用户验收。

## 程序改动位置

- 设计输入页：统一收集型号、额定值、材料、分接及表格数值。完整型号无需先按回车，点击进入计算时提交；不完整型号、逗号小数、非法数值不再静默使用旧值。
- 方案选择页的参数弹窗：从该方案的实际容量、电压、分接及联结回显。点击确认始终读取当前控件并重算；取消不提交工作副本。
- 确认方案后的报价、性能比较、AI解读和文档导出：使用当前方案的额定值及参数。导出型号不再重复拼接 -M，成本清单使用当前方案的导线材料。

实现文件：qt-app/src/gui/widgets/ParamTableWidget.{h,cpp}、qt-app/src/gui/pages/OptimizeCalcPage.cpp、qt-app/src/gui/pages/EnterCalcPage.{h,cpp}。

方案弹窗的性能参数在当前会话中按方案保留；本批不改变既有方案文件格式，不能据此认为性能标准已随方案文件持久化。型号系列/标准表适用范围仍属下一批审查内容。

## 人工验收步骤

1. 关闭旧程序，从桌面快捷方式重新打开。设计输入页输入完整型号 `SB20-M-630/10-0.4`，将低压改为 `0.415`，不按回车直接进入计算。检查方案参数及导出窗口的默认型号是否使用 0.415，而不是旧值；完成后恢复 0.4。
2. 将型号低压写成 `0,4`，或将型号留在 `SB20-M-630/10-`；尝试进入计算，应提示格式错误且不进入计算。恢复完整型号后应可继续。
3. 进入方案选择页，打开方案参数弹窗，修改高压导线材料、分接级数/步长或完整型号，不先点击计算，直接确认。重新打开该方案，应保留所改值；结果应与同样输入先点击计算再确认一致。
4. 在弹窗修改参数后取消，重新打开该方案，原输入和结果应保持不变。将联结组别改为不支持的形式，或将数值单元格留空/填文字，计算和确认均应阻止提交并提示。
5. 确认修改后的方案，检查产品报价页和文档导出默认型号。材料切换为铝后，检查导出成本清单不再按原来的铜材料报价。可在性能比较页核对当前方案修改过的标准值。

仍需人工验收；编译成功不代表数值准确性或界面效果已经验收通过。验收通过后再推送分支并创建 PR，不自动合并。

# 高压圆线表内规格寻优人工验收

分支`codex/hv-round-wire-optimization`，基于已合并PR49的dev。沿用现有圆线表、引擎计算公式及内置材料价格，不改方案计算单弹窗布局。

## 程序改动位置

- 主设计输入：仍先选择“圆线（计算单表）”及有效表内规格，原圆线切换与查表联动保持不变。
- 计算主页 → 寻优计算 → 循环参数设置：新增“高压圆线规格”行，参与开关默认关闭，范围默认为相邻±1档，可设0..5档；步长固定显示“表内相邻1档”，不是毫米步长。
- 设置界面：显示实际规格上下界、档数和直径清单。表两端只取存在的档位，不越界、不补齐、不插值、不向下取近似基准。
- 寻优统计：列出本轮冻结的参与直径，圆线启用时裸线宽、厚说明为“由表内直径同步”，不误称为独立固定尺寸。
- 后台：圆线规格与原允许变量做完整组合，每次同步`裸线宽=裸线厚=表内直径`。现有引擎按对应表项取得绝缘后尺寸和加重数据，再完整重算截面积、排布、电阻、损耗、温升及材料成本。

## 保护与口径

- 当前为扁线时启用圆线规格，阻止保存/启动；不会自动把扁线改成圆线。
- 当前为圆线时，两个高压扁线宽/厚开关必须关闭；允许铁芯直径、直线段、低压匝数、高压层数、低压箔厚及箔宽与圆线规格联合寻优。
- 当前圆线基准须精确匹配完整有效的表；空表、错误排序/重复档、绝缘尺寸或重量数据无效、未收录基准均不生成候选，不以近似直径替代。
- 每次启动重新按当前输入和当前表生成参与直径，不复用上次缓存；只持久化参与开关和±N档设置，不把旧直径清单当作当前规格表。
- 组合数按实际档数相乘，单轮仍不超过100000组合。关闭新增开关时，原八变量搜索行为不变。
- 成本仍以内置基价材料合计（含油箱）最低选优。订单和标准冻结，不放宽约束，不把未校核项称为全部合格。

## 建议验收

1. 关闭旧程序，桌面重新启动。循环参数共九行，新圆线参与首次默认关闭，旧设置保留。
2. 设计输入选择圆线表中间的有效规格。固定其他八项，只开启圆线±1档：实际清单为当前规格和上下各1档，共3组合。±0档应为1组合，取消参与也保持当前直径。
3. 选择表最小规格并搜索±1档：只应有最小档与上1档，共2组合；最大规格对应只取最大档与下1档。未导入外部表时，内置最小档0.45 mm应参与0.45、0.50 mm；最大档2.75 mm应参与2.63、2.75 mm。范围改大后按实际存在档数计算，不补出表外直径。
4. 原四项默认范围参与、圆线实际3档且低压箔两项固定时应为405组合。只开启低压箔厚±1步和圆线3档时为9组合。高压扁线宽厚必须关闭。
5. 在方案表核对所有圆线候选的高压裸线宽=厚，且均来自设置所列清单。查看不同规格方案的绝缘后尺寸、排布、电阻、损耗、温升、成本变化；部分输出有舍入，不保证每一显示值都变化。
6. 方案表材料合计升序最低值与统计一致；实际引擎计算=入库+计算失败+约束剔除；停止后计划=已处理+未评估。圆线搜索不应出现“扁线宽=厚”预检剔除。
7. 保存后重开程序检查圆线参与和范围保留；改变基准规格后界面与本轮统计清单重新生成。取消设置不改变旧配置。
8. 扁线基准启用圆线、圆线基准启用扁线宽厚、未收录规格/无效表或超100000组合时应明确拦截，不能静默改规格或线型。
9. 运行中快速计算、载入和修改候选保护仍有效；结束后查看方案计算单弹窗布局不变。保存并重载圆线候选后仍保留同一直径与订单指标。

实际效果由用户人工验收。不创建或执行自动测试、测试程序或GUI自动化；只做Release编译和独立只读审查。验收前不上传或创建PR。

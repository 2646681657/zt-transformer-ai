# T形轭宽90补充片叠厚：自动/手工模式与人工验收

## 程序层面改动

- `CalcInput.h`：新方案默认自动；原宽90手填值仍独立保留。`SchemeStore.h`保存模式，旧方案没有模式字段时保持手工，不能悄悄换成自动。
- `ParamTableWidget.cpp/.h`：普通“四 铁芯参数”中增加模式下拉及实际叠厚。自动只读、手工可编辑；在同一次编辑中切换回手工恢复之前有效的手填值。专业模式的宽80、宽60仍手填，不重复显示宽90输入。模式切换只更新单元格，不重建整表。
- `ElectromagneticEngine.cpp/.h`：自动时恢复计算单F20椭圆分支，使用实际F19片宽，不固定假设90mm；减去前11级已取整叠厚之和，最后按Excel ROUND取整。宽80/60继续使用Sheet1 D17/D18手填值，不替换成G20/H20公式。无解、负自动叠厚或负/非有限手工叠厚拒绝计算。
- `CalcResult.h`、`EmResultPanel.cpp`和打印：显示模式、实际F19片宽、实际采用的D16叠厚。输入预览、推荐匝数及主计算共用铁芯几何逻辑。

## 计算单依据

只读核对 `SB20-M-630-10计算单.xlsm` 的计算单F19/F20、M20/O20/R20及前11级G18..S18，Sheet1 B16/D16和D17/D18。Sheet1 D16引用F20；D17=1.5、D18=2手填。原表F20缓存为4mm，不表示本程序已运行确认该值。

设w=实际F19，acc=前11级叠厚之和。w=0时为0。否则先计算t=sqrt(M20²-(w/2+O20)²)。t≤R20时采用t，否则采用sqrt((H12/2)²-(w/2)²)+K12/2。自动叠厚=ROUND(采用高度-acc,0)。保留原几何中M20两位、O20/R20整数及各级叠厚的既有取整，不将曲线、截面或重量另行猜测。

自动值不是提示值，而是实际参与心柱/铁轭截面、磁密、重量、损耗及后续温升/成本链的输入；推荐低压匝数也随截面更新，但实际低压匝数仍不自动改写。自动模式保存的是模式和手工备份值，几何改变后重新计算自动值。手工模式保存实际手填值。

## 用户检验位置和项目

关闭旧程序，从桌面ZTBLD快捷方式重新打开。

1. 普通“四 铁芯参数”：新方案应默认自动，叠厚只读；结果“铁芯”页和打印显示自动、实际片宽、实际采用叠厚。相同原样本输入可对照F20缓存4mm，不同几何应按上述公式核对。
2. 改铁芯直径、直线段长或椭圆角：自动值按取整公式更新（小改动可能仍取同一整数）；计算结果D16应与输入预览一致，不用旧4mm。核对心柱/铁轭截面、铁芯重量、磁密、空载损耗及推荐匝数是否使用相同新截面。
3. 切手工填5.5mm，重新计算：实际采用5.5mm；切自动再切回手工，应恢复5.5mm。修改几何时手工叠厚不应被自动覆盖，但其他几何/截面当然仍变化。
4. 专业模式“七 铁芯工艺”：宽80、宽60仍可手填，模式切换不更改这两项；没有另一份宽90输入。宽80/60改变不会进入F20减项，但会影响总截面及其他后续结果。
5. 分别另存自动/手工方案后重新加载，核对模式和有效手工备份值恢复。旧方案应保持手工及原叠厚；不要覆盖原始对照方案。切换普通/专业模式和方案参数弹窗，核对回显和计算一致。
6. 自动几何无解/负叠厚应显示不可用并阻止进入计算，不回退旧值或强制置0。手工填负数、非数字也应拒绝。非椭圆及其他已禁算结构仍保持限制。
7. 重新计算后结果/打印刷新；仅编辑输入不应把已有方案结果冒充新计算结果。屏幕不应因模式或其他选项切换而重建抖动。

按用户约定，仅编译、静态复核及只读公式核对，不新增/运行测试程序，不修改或重算Excel。程序效果由用户验收后再推送、创建PR，不自动合并。

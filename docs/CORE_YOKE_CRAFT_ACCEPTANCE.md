# 心柱与铁轭独立工艺系数：人工验收

## 依据与改动

只读核对SB20-M-630-10计算单.xlsm：Sheet1 T25/W25均保存1.23；T26公式为 `ROUND(T25*I26*P23+W25*O26*U23,0)`。本批不执行宏、不重算或修改工作簿。

- 设计输入“四 铁芯参数”分别显示心柱、铁轭铁损工艺系数；两者可编辑，名称不可编辑。接缝数移至下一行，仍使用原绑定。
- 保留coreLossCraftCoef字段作为心柱系数，新增yokeLossCraftCoef作为铁轭系数。两者均须为有效正数。
- 引擎分别计算心柱、铁轭铁损分项；分项不提前取整，相加后保持原0位取整。两系数相同且其他输入相同，空载损耗与上一版一致。
- 结果“铁芯”、打印输出和计算单配置关联显示各自实际系数；结果及打印增加心柱、铁轭铁损分项。显示分项小数仅为阅读格式，计算用未取整分项。
- 新方案库保存两个系数；旧文件缺少新字段时沿用旧coreLossCraftCoef，不能强制回到1.23。存在但非法的新字段拒绝计算，不视为旧文件迁移。
- 保留已验收的油顶层限值、曲线越界保护；不扩展其他铁芯形状算法。

## 请检查的位置和效果

1. 关闭旧程序，从桌面快捷方式重启。一般/专业模式“四 铁芯参数”出现两个系数，默认均为1.23；参数名称不能改，接缝数仍能正常编辑。
2. 同一个能成功计算的输入，两个系数均为1.23，比较上一版空载损耗、空载电流、阻抗、温升。结果“铁芯”和打印的实际系数及分项应一致。
3. 只把铁轭系数改为1.30，保持其他输入及心柱系数不变：铁轭铁损分项改变，心柱分项不变；总空载损耗按两个未取整分项相加再取整。结果取整可能掩盖极小改动，因此用明显不同的系数验证。
4. 反向只改变心柱系数，铁轭分项不变。空载损耗变化会影响相关温升和方案筛选，这是预期传播；空载电流公式本批未改。
5. 在方案参数弹窗修改两个系数，直接确认后重开应保留；取消修改不提交。保存新方案库再导入，两个不同系数应保留（方案库仍不保存油顶层等性能限值）。
6. 导入原单系数的旧方案文件，两个系数都应等于该文件原系数，特别核对原系数不是1.23的文件。重新保存后应含两个字段；本批不自动覆盖旧文件。
7. 系数留空、文字、0或负数，计算/确认应被阻止；导入显式非法新字段不得用默认系数继续计算。曲线越界限制继续生效。

# Dd/Yd非标完整计算与保存验收

日期：2026-10-15；分支`codex/dd-yd-custom-calculation`，基点`57db126ff240dbd17ce8cd636e3f4c24ea461e6a`（已合并PR75）。本批是用户确认的有限扩展，不新增接法寻优维度，不迁移其他心柱/铁轭/绕组结构算法。

## 程序改动位置

- `ParamTableWidget.cpp/.h`：统一识别Dyn11/Yyn0/Dd/Yd；Dd/Yd完整收集只允许非标手工指标模式。两侧布尔量分别写入，低压d接不再被强制写为星接。加载已有输入、旧精确标签及下拉选择均正确回显。未知接法和未支持钟点数仍阻止计算。
- 同文件内置标准匹配：明确仅Dyn11/Yyn0有对应列，与“当前是否允许计算”独立。Dd/Yd不得借用Dyn列；内置模式无论自动预览还是交互确认都在计算入口直接阻止，不进入“人工确认后继续”的回退。
- 同文件设计输入页：Dd/Yd在非标模式下可生成原有铁芯全链预览及低压匝数建议。实际低压匝数仍手工输入，推荐值不自动覆盖。未选非标时保留基础相电量预览，并提示完整计算及保存须选择非标。
- `OptimizeCalcPage.cpp`：方案回填使用规范Dd/Yd标签，保存提示与新范围一致。
- `EnterCalcPage.cpp`：方案库载入前按每个方案自身保存的指标来源检查适用范围，不用当前页面的来源模式误判。
- `CalculationApplicability.h`：共享入口增加低压d接仅限非标的范围限制；其余结构、50Hz/75℃等限制不变。
- `BasicParamsImporter.cpp`：参数表导入能识别不带钟点数的Dd/Yd；保持带数字未知接法供校验拒绝，不能将Dd0/Yd11截成Dd/Yd。导入不会自动切为非标模式。

现有`SchemeStore`已经保存高压D接、低压星接两个布尔量以及性能指标快照，无需改变JSON结构。接法名由这两个布尔量回显，不丢失低压d接。

## 计算边界

本批没有改动`ElectromagneticEngine.cpp`、数据库或寻优坐标。复用已经存在的星/三角基础电量及其下游公式：相电压→匝电压→高压分接匝数/磁密，及相电流→电密/电阻损耗/阻抗/温升。已有圆/扁线、铁损曲线范围等校验继续有效。

“允许计算”不等于某组输入必然有有效结果，也不等于该方案已通过制造与试验验证。尤其从Dyn/Yyn切换至Dd/Yd后，保持低压18匝时匝电压升高，可能使磁密超出材料曲线范围而被拒绝。不能为让结果出现而静默钳制磁密、沿用旧结果或自动修改匝数。

非标只表明使用人工指标，不保证继承来的数值适合新接法。请人工核对空载/负载/总损耗、阻抗、空载电流、允许偏差和温升限值。不得把已有Dyn指标保留显示理解为Dd/Yd标准已匹配。AJ45/AS45等历史口径问题、储油柜等未接入项不在本批解决。

寻优会继续使用用户选定接法，搜索空间从基准输入复制两侧接法，不跨接法搜索。寻优原有低压匝数搜索规则不变；“不自动修改匝数”指手工编辑/预览不会替用户覆盖实际匝数，并不是取消已有寻优变量。

## 人工验收位置与操作

### 1. 设计输入页

1. 型号`SB20-M-630/10-0.4`，50Hz，原有支持结构。先保持内置模式，选择Dd或Yd：两行相电量仍可看，但进入计算及保存必须提示改为非标手工指标，不能弹出允许借用原标准继续的选择。
2. 选择“非标（手工指标）”，逐项核对性能指标。Dd/Yd下拉、说明及标准来源提示应清楚，无“已匹配内置标准”的误导。
3. 低压相电压应为400V、相电流525A；Dd高压相电压10000V、高压相电流21.00A，Yd为5774V、36.37A。实际低压匝数应保持原值。
4. 若需要接近原Dyn匝电压，可先查看低压匝数建议，再由你决定是否手工采用（当前样例建议通常约31匝，不是强制设计值）。检查匝电压、磁密、高压匝数、电密、损耗和温升是否随有效输入刷新。
5. 保存为“我的方案”，再载入：Dd/Yd、非标模式、手工指标和实际匝数应保留，不变回Dyn/Yyn。
6. 切回内置模式时应被告知当前接法无对应列，保留原非标选择；切回Dyn11/Yyn0后，可按原确认流程回到内置匹配。

### 2. 方案选择页的计算单弹窗

1. 第3行C3接法下拉应显示“Dd（非标）/Yd（非标）”；F3选择“非标”，核对第9行的负载、空载、空载电流及阻抗指标。其他限值/偏差仍在原有折叠区，不新增布局。
2. 第8行AH8实际低压匝数由你修改。输入有效后检查第4行AC4匝电压、第6—8行相电量/匝数、第16行电密/磁密、第20行电阻损耗及后续阻抗温升。
3. 自动计算成功后确认、重新打开：接法和指标保持。改为另一接法后取消，重新打开应保持此前确认值；不能写回取消的改动。
4. 内置/来源待确认状态下选择Dd/Yd，仍阻止确认。若显示旧结果仅供查看，不得把它当作新接法结果。

### 3. 导入、范围与回归

1. 非标Dd/Yd方案导出JSON再打开，模式、接法和匝数应一致；在当前页面处于内置模式时打开非标方案，也应按文件自己的指标模式判断。
2. 参数表导入Dd/Yd后应回显该接法，但不得自动改为非标；仍需你选择来源、核对完整型号与各项指标。未支持的带数字接法不能冒充Dd/Yd。
3. 圆形、长圆形、同心柱轭、分段式等仍按原范围阻止；无新算法时不借用椭圆/T形轭/圆筒式结果。
4. Dyn11/Yyn0的内置表联动、保存、取消与重开保持原行为。可小预算检查寻优仍保持选定接法，本批不要求长时间寻优验收。

未创建或运行测试程序、未执行GUI自动化。Release编译成功；独立静态审查未发现重要可操作问题，核对范围包含两侧接法、非标门禁、标准列排除、保存回填、导入边界及寻优接法固定。2026-10-15用户回复“验证通过”，本批人工验收通过，进入提交、上传及PR归档。

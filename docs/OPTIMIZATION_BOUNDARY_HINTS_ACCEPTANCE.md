# 寻优最低成本方案触边提示人工验收

本地分支 `codex/optimization-boundary-hints`，基于已合并PR55的dev。增加观察搜索范围是否可能限制当前最优方案的提示，不修改计算引擎公式、成本口径、筛选约束、网格范围、细搜中心或停止规则。

## 程序改动位置

计算主页 → 优化计算 → 寻优统计：新增“最低成本可行方案触边提示（本轮冻结范围）”。

- 用本轮后台优化器返回的最低材料成本可行方案，不是当前点击的行，也不受后来编辑方案或设置影响。最低成本并列时保留遍历先遇到的方案，不汇总所有并列候选。
- 逐项检查铁芯直径、直线段长、低压匝数、高压总层数W12、低压箔厚/宽、高压扁线裸宽/厚，报告达到上限或下限及值。只检查实际非零范围；取消参与或范围0不算触边。
- 使用与搜索相同的整数网格坐标，连续量在多轮细搜中仍相对原冻结边界判断，不用显示值舍入或浮点近似决定触边。不会误把内部细搜邻域左右端点当作原搜索边界。
- 圆线单独检查本轮冻结参与规格清单的最小/最大直径，至少两档才判断；这不是完整线规表端点。圆线宽厚同步，不另报高压扁线宽厚触边。
- 硅钢牌号属于分类选择，不按名单顺序判断上下限；仅牌号参与、其他量固定时明确无可判断的尺寸/规格方向。
- 无可行方案时“不判断”，全部固定/零范围或圆线只有1档时“不判断”；有搜索方向且未碰端点时才显示“未达到端点”。
- 人工停止或提前结束时，仅针对已评估可行候选报告；触边不保证范围外一定更优，未触边也不证明全局最优。只建议人工核对是否扩大范围，程序不自动扩展、补算或放宽约束。

## 建议人工验收

1. 关闭旧程序，从桌面重新打开。完成寻优后打开“寻优统计”，确认新提示区存在，旧数量、成本、价格说明和搜索范围仍保留。
2. 固定全部变量（或参与但范围0），使用能计算且通过已启用约束的输入：应显示“无可判断方向”，不能把固定值同时报上限和下限。仅开启硅钢牌号寻优时同样不按牌号顺序报触边。
3. 只开铁芯直径或低压箔厚，范围±1步、其他变量固定，用单轮网格核对最低材料成本候选：若该候选值等于原上/下界，提示方向和值应一致；若为中间值应未触边。并列时以先入库的最低原始成本候选为准，表格显示舍入后相同不一定代表真实成本并列。
4. 用多轮细化核对最终最低成本候选与原始上下界，不把每轮局部邻域端点算触边；中间细分小数不能因显示舍入碰边就被报为触边。
5. 使用有效圆线基准，仅开启圆线规格搜索：两档以上时，最优直径在参与清单最小或最大档才提示对应端点；不能同时报高压裸宽/厚。范围0或实际只有1档时不判断端点，也不制造表外档位。
6. 人工停止较大搜索后，统计仍提示仅已评估范围，未处理候选不推断；若全部候选均被现有约束剔除，应显示无可行方案、不判断，不得称未触边或0成本最优。
7. 改循环参数或点击其他方案，上一轮统计仍基于上一轮冻结范围和原最优候选；改变价格、约束、范围必须重新寻优，提示不会擅自扩展范围或重算。

不创建或运行测试程序、自动测试、GUI自动化，不启动程序代验收。只做Release编译和独立只读静态审查。验收前仅本地提交，不上传或创建PR；保留独立预览、旧程序与旧快捷方式备份。

# 低压箔厚、箔宽寻优人工验收

分支：`codex/lv-foil-optimization`，从已合并 PR47 的 `dev` 开始。

## 程序改动位置

- 计算主页 → 寻优计算 → 循环参数设置：新增“低压箔厚(mm)”“低压箔宽(mm)”两行，可分别选择参与/固定，编辑步长和 ±N 步，实时显示搜索上下界和全部组合数。
- 新变量首次默认固定，保持旧搜索组合数。默认箔厚步长 0.05 mm、±1步；箔宽步长 5 mm、±1步。勾选后生效，取消参与保留设置。
- 寻优统计：增加两项冻结的基准与实际搜索边界。原实际计算、入库、计算失败、约束剔除、未评估、成本及未校核统计继续有效。
- 后台为六变量完整笛卡尔积网格，每个组合调用现有全链路电磁引擎，重新计算导线截面积、电流密度、电阻、绕组尺寸、重量、损耗、温升和材料成本。仍以已启用约束通过的候选中内置基价材料合计最低选优。

引擎公式、材料价格、订单容量/电压/联结组别/性能标准与偏差、方案计算单弹窗布局保持不变。本批不是多轮自适应或多线程寻优，不搜索高压导线尺寸。

## 参数校验

- 步数范围0..5，固定变量实际为0步；箔厚步长0.01..1.00 mm，箔宽步长1..50 mm。
- 箔厚、箔宽下界必须>0，上界及截面积必须为有限值；不能用无法改变基准数值的步长生成重复候选。
- 单轮最多100000组合，超过时阻止保存/启动并提示缩小范围。此限制仅防止组合爆炸，不是制造规格限制。
- 当前为围绕设计基准的尺寸网格，不是企业库存规格表；可制造性及可采购尺寸仍需人工核对，不能将所有约束通过理解为全部制造校核完成。

## 建议验收顺序

1. 关闭旧程序，通过桌面快捷方式重新打开。检查新增两行默认不参与；原四项范围2/1/1/1且参与时仍为135组合。
2. 原四项全部固定，只勾选箔厚，步长0.05、±1步：应显示3组合；以1.35 mm为基准时上下界为1.30～1.40 mm。完成后统计实际计算3；入库候选在方案表低压线厚列显示相应值。
3. 只勾选箔宽，步长5、±1步：应为3组合；以323 mm为基准时上下界为318～328 mm。其他变量保持基准。
4. 只勾选箔厚和箔宽，两项均±1步：应为9组合；没有计算失败或约束淘汰时有9行，若有淘汰以统计原因解释。原四项也按默认参与时应为1215组合。
5. 选择不同尺寸的已入库方案，核对截面积、电阻/损耗、重量、温升和成本随实际设计变化（部分结果有舍入，不保证每个显示值每次都变化）。将已启用约束设得较严格时，应按现有约束淘汰，不自动放宽标准。
6. 方案表按“材料合计”升序排序，最低值与寻优统计一致；实际计算=入库+计算失败+约束剔除；停止后未评估不能算作剔除。
7. 搜索下界<=0或组合数>100000时不能保存/启动；取消设置不改变原配置；保存后重开程序，两个新开关/步长/范围保留。
8. 运行中原有写入保护继续有效；结束后可打开方案弹窗，布局与上版相同。保存并重新载入候选后，箔厚箔宽及订单指标仍属于对应方案。

本批不创建或执行自动测试、测试程序或GUI自动化，仅Release编译与静态审查，由用户人工验收；验收前不推送或创建PR。

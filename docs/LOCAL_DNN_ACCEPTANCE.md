# 本地DNN第二批：训练、验证与独立预测

## 本批交付边界

接入真实CPU PyTorch训练，不是模拟进度。仍不提供生产模型启用、回退或寻优联动。模型保存为experimental、productionEligible=false；训练完成也可能不优于原公式，应以验证报告为准。当前没有企业实测数据，测试通过只证明程序链路可运行，不能证明业务精度、节省时间或降本效果。

## 入口与环境

进入计算页面 → 自学习管理 → 训练与模型（页面可滚动）。独立环境位于`D:/zt-transformer/zt-transformer-ai-main/build/self-learning-runtime`，不修改系统Python。已验证Python3.12.5、PyTorch2.14.1+cpu、NumPy2.5.2，CUDA未启用。

发行目录`build/learning/runtime.json`提供本机默认python.exe/trainer.py位置；用户也可用文件选择器指定，选择后保存到学习数据目录的runtime.json。新电脑须重新创建独立环境并配置路径，不直接拷贝虚拟环境。安装来源为[PyTorch官方CPU发行渠道](https://pytorch.org/get-started/locally/)，程序运行时不自动安装软件，也不上传设计数据。

## 操作流程

1. 在学习样本页建立或导入真实样本，保存已测项目和来源。缺失项留空。
2. 训练与模型页检查运行路径，点击“检查训练环境”。成功后才能训练。
3. 每个目标至少5个有标签的独立产品，才能进入训练/验证；不足目标跳过，所有目标都不足则不训练。这个数量只是运行门槛，远非足够的工程数据量。
4. 设置最大轮数，点击“开始本地训练”。后台子进程工作，界面仍可响应；取消按钮提交取消标记，超时只结束该训练子进程，不结束其他程序。
5. 使用人为构造或合成数据时必须勾选“使用测试/合成数据”。测试标识保存在模型和报告中，不会混入正式数据或变成生产模型。
6. 完成后在模型版本列表查看验证报告：各目标原公式MAE、DNN MAE、RMSE、验证样本数；完整JSON中有分组、归一化、权重和来源等记录。
7. 在样本页选中需要验证的样本，再到训练页点击“对当前样本独立预测”。结果显示在样本表的DNN修正列，带测试/独立验证提示，悬停可见模型版本。切换样本/模型、重新预测或失败会清除旧预测，不修改原公式值或寻优候选。

## 学习范围和验证含义

- 固定结构：油浸/箔绕/叠片硅钢/椭圆心柱/T形轭/双绕组/多层圆筒式/50Hz/75℃。
- 六项目标分别训练，学习`实测-原公式`残差；只使用明确列出的16项电气、几何、材料标识特征。不使用产品ID、实测标签、价格或合格指标作为输入特征。
- 未纳入特征的物理参数必须保持训练上下文一致；如硅钢牌号、连接方式、冷却参数或油道等发生未覆盖变化，应拒绝，而不是静默套用修正。
- 按规范化产品编号分组，重复产品不能同时进入训练和验证。归一化仅从训练集拟合。验证集用于选择最佳轮次，不是独立最终测试集；报告不构成上线精度证明。
- 独立预测要求特征处于该模型训练范围内；缺字段、版本/结构或上下文不匹配、权重或报告损坏均应拒绝。
- 原Qt交接包摘要作为生产方证据记录，Python另算完整交接文件SHA256。Python不重算C++物理引擎，不能用此摘要认证恶意篡改的生产方。

## 数据与任务文件

独立样本目录下`jobs/<UUID>/`保存冻结bundle.json、job.json状态、model.json、report.json。每次训练新建目录，不覆盖旧模型。取消/失败不进入已完成模型列表；进程中断遗留的孤立model.json不是可用完成产物。模型为有限数值JSON权重，不使用任意pickle加载。

## 建议验收

1. 默认路径可检查通过；关闭重开后手选路径仍保留。
2. 数据不足时不能训练，提示数量是运行门槛而非精度保证。
3. 有合适数据后能看到真实进度、取消状态和本地验证报告；界面无卡死。
4. 训练后启用/回退仍不可用；原公式、报价和寻优不变。
5. 模型或样本切换后没有旧预测残留；不支持的设计变化明确拒绝。
6. 测试模型始终显示测试标识，不应被当作企业实测结果。

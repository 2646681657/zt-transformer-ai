# 方案弹窗计算单布局验收

## 范围

只改变方案选择表行内“选择”按钮打开的弹窗；标题为“方案计算单 - 方案 N”。主设计输入页、方案表本身、输出打印页不改变。

`SchemeCalculationSheet` 使用单张12列网格，每行并排三个分区，每个分区每行容纳两组名称和值。上部为基本信息、性能与损耗、温升；中部为铁芯、高压绕组、低压绕组；下部为主空道与阻抗、油箱与成本、工艺参考。各区把输入和相关计算结果放在一起，产品型号和调压三数使用宽单元格。取消左右两条长列表及分隔条。保留正常字号，紧凑行高、绿白网格和行号；可滚动和最大化。不是Excel嵌入，不执行工作簿宏，也未复制或改变工作簿算法。

隐藏的原参数编辑器是唯一输入数据源，其行列及键绑定完全保留。紧凑单元格映射回原值，型号、下拉框及调压控件转交原有编辑与联动逻辑，并同步被原联动屏蔽信号的选择变化；不修改公共编辑组件。结果复用已有分组及参考提示，不额外推导计算值。修改输入后标记“上次快照 / 待重算”，成功计算后刷新；失败时保留带待重算标记的上次结果。编辑时只同步值，不重建分区，避免抖动。

原“计算 / 确认 / 取消”逻辑保留：计算只更新弹窗工作副本；确认校验重算后只保存当前方案；取消或关闭不保存。未修改计算引擎、方案筛选、参数联动或主输入页。

## 验收

窗口默认最大化到当前屏幕工作区（保留标题栏与任务栏），12列均匀伸缩形成三个等宽分区。分区标题居中，名称左对齐，数字右对齐；只调整排版，不修改数值、字号或算法。

1. 关闭旧程序后从桌面ZTBLD打开，进入方案选择，点击任一方案行“选择”。检查单张紧凑计算单、多区并排、铁芯/高压/低压同带排列、绿白网格和最大化；不应仍出现左右长列表。
2. 核对型号及参数对应所选方案，各区结果与该方案原结果一致；所有名称和计算值不能编辑。长名称、说明、计算依据可悬停看全文，单位随计算值保留。
3. 修改允许编辑的浅绿参数，查看顶部待重算标记；点击“计算”，成功后核对各区结果刷新；输入错误计算失败时不能显示为当前新结果。
4. 检查型号、导线形状/绝缘、硅钢牌号、调压三个数等已有编辑和联动；普通/专业模式的原参数范围保持不变，专业模式仍能滚动查看高级参数。
5. 修改后点“取消”或关闭，重开检查原方案未改变。修改后点“确认”，检查仅当前方案更新、选择按钮点亮，主输入和寻优基准不改变。
6. 回到主设计输入页及打印页，确认原布局不变。窗口较小时应能滚动，列宽自动适配，不发生选择时反复重建导致抖动。
7. 新打开弹窗应直接最大化，三列分区铺满可用宽度；点击标题栏还原/最大化时列宽自动适配。小屏幕列宽保留最小70px，空间不足时允许横向滚动，不强行缩小字体。

按用户要求不新增或运行自动化测试、测试程序或GUI自动化；Release编译和只读代码审阅后交给用户验收。用户验收通过后再推送创建PR。

# 方案弹窗计算单布局验收

## 范围

只改变方案选择表行内“选择”按钮打开的弹窗；标题为“方案计算单 - 方案 N”。主设计输入页、方案表本身、输出打印页不改变。

新增 `SchemeCalculationSheet` 展示组件：左侧为原参数编辑器的独立实例，右侧为当前方案的只读结果分区（铁芯、绕组、阻抗、温升、重量与成本、油膨缩）。使用绿白网格、行号、浅绿编辑区及浅绿分区标题；可拖动中间分隔条、调整列宽、滚动及最大化窗口。不是Excel嵌入，不执行工作簿宏，也未复制或改变工作簿算法。

原参数行列及键绑定完全保留；实例内委托和样式不作用于公共编辑组件。右侧复用已有结果分组及参考提示，不额外推导计算值。修改输入后标记“上次计算结果 / 待重算”，成功计算后刷新；失败时仍保留带待重算标记的上次结果，不将其当作新结果。

原“计算 / 确认 / 取消”逻辑保留：计算只更新弹窗工作副本；确认校验重算后只保存当前方案；取消或关闭不保存。未修改计算引擎、方案筛选、参数联动或主输入页。

## 验收

1. 关闭旧程序后从桌面ZTBLD打开，进入方案选择，点击任一方案行“选择”。检查左右计算单分区、绿白网格、可拖动分隔条和最大化。
2. 核对左侧型号及参数对应所选方案，右侧结果与该方案原结果一致；右侧及左侧参数名称不能编辑。长说明可悬停查看，结果说明自动换行。
3. 修改一个允许编辑的参数，查看右侧待重算标记；点击“计算”，成功后核对结果刷新；输入错误计算失败时不能显示为当前新结果。
4. 检查型号、导线形状/绝缘、硅钢牌号、调压三个数等已有编辑和联动；普通/专业模式的原参数范围保持不变，专业模式仍能滚动查看高级参数。
5. 修改后点“取消”或关闭，重开检查原方案未改变。修改后点“确认”，检查仅当前方案更新、选择按钮点亮，主输入和寻优基准不改变。
6. 回到主设计输入页及打印页，确认原布局不变。窗口较小时应能滚动/调整列宽，不发生选择时反复重建导致抖动。

按用户要求不新增或运行自动化测试、测试程序或GUI自动化；Release编译和只读代码审阅后交给用户验收。用户验收通过后再推送创建PR。

# 输出打印 AI 说明草稿：人工验收

日期：2026-10-15。当前代码分支`codex/core-lamination-preview`，功能等待人工验收。

## 本批改动

- 输出打印页的“AI 说明草稿”只发送当前已计算方案的关键输入和结果摘要，不再把整张打印计算单逐行发送。
- 摘要包含产品型号、额定值、联结组别、材料、主要铁芯/绕组输入，以及截面、磁密、重量、损耗、阻抗、温升和材料合计等计算结果。
- 提示模型用约200字简述；没有明确性能限值时不作达标判断，不编造或自行推算数值。
- 草稿请求上限为512 token，连续无数据传输的超时阈值至少180秒。AI方案助手、AI计算结果解读和AI方案对比沿用各自原有请求设置。
- 不修改电磁计算引擎、优化算法、其它AI功能或网络代理配置。

## 人工检查位置

桌面快捷方式 ZTBLD → 方案确认 → 输出打印 → AI说明草稿。

1. 确认草稿窗口显示“连续无数据180秒后超时”，成功后生成约200字的简短中文说明。
2. 对照当前确认方案，核对型号、容量、电压、材料和计算结果没有读到旧方案数据。
3. 检查模型没有把未提供的限值说成“达标”，也没有编造数值。
4. 对比AI方案助手或AI方案对比，确认其操作和请求未被这次改动影响。
5. 若请求仍超时，记录实际等待时间和完整错误信息；错误提示会恢复“开始分析”按钮，便于再次尝试。

本批不添加或运行测试程序，Release编译与静态审查结果在交付说明中报告。桌面程序更新后等待用户验收，通过后再提交和创建PR。

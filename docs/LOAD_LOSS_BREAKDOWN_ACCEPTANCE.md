# 负载损耗组成对照：人工验收

## 程序改动和口径

- 保存本次计算的低压附加损耗采用值、杂散系数J10、杂散修正前合计三个结果快照；结果页“绕组”、文本导出和打印显示相同快照，新增数值均用15位有效数字，不另加计算取整。
- 当前支持的扁导线范围内，修正前合计为高压电阻损耗+低压电阻损耗+高压附加损耗+低压附加损耗，最终负载损耗仍是合计乘(1+杂散系数)，最后取整到整瓦。系数0.11表示乘1.11，不是乘12，也不是直接填百分数11。
- 引擎最终公式原样保留；组成快照保留原宽厚相等时的附加项分支，不借展示更改分支或开放圆线。此分支在当前支持范围外，不作为本批验收范围。
- 低压附加损耗同一输入还在AK48热负荷中采用，因此影响低压绕组温升；通过既有总负载损耗也会影响油温升。它与“引线损耗仅记录未参与计算”不同，专业模式“九 损耗系数”增加只读作用说明及提示。
- 原表AJ45为0、AK48引用AS45的工艺口径待确认，本批只说明程序已有行为，不把它宣称为原表完全等价，不新增工艺假设，不改公式、输入值、校验、筛选或JSON文件结构。
- 输出只读取结果快照，改输入不计算时不混入新值；正常保存/导入仍仅存输入、加载后重算。

## 请检验的位置

1. 关闭旧程序，从桌面重启。专业模式“九 损耗系数”低压附加损耗旁应显示参与负载损耗和低压温升、原表口径待核对的只读说明；原参数值可编辑。
2. 用上一版相同正常输入计算，结果“绕组”、文本导出、打印均应新增低压附加损耗采用值、杂散系数和修正前合计，三处数值及单位一致。既有最终负载损耗、阻抗、温升和成本不变。
3. 核对合计与高低压电阻损耗、高压附加损耗、低压附加损耗的组成。旧分项显示精度与原值可能不同，用显示值复算时允许显示舍入误差；引擎无新增取整。最终负载损耗应是修正前合计×(1+系数)最后四舍五入到整瓦。
4. 可用正常输入副本将低压附加损耗从0改为100W再计算：结果应采用100W，修正前合计增加100W（其它输入不变时），最终负载损耗按已有系数增加并取整，AK48低压热负荷应改变。温升有取整，较小改动可能显示不变；是否超限仍由原规则判断。
5. 将系数设0再计算，最终负载损耗应为修正前合计取整到整瓦。改回原值并重新计算应恢复；不应把此系数误当百分数。只改输入不重新计算时三个新增结果保留旧快照。
6. 旧方案导入及方案参数弹窗重算仍使用同一规则，输入值保留；引线损耗仍未计入，不应因这批展示多加一次。

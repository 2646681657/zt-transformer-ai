# 高压端绝缘参考提示验收

## 改动范围

- `HvEndInsulationNotes.h` 只读本次计算结果的 AA31 和 AC32 快照，统一参考差额、状态和核对提示。
- 计算结果的“绕组”页增加参考差额（实际－参考下限）、参考状态和核对提示。显示值不参与比较，差额保留有效数字以避免微小不足被显示为零。
- 打印表及“导出计算单与成本清单”的计算单文本增加实际值、参考下限、差额、状态、符号说明和用途。打印窄列使用短提示。
- 结果文本、计算数据导出及“保存为自定义计算单”CSV 复用结果分组，包含同一提示。
- 未改动 AA31/AC32 计算公式、输入参数、结果有效性、方案合格约束或寻优筛选。分段圆筒式仍不开放计算。
- 参考下限只是原计算单提示，不宣称是通用工程标准；高于或等于参考值不代表绝缘合格。

## 人工验收位置

1. 关闭旧程序，从桌面 `ZTBLD` 快捷方式重新进入。执行一次电磁计算，在“计算结果 → 绕组”查看新增三行。
2. 按原计算单参数计算：低压箔宽323 mm、低压端绝缘17.5 mm，且高压总轴向高321 mm时，应显示端绝缘18.50 mm、参考下限20 mm、差额-1.5 mm、“低于参考值”，并提示不足1.5 mm需人工核对。
3. 保持其他参数不变，将低压端绝缘改为19 mm并重新计算；若高压总轴向高仍为321 mm，端绝缘应为20.00 mm、差额0、“等于参考值”。改为20 mm时应为21.00 mm、差额1、“高于参考值”，不显示“合格”。注意修改该输入本来就会影响窗高等下游计算，验收后恢复原值。
4. 查看打印表和打印预览；导出计算单文本、计算数据及自定义CSV，核对参考差额和状态与当前计算结果一致。成本清单不新增端绝缘行。
5. 确认低于参考值时不会因此拒绝电磁计算或增加寻优筛选条件；这只是提示，不保证该方案满足绝缘设计要求。
6. 若换选方案，提示应跟随该方案已计算结果，而非未重新计算的输入。

按用户要求，不新增或运行自动化测试；以Release编译、静态审阅和人工效果验收交付。

## 程序层面变化

方案选择 → 选择 → 原计算单第3行：

- C3受支持接法显示为Dyn11、Yyn0，缩短原“Dyn（Dyn11）”“Yyn（Yyn0）”在紧凑位置的文字。Dd/Yd及未知导入项仍保留未支持标识。选项悬停保留原完整文字。
- F3指标来源下拉显示为“内置表”“非标”“待确认”；实际UserRole仍为原StandardMode枚举，接法UserRole仍为原字符串。更改显示名不改变计算输入或保存值。
- F3下拉悬停显示本次完整适用状态，并说明“内置表仅自动匹配已有损耗标准，不代表完整国标认证”。同步到隐藏源控件和原生绑定单元格，由已有ToolTipChange镜像机制更新可见下拉；不会只写入不可见的备注行。
- 型号清空、未输入完整，或低压电压尚未回车提交时，F3悬停明确旧匹配状态无效并显示当前模式；无效型号提前返回路径也刷新提示。不修改原增量解析、数值联动或指标保存规则。
- 镜像下拉转交用户选择后，显式用源控件最终索引回显，回显时屏蔽镜像信号。源处理函数若因取消或不适用而阻塞信号回退，镜像仍以源为准，不产生第二次编辑。
- 主设计页保持原完整显示名，仅增加对应来源状态悬停说明；不增加或删除行。

## 静态核查范围与边界

| 核查内容 | 代码路径与结论 |
|---|---|
| 数据唯一来源 | 隐藏ParamTableWidget仍为接法/标准等实际输入源，镜像共享选项模型；下拉显示名不是保存值 |
| 名称/结果只读 | 原生单元格默认只读，输入绑定沿用源flags；有子控件的单元格不开放文本编辑 |
| 标准手工/自动联动 | 原applyModelLinkage、手改损耗转非标及切回内置前人工确认均保留 |
| 确认 | EnterCalcPage弹窗局部工作副本；确认前重新收集和计算，成功后写回该方案 |
| 取消/关闭 | 原reject路径和定时器停止路径不写回；本批未改该代码 |
| 未支持结构 | 仍由inputsReady和原参数校验拦截，不能按新显示名绕过 |
| 界面稳定性 | 不调用重建表格、不替换控件、不增加自动计算触发；回显索引使用QSignalBlocker |

以上为源代码静态核查，不声称已经执行GUI验收。心柱/铁轭仅能确认当前受支持的椭圆形/T形轭，其他结构仍待后续算法阶段。

## 人工验收位置

1. 弹窗第3行C3/F3查看紧凑显示名；展开下拉与悬停查看完整说明，名称/结果不可编辑。
2. F3悬停检查当前内置标准匹配状态；切非标后提示应变化。修改规格后提示也应更新，不能残留旧匹配结论。
3. 非标手工填三项损耗，切回内置时选“否”：下拉应回到非标，手工值不变。选择“是”才按原规则替换三项损耗；内置表不适用时拒绝并保留原值。
4. Dyn11/Yyn0切换并确认，再重开该方案，接法和来源模式应正确恢复；点取消或标题栏关闭后重开，不应保留未确认修改。
5. Dd/Yd、心柱其他形状、同心柱仍有未支持提示并阻止计算/确认。切回支持项后恢复，不能因镜像回显绕过原校验。
6. 原油道、材料、导线绝缘等下拉同样沿用源索引；连续切换、滚动、折叠/展开不应抖动或丢值。主设计页原完整显示名不变。
7. 清空或输入不完整产品型号后切换非标/待确认，F3悬停应说明旧匹配状态无效，不能仍声称当前规格已匹配；补全并提交后恢复当前实际适用状态。修改低压电压但未回车时也应提示尚未完整提交。

# 高压扁线裸线宽、厚寻优人工验收

分支 `codex/hv-flat-wire-optimization`，基于已合并PR48的dev。本批沿用现有引擎与内置基价，不改计算公式、制造标准、材料价格或方案弹窗布局。

## 程序改动位置

- 计算主页 → 寻优计算 → 循环参数设置：新增“高压裸线宽(mm)”“高压裸线厚(mm)”两行，参与开关、步长、±N步和实际上下界独立可配。
- 首次新增两项默认固定；默认步长均0.05 mm，范围±1步。步长允许0.01..1.00 mm，范围0..5步。保存到QSettings；取消不改变设置。
- 后台八变量完整笛卡尔积。有效尺寸组合重新计算绝缘后尺寸、线截面积、电流密度、匝数排布、电阻、损耗、重量、温升和成本；继续按原启用指标过滤并以材料合计最低选优。
- 寻优统计增加高压宽/厚边界、冻结线型及绝缘类型，以及“尺寸预检剔除”“已处理组合”计数。

## 线型与边界保护

- 当前为扁线时，候选宽=厚按引擎判定属于圆线，本批在调用引擎前剔除，绝不自动进入圆线算法。原因统计为“扁线宽=厚（禁止自动切换圆线）”。
- 当前为圆线且勾选高压宽或厚时，阻止保存/启动并提示取消两项参与。取消后允许原有其他变量寻优，圆线继续严格使用有效表内规格，不插值或取近似规格。
- 绝缘类型及增厚、铜/铝、并绕/叠绕、订单参数和标准冻结。本批只搜索扁线宽厚，不新增企业库存规格表；实际可制造规格仍需核对。
- 裸线宽厚下界必须>0，上界/截面积为有限值；过小到无法改变基准数值的步长不允许。单轮仍限100000组合。

## 统计口径

- 实际引擎计算 = 入库 + 计算失败/成本无效 + 约束剔除。
- 已处理组合 = 实际引擎计算 + 尺寸预检剔除。
- 计划组合 = 已处理组合 + 未评估。
- 预检剔除不计入计算失败，不计作未评估；同一组合违反多项约束时原因计数可重叠。
- 暂停/停止与已算范围内最低成本沿用上版行为；停止后的未评估部分不算淘汰。

## 建议人工验收

1. 关闭旧程序，从桌面重新启动。循环参数有八行；新增高压宽、厚默认固定，升级不改变原已保存的六项设置。
2. 前六项全固定，仅勾选高压宽，0.05 mm/±1步：3组合；默认2.05 mm基准上下界2.00～2.10 mm。仅勾选高压厚：3组合；默认5.52 mm基准上下界5.47～5.57 mm。
3. 前六项固定，高压宽/厚均±1步：9组合。原四项默认135组合并启用高压两项时为1215组合；再启用低压箔两项时为10935组合。
4. 核对方案表“高压线规宽/厚”；选择不同入库方案，查看排布、电阻、损耗、温升和材料成本变化。部分输出经舍入，不要求每个显示值每次都变化。
5. 在线型为扁线的主设计输入设置宽2.00、厚2.50 mm；其余七项固定，仅高压宽步长0.50 mm、±1步：计划3组合，宽2.50的那1组合应预检剔除，实际引擎计算2，已处理3，未评估0（无论剩余2个计算是否成功或约束通过）。不得出现该组合的圆线候选。
6. 主设计切换有效圆线表内规格，仍勾选高压宽/厚时应明确阻止启动；取消两项后原有变量搜索可用，不能将圆线自动变回扁线。
7. 搜索尺寸下界<=0、超100000组合时阻止保存/启动；保存后重开程序检查设置保留。运行中旧有快速计算/载入/修改候选保护仍有效。
8. 最低材料合计与表格升序最低值一致；暂停/继续/停止后以上统计等式成立。查看方案的计算单弹窗布局保持不变。

不创建或执行测试程序、自动测试或GUI自动化；只做Release编译与只读审查，实际效果由用户验收。验收前不推送、不创建PR。

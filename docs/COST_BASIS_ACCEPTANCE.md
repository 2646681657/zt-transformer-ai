只更正显示名称和说明，不修改任何价格、采购系数、计算公式、取整、成本字段、排序或寻优规则。共用CostBasisNotes说明供多个界面引用，其中不包含价格或计算代码。

- 两级表头上层为“内置基价成本”，保留列索引、数值排序、隐藏列和绿色主题绘制。表头悬停说明各自范围；排序下拉框、筛选、方案摘要和AI比较上下文同步更名，但方案存储键不变。
- 引擎选优依据仍是materialCost；内置基价为原代码值，不是实时市场价，不含报价费用、利润或税额。修改报价页价格不会改变引擎成本或选优结果。
- 结果“重量与成本”、文本导出和打印补上内置基价及含油箱说明；寻优结束摘要与方案比较同步说明口径。
- 设计页原“打开报价单”按钮实际只显示引擎材料明细，更名“材料成本明细”，弹窗明确“非报价”；函数和点击流程不改。
- 产品报价页常驻说明及导出文本标明可编辑报价参数口径；材料成本按报价价格重算，另计费用、利润和税额。设计页导出的成本清单使用持久化报价参数（无有效文件时默认值），同样标明报价口径，不和内置基价清单混淆。

## 请检验的位置

1. 关闭旧程序，从桌面重启。方案表两列显示“内置基价成本 / 材料合计”和“铁芯导线”；悬停表头查看范围。排序下拉框同样更名，列映射不变。切换“仅显示主要参数列”后，单列仍有完整两级表头；原绿色配色和数值排序应保持。
2. 同一方案与上一版比较，各成本数值不变；材料合计应包含结果页的硅钢片、高压导线、低压箔、绝缘油和油箱五项，不只是铜铁油。
3. 结果“重量与成本”、结果文本导出、打印预览及打印表CSV导出应显示内置基价说明；CSV导出的是打印表，不是方案表，方案库仍保存JSON。“材料成本明细”弹窗应明确非报价。完成寻优、筛选或比较两方案时，成本名称不再暗示是可调价格报价。
4. 产品报价页应看到常驻说明。临时修改铜/铝或油等单价，报价相关材料金额和报价随之重算；已有方案表及电磁结果中的内置基价成本不变，寻优选优依据不改变。报价导出的文本也应包含报价口径说明。验收后恢复原单价，不必保存改动。
5. 导出计算单与成本清单，前者材料合计为内置基价口径，后者注明报价参数口径。若未保存报价页临时改价，成本清单仍采用已保存价格（或默认值），这是已有行为，本批不修改。
6. 旧方案库导入/保存仍兼容原costCuFeOil/costCuFe等字段，不因显示更名改变数据；前批引线损耗未参与提示继续保留。

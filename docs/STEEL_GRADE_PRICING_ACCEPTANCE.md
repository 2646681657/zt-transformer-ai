# 按硅钢牌号定价寻优人工验收

分支 `codex/steel-grade-pricing`，基于已合并PR53的dev。保留默认17元/kg模式，新增按牌号自定义硅钢单价；铜、铝、油、油箱仍用原内置基价。只改变材料成本，不改变电磁公式、材料曲线、重量损耗系数、舍入规则、性能约束和搜索网格。

## 程序改动位置

- 计算主页 → 优化计算 → 循环参数设置：新增硅钢价格模式；“候选牌号及单价…”窗口同时显示参与牌号、片厚/曲线范围、单价。
- 自定义模式不猜测价格。每个参与牌号都必须明确填写有限正数，最多99999元/kg；未填、文字、零、负数、越界价格阻止保存/启动。关闭牌号寻优时，仍可为当前固定牌号定价。
- 候选选择窗口取消不改变本次设置，外层取消不保存；已输入价格按牌号保存，可跨模式保留，不因关闭牌号寻优而删除原勾选名单。
- 本轮开始时冻结价格表，候选只保存自身采用的模式、牌号和单价。寻优目标、细搜中心、成本排序、按牌号统计均采用该口径。
- 方案表改为“本方案材料成本”，成本单元格提示具体价格口径；成本明细、计算结果、打印和方案库对比显示自身价格说明。不同批次单价不同的方案可同时存在，但差额不能只归因于设计改善。
- 方案保存载入及弹窗自动重算保留候选价格。弹窗布局不增加价格输入项；若在弹窗改变牌号，自定义价格的绑定校验阻止沿用另一牌号单价，需要回循环参数设置价格并重新寻优。
- 新一次寻优切回内置模式时，对新候选恢复17元/kg；不会回溯修改已有候选。旧方案文件没有定价信息时按原内置17元/kg重算；显式自定义信息缺失或损坏不静默退回17。
- 报价页独立：不自动采用候选自定义价，调报价页价格也不改变候选冻结成本。

## 建议人工验收

1. 关闭旧程序，从桌面快捷方式重新打开。进入循环参数设置，默认内置模式；与原批次相同输入、范围和约束时，成本应与原版一致。
2. 改为自定义模式，打开候选窗口，留空参与牌号价格，确认应提示缺少有效价格；检查0、负数和文字也不能进入计算。关闭牌号寻优后，当前牌号同样需要填写价格。
3. 先只用当前牌号、固定所有尺寸，填写17元/kg：应与内置模式金额一致。再只改为30元/kg（仅验收示例，不是市场价）：相同牌号、相同输入下，重量、磁密、损耗、温升等物理输出不因价格变化；硅钢成本按原舍入后的计价重量×30，材料合计相应改变。
4. 开启牌号寻优，选2个有效牌号并分别填写单价；固定全部尺寸，单轮计划应为2组合。核对每个候选成本提示与统计中的冻结价格，不保证哪一个牌号一定更优，也不放宽不合格候选约束。
5. 保存一个自定义候选并载入，检查价格说明和成本保持一致；改变尺寸触发重算仍用该候选价格。只改变牌号应明确提示绑定不一致，不沿用旧牌号价格。
6. 修改循环参数中的价格后，旧候选仍显示旧价格，新一次寻优采用新价格。切回内置模式，新候选采用17元/kg；旧自定义候选不被修改。方案库对比显示两种口径及差额警告。
7. 重开设置检查单价保留；取消内层及外层窗口不持久化新输入。检查报价页仍按报价页单价独立计算，双方互不自动同步。

不创建或运行测试程序、自动测试、GUI自动化，不启动程序代验收。仅Release编译及独立只读静态审查。验收前只本地提交，不上传或创建PR；独立预览exe和旧快捷方式备份均保留。

## 来源与算法边界

只读核对源文件 `D:/zt-transformer/zt-transformer-ai-main/SB20-M-630-10计算单.xlsm`：

1. 原单AN14=`ROUND(SQRT((H12/2+B28)^2-(AJ12/2)^2)-AG12-4+K12/2,0)`，原表“线圈型式”!Y17引用它。完整表达式最后按Excel ROUND到整数；不预先舍入半径，也不将负根号钳位为0。固定扣减4mm的工艺依据待确认。
2. 当前支持椭圆形时，“线圈型式”20行片宽/叠厚均为0，Z20=0；21—35行按原单15级片宽与对应**几何叠厚**累计，非Sheet1片数取整后的实际叠厚。
3. 对当前弦高，以Z20:Z35近似LOOKUP，取“不大于弦高的最后一行”；累计值重复时取最后匹配。K20为弦高减该命中累计值。
4. K19在命中序号+1后再次对序号1—16近似LOOKUP取片宽；超过末序号按原表仍取末行，不外推新片宽。若原末行片宽为0，保留真实0，不能解释为制造条件已满足。

此前将K19/K20笼统称为“铁轭辅助量”不够准确。它们由**内排弦高与当前几何叠厚**查表得到，不是独立铁轭工艺输入，也不直接填当前80/60补充片参数或示例80/2。

新模块`ConnectionBarChordReference.h`只在有效方案请求详细快照后生成三项显示，不反馈现有电磁、损耗、温升、成本、整机合格或寻优筛选；默认寻优入口不采集。AK12截面参考与弦高参考按各自前提判断可用，互不作为计算门槛。

## 不可用处理

- 内排两项全空：三项均“未录入”；只填一个：“待补全”。
- 尺寸非法/非有限/≤0、根号内为负或非有限、弦高溢出：三项“不可用”并说明原因。
- 弦高可算，但缺少片宽/几何叠厚快照、存在负值/非有限值、累计值溢出，或弦高小于表首项0：保留可算弦高，K19/K20单独“不可用”。不排序原表、不钳位叠厚、不用0冒充缺失。
- 不单因参考不可用而把整机判失败；原算法自身的参数校验保持有效。所有参考都不是制造安全判断。

# 高压层数与每层匝数名称：人工验收

## 映射与范围

按现有引擎语义、用户确认范围修正显示，不修改原计算单文件或公式。

- W12 输入用于 W9/W10/W11 层分布、辐向尺寸、层间间隙和寻优总层数变化，名称统一为“高压总层数 W12”。旧 `hvTurnsPerLayer` 字段名与JSON键保持不变，默认15也不变。
- Y9 是 `INT(最高分接匝数/W12)+1` 的派生结果，原 `layerCount`/`hvLayers` 中存放的就是此值。结果原“每段层数”、方案表/比较原“高压线圈层数”改为“高压每层匝数 Y9”；结果及文本导出单位标匝/层，数值不改。
- 主设计输入与方案参数弹窗共用输入表；寻优当前值、设置、运行摘要及输入摘要同步W12名称。输入行增加两者区别的只读说明，W12至少2的校验提示同步改名，条件不变。
- 原始字段名、寻优范围字段及已有存储格式保留，仅注释澄清语义。不新增自动覆盖、不迁移旧文件、不改变损耗/温升/尺寸/成本、候选数量或排序。
- 历史验收文档中的旧名称记录当时版本，不批量改写；本说明及审查清单最新进度以新名称为准。

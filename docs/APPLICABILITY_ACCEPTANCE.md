# 适用范围批：改动与人工验收

本批承接输入一致性批，处理审查 A3/A4 及 B4 的固定假设提示。不修改电磁或温升公式，不推测其他截面算法。内置标准表只代表项目已收录数据，不构成标准符合性认证。

## 程序位置与规则

- 设计输入页顶部：默认叠铁芯、椭圆形、双绕组、多层圆筒式。卷铁芯、非晶、双分裂、两段线圈等可查看，但阻止计算。干式、低压线绕同样不能套用当前油浸箔绕链路。
- 设计输入表及方案参数弹窗的性能指标：初始化即按内置 SB20-M/SB22-M/SB13-M、标准容量、10kV、50Hz、叠铁芯双绕组和已支持联结匹配损耗值。未知系列不再回退 SB20 表。
- 不适用/无匹配时保留原损耗值，并在备注/提示中标明“需手工核对”。计算前明确询问是否已核对，默认选择不继续。不会把这些值宣称为当前规格的自动匹配结果。
- 同一规格手工修改或导入损耗指标后保留手工值；模式切换和重复计算不覆盖。换到新的可匹配规格时重新查表。阻抗及空载电流标准仍保留手工值。
- 频率新增实际读取与校验，非50Hz不能计算；非75℃折算不能计算。环境等级、环境温度、海拔仅记录，未参与温升修正，当前采用波纹油箱算法。
- 快速计算、寻优启动、方案弹窗确认和方案库重算补上入口检查。方案库包含不支持的线圈型式时在替换现有方案表之前拒绝导入。

实现位置：`qt-app/src/core/CalculationApplicability.h`、`ModelStdTable.h`、`StructureConfig.h`、`TransformerParams.h`、`BasicParamsImporter.cpp`；`qt-app/src/gui/widgets/ParamTableWidget.{h,cpp}`；`qt-app/src/gui/pages/OptimizeCalcPage.cpp`、`EnterCalcPage.{h,cpp}`。

来源状态只保留在当前会话，不改变既有方案JSON格式；重新加载方案会按当前参数匹配或重新确认手工损耗值。已有公式仍有绕组/温升分支缺口，不能把“通过范围检查”理解成完整算法认证。磁密曲线越界状态、导线圆线及后续温升分支仍待后续批次，不在本批声称完成。

## 人工验收

1. 关闭旧程序，从桌面重开，选择油浸式/箔绕进入设计输入。检查默认选型为叠铁芯+椭圆形+双绕组+多层圆筒式；默认 `SB20-M-630/10-0.4` 损耗标准为510/4960/5470W，阻抗仍是当前手工设置。
2. 型号改为 `SB22-M-630/10-0.4`、`SB13-M-630/10-0.4`，分别应显示460/4460/4920W、570/6200/6770W。回到 SB20-M，修改阻抗，切换型号检查不会覆盖阻抗。
3. 型号改为 `ABC-M-630/10-0.4`、`SB20-M-640/10-0.4` 或高压11kV，检查“未收录/不适用、需手工核对”提示和备注，原值保留但不被标成匹配标准。进入计算时应先要求手工标准确认；选择否应留在输入页。
4. 同一规格手工改空载损耗标准为550W，切换正常/专业模式再回来、进入计算、快速计算、打开方案参数弹窗，检查550W仍保留，备注为手工设置。变更到另一可匹配系列/容量后应重新查表；导入的明确损耗指标同样应保留为手工值。
5. 依次改选立体卷铁芯、平面非晶、双分裂、两段圆筒式、非椭圆形，点击进入计算和校验算单均应阻止并说明原因；恢复支持组合后可继续。主界面选择干式或线绕时同样应禁止当前计算。
6. 频率改60Hz、折算温度改80℃，应禁止计算；恢复50Hz/75℃后可继续。检查环境温度和海拔备注说明它们不参与温升修正。
7. 在方案选择弹窗重复未知系列/非标容量与手工标准检查，直接确认与先计算再确认应采用一致规则。加载既有方案库，检查不同容量的损耗标准按该方案匹配；不支持的线圈序号不能静默重算。

按用户要求不新增/运行测试程序，仅编译和静态复核，界面效果由用户验收。验收通过后才推送分支并创建 PR，不自动合并。

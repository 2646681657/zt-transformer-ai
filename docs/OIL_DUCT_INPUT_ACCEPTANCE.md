# 油道输入校验与布局提示：人工验收

## 原表依据与边界

只读核对SB20-M-630-10计算单.xlsm“计算单”X28:AJ34、AF10:AK10、AC47:AK48，未执行宏、重算或编辑工作簿。

- X30:X34为高压相间侧、Y30:Y34为高压端部侧；AG28:AG32/AH28:AH32对应低压两侧。界面旧称“宽/高”并不表示油道轴向高度，本批增加含义说明，不更改字段。
- AC47/AK47分别判断两侧尺寸为0与否，因此允许单侧停用，不能擅自把宽/高必须成对启用当成原表规则。
- AF10:AJ10及Z30:Z34的分段依赖端部侧停用状态，而散热又独立读取两侧。中间停用、后面仍启用或单侧启用时需人工核对。本批只提示，不宣称此类布局已经验证，也不重排、改值或禁算。
- 原表部分地方区分空白与0，现有程序数组使用数值0；本批不改分段公式，也不声称解决原表所有空白/0分支差异。输入空白不被默认为停用。

## 程序改动

1. CalcInput新增共享校验：高低压各5组宽/高都必须是有限且非负的数值，0仍表示对应侧停用。错误指出高/低压、组号及相间/端部侧。
2. 主界面输入收集、方案参数弹窗使用同一校验；引擎也在公式计算前校验，避免绕过界面。方案库预检通过共享范围检查拒绝非法油道数据，再决定是否替换当前表。
3. 专业模式“八 绕组工艺”新增只读说明。单侧启用或端部不连续布局不作为新增寻优剔除规则，结果“绕组”及文本导出显示具体提示，打印显示需人工核对或无提示项，并注明非合格判定。
4. 提示保留计算输入快照，输入修改后须重新计算才更新；“无提示项”不等于散热或结构合格。
5. 方案JSON显式非法数组项（文字/null等）不再回退有效默认数值，转为无效值供校验拒绝；显式非数组或超过5个元素同样拒绝。缺失字段及旧短数组继续沿用原默认补齐行为，不自动覆盖旧文件。
6. 不改正常输入的电磁、分段、几何、阻抗、损耗、温升、成本公式和取整，不扩展圆线、两段线圈或其他截面算法。

## 请检验的位置

- 关闭旧程序，从桌面重启。专业模式“八 绕组工艺”有两侧含义/停用说明，说明不可编辑；原油道值仍可编辑。
- 使用此前可成功计算的输入，所有油道为原值，损耗、阻抗、温升和成本应与上一版一致；结果“绕组”显示无单侧或端部不连续提示项，打印标明非合格判定。
- 任意一组宽/高填负数，例如高压油道宽2=-1，计算或方案弹窗确认应指出该组该侧并阻止；空白、文字仍按既有输入收集校验阻止，不能悄悄使用旧值。
- 将高压第5组宽设0、高保留正数：单侧停用值应保留，不被强制改成两侧0；若其他条件仍允许计算，结果应提示该组仅单侧启用。这里数值变化仍通过已有公式影响散热，不要求变化后结果保持不变。
- 两侧第2组设0、第3组保留正数：若其余输入仍能计算，结果应提示停用后仍启用的端部组号；输入不应被自动移位或清零。两侧从尾部逐组停用则不出现端部不连续提示。
- 打印及文本导出与结果布局提示状态一致。只改输入但不计算时旧提示不变，重新计算后更新。
- 方案库正常保存/导入保持油道0值和单侧布局；使用副本导入含负数、显式文字/null或错误数组结构的文件，应在替换当前方案表前拒绝。缺少油道字段的旧文件继续默认补齐，不是本批重建全部文件。

# 设计输入页：联结组别联动验收

2026-10-06，分支 `codex/design-connection-linkage`。本批只调整设计输入页，不扩大方案弹窗，不开放尚未核对的接法或形状算法。

## 程序改动位置

- `ParamTableWidget.cpp/.h`：主设计输入表的联结组别下拉；附近两行只读的高、低压额定相电压和相电流。切换下拉更新原参数单元格，沿用原来的标准列、匝数建议和参数收集链。实际匝数不被自动覆盖。
- `OptimizeCalcPage.cpp`：主页面初始化、方案回填、导入和表格刷新均开启上述主页面入口。其他表格调用默认不开启。
- `ElectromagneticEngine.cpp/.h`：新增基础电量预览入口，复用现有 `calcElectrical` 公式。未修改完整计算公式；预览不判断完整方案是否可算、是否合格。
- `EnterCalcPage.cpp` 与 `SchemeCalculationSheet.cpp` 相对本批基点 `cd890d2` 无变化，保留原弹窗布局和自动计算。

## 人工验收

关闭旧程序，从桌面 ZTBLD 快捷方式重新打开，进入**设计输入页**的输入信息表。

1. 联结组别应为下拉，可选 Dyn（Dyn11）、Yyn（Yyn0）、Dd、Yd；后两者明确标注暂不支持计算。参数名称及新增相电量不可编辑。
2. 产品型号 `SB20-M-630/10-0.4`，低压电压按回车提交后，Dyn 的高压相电压应为 10000 V、高压相电流约 21.00 A；Yyn 应为 5774 V、36.37 A。两者低压相电压约 231 V、相电流约 909.33 A。实际低压匝数等手工设计值保持原值。
3. 检查原损耗标准联动：该 630 kVA 型号两种接法的标准负载损耗均为 4960 W，因此切换时数值不变是正常现象。可用 `SB20-M-160/10-0.4` 检查两列差异：Dyn 为 1850 W，Yyn 为 1760 W。这些是项目已有标准表的值，不是本批新增标准。
4. 切换 Dd 或 Yd，四个相电量显示“不可用”，计算仍被拦截；切回受支持接法恢复有效显示。导入未知接法应保留原值并标注未支持，不默认为 Dyn。
5. 产品型号未填写完整、低压额定电压尚未按回车提交、频率不是 50 Hz，或实际低压匝数无效时，相电量不应沿用旧有效值。普通表格参数按原来的提交方式生效。
6. 刷新、导入、方案回填，以及普通/专业模式切换后，联结组别入口和相电量仍应正确；再打开方案弹窗，确认没有插入这些新行，原紧凑布局不变。

标准值自动匹配继续受原来的系列、容量、电压和人工标准来源规则约束；相电量能显示不代表全部输入已通过完整计算校验。标准、铁芯、铁轭、绕组和绝缘线的其余联动留待后续分批核对。

# 寻优最低成本方案性能裕量人工验收

分支 `codex/optimization-performance-margins`，基于已合并PR56的dev。只增加性能约束对照说明，不改变实际值计算、标准来源、允许偏差、筛选条件、成本目标、网格与细搜规则。

## 程序改动位置

计算主页 → 优化计算 → 寻优统计：新增“最低成本可行方案性能裕量（本轮冻结标准及允许偏差）”。

- 显示本轮后台返回的最低材料成本可行方案，而非当前点击或后来修改的方案。同成本仍取遍历先遇到的方案，不汇总全部并列方案。
- 空载损耗、负载损耗、总损耗、空载电流和三项温升：显示实际值、允许上限、剩余裕量。限值在现有约束校验处产生，不另维护一套显示公式。
- 损耗和空载电流上限=本轮标准值×(1+最大允许偏差/100)；温升限值仍直接采用本轮标准值。上限裕量=允许上限－实际值。
- 阻抗电压下/上限=本轮标准值×(1+相应最小/最大偏差/100)，分别显示实际值－下限、上限－实际值。
- 损耗及裕量单位W，温升及裕量单位K；电流与阻抗实际值、限值单位%，差值单位“个百分点”，不报告为相对改善百分比。
- 沿用现有启用规则，标准值≤0时明确“未校核”，不显示0裕量或默认限值。没有可行候选时不报告裕量。显示实际值/限值为非有限数、上限非正、区间下限为负或倒置时明确无法报告，不合成安全余量；这些报告保护不改变原筛选条件。
- 差值不截断、不按表格显示舍入再计算；正值有余量、0贴限、负值越限。正常已启用指标通过的候选不应有负裕量。
- 人工停止、低改善提前停止等情况，只解释已评估候选；不证明未评估区域或全局最优，不代表制造安全保证，不提供跨W/K/百分点的综合安全评分，不自动放宽标准。
- 统计保留上一批触边提示、价格快照与真实数量；改变订单标准、价格或搜索范围必须重新寻优，上一轮统计不会随当前设计修改而改变。

## 建议人工验收

1. 关闭旧程序，从桌面重新打开。完成一次寻优，打开统计，新区应显示上述8项指标，触边及价格说明仍保留。
2. 对照同一个最低成本方案和本轮冻结标准。例如空载损耗标准1000W、最大允许偏差10%时，显示允许上限1100W，余量=1100－实际损耗。仅为公式示例，不需把实际订单改成这个标准。
3. 核对总损耗实际值=空载+负载；温升限值不套用损耗偏差；空载电流差值写“个百分点”，不能误写相对百分比。
4. 核对阻抗范围和两端余量。例如标准4%、最小偏差−10%、最大偏差+10%，限值3.6%～4.4%；实际4%时两端各余0.4个百分点。仅为口径示例，以实际冻结订单为准。
5. 自定义标准将一项设置为0后重新寻优，该项应标未校核，而不是0裕量。若所有候选被现有约束剔除，应显示无可行方案、不报告裕量，不借用失败或默认0值。
6. 固定设计和搜索设置时，本批候选数量、物理结果与成本排序不应变化；多轮及人工停止后，裕量均应对应最终已评估最低成本候选。
7. 运行结束后点击其他方案、改设计或标准，旧统计仍保持本轮快照；只有重新寻优才更新。弹窗输入布局和即时重算保持原行为。

不创建或运行测试程序、自动测试、GUI自动化，不启动程序代验收。仅Release编译与独立只读静态审查。验收前仅本地提交，不上传或创建PR；独立预览、旧程序和旧快捷方式备份保留。

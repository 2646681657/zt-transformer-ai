# 高压温升分支批：改动与人工验收

## 程序层面

- `ElectromagneticEngine.cpp`：按原计算单恢复 AC47 的 >12kV 内表面项、AC51 的大间隙修正、AC52 的 AG43 计数及 Y53 的负修正排除。保留原表分段取整，不用合并后的公式代替。
- AG43 由高压额定电压自动联动（>12kV 为5mm，否则0），与既有 AK43 总宽共用一个来源。无需新增手填参数、保存字段或改写已有方案文件。
- `CalcResult.h`、`EmResultPanel.cpp`、打印输出：增加高压散热面积 AC47、第二油道 AG43、取整后等效间隙、AC49、AC51、原始 AC52 和对油温升 Y53。
- `ParamTableWidget.cpp`：主空道输入行注明电压联动规则。
- 仅处理当前开放的单段线圈。AC9=2 的有效高度分支未移植，两段线圈继续禁止；不推测其他铁芯形状算法，不改低压温升公式。

## 核对依据

原始文件 `SB20-M-630-10计算单.xlsm`，只读检查公式及缓存，不修改、执行宏或重算原表。

- AC47 内周长先取1位小数，再乘 >12kV 时的0.85，最终面积取2位。该内周长按原式只引用前三组低压端部油道；其他周长和散热油道继续用五组。
- 等效间隙 `ROUND(W25/(W12-1)+X14-X13,2)`；程序已有层间绝缘总厚与原 W25 对应。
- 令 n = AG43存在时的1 + 前三组高压端部油道各存在时的2 + 1。
- AC51：间隙≤0.64时原表为空、程序显示0；否则 `ROUND(0.002*(间隙-0.64)*(W12-n)*AB48,1)`。
- AC52：`ROUND(0.002*MIN(间隙,0.64)*(W12-2*n)*AB48,1)`；界面显示原始负值，不悄悄把其显示成0。
- Y53 = AC49 + AC51 + MAX(AC52,0)，Y54 = Y53 + N49。负 AC51 按原表仍参与，不擅自截断。

## 用户检验位置和项目

关闭旧程序后从桌面 ZTBLD 快捷方式重新打开。计算方案后在结果的“温升”页及打印输出查看以上中间值；输入页“六 主空道”有自动规则说明。

1. 10kV 原样本：AG43=0；AC51 若间隙≤0.64应显示0。用相同输入对照原表 AC47/AB48/AC49/AC52/Y53/Y54。原表缓存样本依次为11.47m²、225W/m²、5.0K、0.2K、5.2K、31.9K；仅是原表参考，不表示本程序已运行验证这些结果。
2. 将高压设为12kV及大于12kV（如20kV），重新计算：AG43 应分别为0及5mm；主空道总宽和温升面积应按联动变化。不要用其他输入不一致的缓存样本判断结果。
3. 在专业模式调整层间绝缘厚度或导线绝缘增厚，分别得到取整后间隙≤0.64和>0.64；前者AC51=0，后者按上述式核对。0.64本身仍属于无AC51分支。
4. 保持前三组高压端部油道开启，调整 W12 对应输入使 AC52 为负：应显示原始负值，但 Y53=AC49+AC51；不能因此降低 Y54。界面既有“高压每层匝数”名称沿用原项目，实际公式 W12 按层数使用，本批不改名。
5. 确认 Y54=Y53+油面温升 N49，打印与结果页一致；两段线圈和非椭圆截面仍被禁止进入计算。

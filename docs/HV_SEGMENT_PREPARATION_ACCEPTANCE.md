# 高压分段公式准备与人工验收

## 范围与限制

本批仅按原计算单补齐AC9=2公式分支，不宣布“两段圆筒式”已得到算法支持。计算单高压第二项名为“分段式”，结构对应关系及AC9=2参考算例尚未确认，界面与电磁引擎入口均继续阻止两段及其他高压型式计算。只允许AC9=1；不增加其他铁芯形状算法。

## 程序修改

- 选型按钮同步CalcInput.hvCoilFormIdx：圆筒式为1，两段为2（暂定对应原表第二分支，仅记录与传递）。保存字段沿用原方案格式。
- 输入页采用圆筒式旧方案时同步选型按钮；不支持型式的方案拒绝应用，保留当前输入，不静默降为1。计算页既有导入范围检查保留。
- 方案JSON仅缺失hvCoilFormIdx字段时沿用旧默认1；字段存在时仅接受数字1或2，其余（含1.5、字符串、null）保留为不支持标记0，不能截断或回退为单段。
- AA29段间距共用同一中间量：AC9=1为0；原表其他分支按额定高压>24kV取40mm，否则35mm。
- Q30恢复ABS(AC30-AJ14)+AA29，传递至Q32、P43与Q35。
- AC47高度因子恢复IF(AC9=2,AC30-AA29,AC30)，未额外减半或推测段数算法。
- 结果快照新增AC9、AA29、AA30、AC30、AA31、AC32参考下限、Q30与AC47有效高度。结果明细与共用设计结果表均由结果快照展示，不读取后来修改的输入。
- AA31=(AA33-AA30)/2；AC32在<=12、<=24、>24kV分别显示参考下限20、34、45mm，仅供人工核对，未接入合格判定或寻优筛选。原样例AA31=18.5mm而参考下限20mm，不据此宣称样例绝缘合格。
- AC9=1时AA29仍为0，Q30与AC47原有数值表达式不变。两段分支被入口拦截，其数值效果本批不能在程序界面验收。

## 人工验收

关闭旧程序，从桌面ZTBLD快捷方式重新打开。

1. 设计输入选“两段圆筒式”，点击进入计算及校验算单：均应提示型式对应与参考算例尚待核对，不能开始计算；切回多层圆筒式后正常计算条件恢复。反复切换不应重建整个参数表或抖动。
2. 在可算单段方案的结果明细“绕组”查看新增项：AC9为1、段间距AA29为0、AA30等于原高压轴向高AA28，AC30为AA30减去绝缘线厚Z14乘并绕根数。
3. AA31应等于(低压箔宽+2×低压端绝缘-AA30)/2。原默认参数对应的18.5mm与20mm下限仅作原表参考，不显示为合格结论。
4. “阻抗电压”新增Q30，单段等于ABS(AC30-低压箔宽)；“温升”新增有效散热高度，单段等于AC30。设计结果表中同名项目应与明细一致。
5. 对比同输入的上一版单段方案，既有阻抗、温升与损耗结果应保持。修改输入再切回旧结果时，新增项仍应来自旧结果快照。
6. 当前选两段时采用圆筒式旧方案，按钮应回显多层圆筒式。导入或采用hvCoilFormIdx不为1的方案应被拒绝，不能悄悄按单段计算。
7. 如手工核对JSON导入边界，请复制原方案再修改副本：字段为1.5、字符串"1"、null或未知值时应拒绝；仅缺失该字段的旧方案仍默认单段。不要覆盖原方案。

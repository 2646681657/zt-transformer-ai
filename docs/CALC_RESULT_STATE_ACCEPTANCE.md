# 计算失败后的成功结果保护

2026-10-06，分支 `codex/calc-result-state`，基点 `049a33e`。

## 原因与程序位置

`EnterCalcPage.cpp::runEmCalcInput` 原先在引擎成功前清除已确认方案索引、替换 `m_lastInput`，并将计算写入成员 `m_emResult`。引擎一进入就清空结果，失败返回后旧界面和打印表未刷新，但其输入/结果成员已被替换；报价、返回上次方案与输出可能读取不一致数据。

本批只改该入口：计算先写入局部 `CalcResult`，成功后一起提交确认索引、上次输入、当前输入、指标、结果和有效标记，再刷新结果、打印与方案表。输入校验、支持范围和引擎失败均只更新提示，保留之前完整成功结果；没有成功结果时明确说明未生成结果。范围检查使用本次已收集的指标参数。

引擎公式、标准来源机制、方案计算单弹窗布局、确认/取消和自动重算均不改。保留成功结果不表示失败候选可计算或合格，失败候选不追加到方案表。

## 人工验收

关闭旧程序，从桌面快捷方式打开新版。

1. 准备失败候选B：在设计输入页使用默认有效型号与支持配置，将实际低压匝数设为1，保存为一个独立的验收草稿，不覆盖正式方案。该值是故意不合理的验收输入，不是设计建议。若输入校验已拦截该组合，不要强行修改文件；也可使用已有能通过输入校验但触发硅钢曲线越界的候选。
2. 恢复原实际匝数和有效设计A，进入计算页，成功计算并确认A。记录型号、实际匝数、损耗、材料合计及打印表关键值。
3. 在**计算页侧栏的方案库**选择失败候选B，触发快速重算失败。须出现原因，并提示“本次未更新；仍保留上一次成功方案”。结果、已确认方案、方案表、打印数据应保持A，不能混入B；失败候选不追加为成功方案。
4. 检查计算单、成本明细、报价/文档导出仍使用A；“返回上一次方案”应回到A而非失败候选。导出操作可按需人工进行，不要求覆盖正式文件。
5. 再选择另一个可成功计算的候选C，成功后所有输出应更新为C，不能一直锁在A。
6. 未有成功结果时触发失败，应说明没有成功结果，不将默认或失败中间值显示成有效结果。旧方案指标来源缺失等输入校验失败同样应保留已有成功结果并说明此次未更新。

# 方案计算单四项下拉验收（2026-10-15）

分支：`codex/sheet-selection-dropdowns`。仅补齐方案选择弹窗选型入口，不扩展接法、心柱或铁轭算法。上一批内排参考已验收并经PR70合并。

## 程序位置

桌面ZTBLD → 方案选择 → 选择，主表原单坐标：

| 行 | 单元格 | 参数 | 选择与支持范围 |
|---|---|---|---|
| 3 | C3 | 联结组别 | Dyn/Dyn11、Yyn/Yyn0可计算；Dd、Yd标注暂不支持并阻止计算/确认 |
| 3 | F3 | 标准/指标来源 | 复用内置标准（损耗表）、非标（手工指标）、来源待确认；内置损耗表不是完整国标认证 |
| 4 | F4 | 心柱 | 圆形、长圆形、椭圆形；仅椭圆形可计算 |
| 5 | F5 | 铁轭 | 同心柱、T形轭；仅T形轭可计算 |

原工作簿下拉控件来源为“线圈型式”Q10:Q13、T2:T3、M9:M11、M2:M3。主表不扩展右侧图形区域、不插入主设计页预览行；只刷新值和状态，不因切换重建表格。

## 实现边界

- ParamTableWidget增加默认关闭的sheetSelectionUi参数，仅为弹窗启用既有联结组别及指标来源控件；主设计页和其他调用行为保持不变。
- 标准与联结组别继续使用同一个隐藏参数表作为数据源。标准的切回确认、取消恢复、非标不覆盖、手工修改转非标、指标快照保存均复用现有逻辑。
- 心柱、铁轭在本弹窗仅允许当前已支持的椭圆形/T形轭通过。未支持选型停留供查看，inputsReady在自动计算与确认入口共同拒绝，旧结果明确标注仅供查看，不伪装成新选型计算结果。
- 不新增结构持久化枚举，不将未支持选型保存为有效方案；不改变电磁公式、温升、成本、寻优或主设计输入布局。

## 人工验收点

1. 查看第3行两项、第4行心柱、第5行铁轭是否均为下拉；参数名称不可编辑。
2. Dyn与Yyn切换，原高低压相电量和损耗表按现有规则联动。630kVA两列负载损耗相同属正常，可用160kVA观察不同值；不要求每个结果都变化。
3. 切换Dd、Yd、圆形、长圆形、同心柱，自动计算状态应明确未支持；点确认不能保存，切回受支持项后恢复计算。旧数值不得被解释为所选未支持结构的新结果。
4. 切到非标后修改指标，再改规格/接法不自动覆盖手工指标；切回内置时取消应恢复原模式和值，确认才替换三项损耗。其他指标仍为手工，不代表完整国标认证。
5. 确认后重新打开方案，联结组别及标准模式应保留；取消修改不写回。心柱/铁轭仅能以椭圆形/T形轭确认。
6. 连续切换和折叠底部两区，检查不抖动、不重建、不丢失其他输入。原有内排参考和历史记录仍正常。

按用户要求仅Release编译、静态审查、差异检查和桌面文件核验，不新增或运行测试程序、GUI自动化。待人工验收通过再提交PR。

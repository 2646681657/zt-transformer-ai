# 铜、铝、油、油箱自定义寻优基价人工验收

本地分支 `codex/material-base-pricing`，基于已合并PR54的dev。补齐其他材料的寻优定价，硅钢按牌号定价继续独立设置；不改变电磁公式、曲线、约束、搜索维度和方案弹窗输入布局。

## 程序改动位置

- 计算主页 → 优化计算 → 循环参数设置：新增“自定义铜/铝/油/油箱基价”开关和“其他材料基价…”窗口。
- 默认关闭，仍用原计算单基价：铜60、铝60、油10、油箱钢材9元/kg。窗口首次预填这些原基价，明确不是当前市场价格。启用后四项都须填写有限正数，不超过99999元/kg，即使本轮没有铝导线也要填写铝基价，为后来切换材料保留完整口径。
- 无效输入在价格窗口确认及外层保存/启动时拦截，不自动套用内置或报价页价格。取消内层不改本次设置，取消外层不持久化。关闭开关保留填写值，但新一轮候选恢复原基价。
- 每轮冻结输入基价；每个候选保存模式和四项有效价格。方案表成本提示、统计、明细、结果和打印显示该方案采用口径。修改设置只影响新一轮，不重新定价旧候选。
- 方案保存载入及弹窗自动重算继续用候选价格；旧文件没有材料基价对象时用60/60/10/9，显式自定义对象缺少价格或模式无效时拒绝重算，不静默迁移。内置模式始终固定原四项基价，不使用闲置自定义字段。
- 报价页仍按其自身价格独立重算，不自动同步任一方向。不计费用、利润和税额，不宣称采购全成本或全局最优。

## 保留的计算单成本规则

输入铜、铝基价，不是成品导线价格。设铜基价C、铝基价A：高压铜线单价=C+3.3，高压铝圆线=A+6，铝扁线=A+8.5；低压铜箔单价=C×1.05+6.5，低压铝箔=A+6。原计价重量（硅钢×1.05、高压导线×1.05、低压箔×1.08、油×1.1、油箱×1.05后加200）和舍入不变，铜箔的1.05基价系数也保留，不等同于只乘基价。

仅价格改变、牌号和物理输入一致时，重量、磁密、损耗、阻抗和温升不应变化。成本变化可能影响排序、细搜中心及后续评估区域，因此比较物理结果时请固定搜索变量或对照相同输入，不要求两次寻优最优方案物理参数一致。

## 建议人工验收

1. 关闭旧程序，从桌面重新打开。关闭新开关，保持原输入和搜索设置，结果应与上一批一致。开关与硅钢定价独立，四种内置/自定义组合均可设置。
2. 打开价格窗口，核对60/60/10/9及说明；清空任一项，或填0、负数、文字、超过99999，确认应提示该项无效。修正后可保存，取消不改变之前保存的数值。
3. 固定全部搜索变量，启用自定义并保留60/60/10/9，金额应与内置一致。只把铜改70（人工验收示例，非市场报价），相同铜线/铜箔设计的成本变，高低压计价仍含加工加价；物理参数不变。铝导线设计可对应只改铝基价检查。
4. 分别只改油或油箱单价，对照成本明细，仅相应材料金额及总额变化；硅钢价格不受新开关影响，始终按上一批选择的硅钢模式计价。
5. 查看统计冻结价格、成本单元格提示、成本明细和打印中的价格，与本轮设置一致。不同价格批次同时出现在方案库时，对比显示各自口径，不把价差当纯设计改善。
6. 保存自定义候选再载入，检查成本和单价不变；在弹窗改尺寸触发重算，仍用候选价格。改循环参数后已有候选不重新定价；切回内置，新候选恢复原四项基价，旧自定义候选保留旧价格。
7. 重开循环参数检查开关和价格持久化，取消内层/外层不保存新输入。报价页调价不影响已有候选，也不自动跟随本批寻优价。

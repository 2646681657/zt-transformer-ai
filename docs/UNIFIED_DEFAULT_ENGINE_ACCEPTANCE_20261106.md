企业要求所有设计共用默认计算单对应的引擎规则。三份计算单之间存在的公式差异不再通过单独模式或调参来复现；保留差异记录，不推断原单必然错误。

## 实现范围

- 片宽偏移、片数补偿、中心距附加、层绝缘系数、匝数/轴向附加、油道层序、阻抗、重量、温升、油箱等18类入口移除。默认公式原有片宽偏移及补片+2/-1保持固定。
- 原辅助片数设计截面、手工单位铁损、三档油道/温升、阻抗除Kx等替代公式分支移除。
- 原始设计尺寸、材料、匝数、油道尺寸、绝缘、接缝数、轭阶梯20级、杂散/工艺系数、材料价格等正常输入保留。
- 历史JSON中的21个废弃键（包括数组和手工铁损字段）不再导入或保存，即使值损坏也不影响新规则。内置第一/第三组预置只保留实际输入。
- 默认计算明细版本12；学习引擎版本sb20-default-sheet12-learning-v1。旧模型须重新准备数据、训练和审核，不可沿用旧公式版本审核。
- 导出Excel取消复核系数引用，统一默认模板公式；此前已导出的文件不会自动改变，需重新导出。

# 硅钢曲线磁密范围保护：人工验收

## 程序改动

- 设计输入“四 铁芯参数”在牌号行下增加曲线磁密上下限，均只读，切换牌号自动更新。共享表覆盖一般/专业模式及方案参数弹窗。
- 范围来自内置design_data.json，各牌号独立；不是材料保证值或最新版标准认证。本批不修改原曲线数据。
- DesignDatabase的两个线性插值接口拒绝超范围、非正、非有限磁密。端点包含在有效范围内，范围内原两点内插公式不变。
- 引擎分别检查实际送入心柱单位铁损I26、铁轭单位铁损O26、磁化容量J16的磁密，沿用原取整规则。错误列出查表项目、牌号、磁密及允许范围，不用端点替代；缺失磁化容量也明确失败，不按0继续计算。
- 寻优沿用既有计算成功且约束通过才接收候选的逻辑，越界失败点不会进入方案列表或最优解。不增加其他铁芯形状算法。
- 本批从已验收的PR29本地提交继续，预览仍包含油顶层限值功能。方案文件不增加字段。

## 请人工检查

1. 关闭旧程序，从桌面快捷方式启动。默认18SQGD065显示0.4~1.92T，切换30Q120显示1.35~1.8T。上下限及参数名称不能手工编辑。一般/专业模式及方案参数弹窗显示一致。
2. 保持原已验证且查表磁密在范围内的输入重新计算，与上一版比较空载损耗、空载电流、阻抗、温升等；应不因本批改变。恢复默认牌号再做其他检查。
3. 在可行几何与绕组组合下减少实际低压匝数，提高匝电压和磁密（默认18匝，可尝试14或更低）；应出现带项目、牌号、实际磁密及范围的越界报错，不能产生成功的新计算结果。具体触发点以计算后的实际查表磁密为准。
4. 反向增加匝数，可尝试远大于18匝（如100）检验低于下限的情况；如果先触发其他几何/绕组错误，那不是曲线下限验收成功，应调整为可行组合再观察。
5. 使用跨越数据范围的寻优设置，核对越界点不会被作为有效候选。范围外候选被排除后有效方案数量可能减少或没有可用方案，这是本批预期影响；其他约束仍然同时生效。
6. 修改牌号后在方案弹窗计算/确认，同样应受范围保护；导入旧方案重新计算也不豁免越界检查。查表实际心柱磁密与界面显示的设计磁密并非同一值，不能仅按设计磁密判定错误。

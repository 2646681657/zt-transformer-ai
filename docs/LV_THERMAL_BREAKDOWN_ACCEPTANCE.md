# 低压温升过程显示：人工验收

## 程序改动

- CalcResult 的温升结果增加低压散热面积 AK47、表面温升 AK49、原始层间修正 AK50、对油温升 AK51 四个计算快照字段。引擎直接保存原来已计算且已校验的中间值，不另算一遍，不改变公式、取整或合格限值。
- 结果页“温升”和文本导出显示上述四项；低压热负荷标注 AK48，显示两位小数及 W/m²。低压总绕组温升标注 AK52。
- 打印输出补充同样的低压链路，包括已有的低压绕组温升 AK52。面积两位小数、热负荷两位、温升和原始修正一位，三个出口一致。
- AK50 原始负值仍显示，但不计入对油温升，保持原有 `AK51 = AK49 + max(AK50, 0)`；`AK52 = AK51 + N49`，叠加的是油面温升而非油顶层温升。
- 新项是只读结果快照：改输入后需要重新计算才更新。方案库仍仅保存输入，重新导入按引擎重算，不改变文件结构。
- 不修改低压附加损耗的现有作用或计算单中 AS45/AJ45 待确认口径，不扩展其他形状、圆线或两段线圈算法。

## 请检验的位置

1. 关闭旧程序，从桌面重启。用上批正常方案计算，结果“温升”应新增 AK47、AK49、AK50、AK51；AK48 有 W/m² 单位且保留两位小数。最终高低压温升、损耗、阻抗及成本应与上一版一致。
2. 同一结果的文本导出和打印表应有同样的低压中间项，数值、精度、单位一致。AK50 可为负，不能自动显示为0。
3. 查看 AK51 是否等于 AK49 加非负 AK50；当 AK50 为负时，AK51 应等于 AK49。AK52 应等于 AK51 加油面温升 N49，不是加油顶层温升 N51。本批不新增输入来强制生成负修正方案，可用之前人工确认的有效方案。
4. 在输入副本中修改低压油道、箔宽或层间绝缘，重新计算后新增结果应按既有算法更新；只修改输入但不计算，显示保持上次结果，不应混用新输入。之前零低压面积的异常组合仍应被拒绝。
5. 保存正常方案再导入、打开方案参数弹窗重新计算，新增中间项应一致，旧文件无需迁移。若修改后的组合被既有几何、磁密、损耗或温升规则拒绝，不代表本批新增限制。

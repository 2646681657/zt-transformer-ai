# N50高度比独立参考验收（2026-10-15）

六处平均宽长说明已验收并经PR66合并。本批分支 `codex/sheet-height-ratio-reference`，按用户确认补齐N50/E50；用户于2026-10-15确认本批人工验收通过。

## 改动与边界

方案选择 → 选择 → 方案计算单，原50行N50显示高度比，E50展开当前操作数并明确标“参考”。对当前支持的椭圆形、波纹油箱，采用原表公式：

`ROUND((J23 + G17 + J14/2) / (Q26 + S23/2), 2)`

- J23：当前箱底油空输入。
- G17：本次首级铁芯片宽快照，不是Sheet1实际截面。
- J14：本次窗高快照。
- Q26：本次箱顶油空（J27箱高−S23波纹高−Q22箱沿高），不是底部距离。
- S23：当前波纹高。

N50为无量纲只读参考，按Excel ROUND语义保留两位小数。它在有效计算完成后的明细采集阶段单独计算，只写入显示映射；不反馈现有温升公式，不改变方案有效状态/错误，不增加合格约束，不参与寻优筛选、排序或目标。默认寻优入口不采集此值。同一有效输入下，原有温升、阻抗、损耗、成本等数值不应因本批改变。

缺少首级片宽/Q26快照、分子分母非有限、分母≤0或结果溢出时，N50显示“不可用”，悬停解释原因。不填0，不沿用旧快照，也不单因参考不可用而把整机判失败。现有主算法自身的校验仍照常执行，不为展示错误分支而放宽校验。

明细版本由6升至7，旧方案弹窗打开自动重算；N50固定预留绑定，自动刷新不重建表格。未来其他芯柱/油箱形状需独立算法支持，本批不推断其高度比。

## 桌面检查

关闭旧程序，从桌面ZTBLD启动，进入方案选择并点击“选择”。

1. 左侧50行：N50不再显示“—”，应有两位小数结果；E50显示本方案操作数且明确“参考”。悬停可见Q26为箱顶油空，以及不参与温升/寻优的说明。
2. 按上述公式，用当前J23、G17、J14、Q26、S23核对结果。不要用原Excel示例的0.71作为所有方案的固定期望值。
3. 在现有允许范围内修改箱底油空、铁芯直径或波纹高，核对E50与N50联动更新。改波纹高也会联动Q26，不要求比值单调增加或每次都变化。
4. 打开旧方案应自动补算；确认保存、取消不保存、连续编辑、折叠区保持正常。
5. 不为本批引入新的温升或寻优结果变化；其他参数本身引起的变化仍是原算法正常联动。

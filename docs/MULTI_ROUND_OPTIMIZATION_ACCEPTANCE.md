# 多轮细化与停止条件人工验收

分支 `codex/multi-round-optimization`，基于已合并PR51的dev。用户已批准：保留单轮及一轮细搜，新增默认最多细搜3轮、逐轮减半、从已评估可行方案重新选3个最低成本中心、跨轮去重，连续两轮改善不足0.01%或无新增组合时停止。

## 程序改动位置

- 计算主页 → 优化计算 → 循环参数设置：新增“粗搜＋多轮细化”，最大细搜轮数1～5、首次默认3；仅多轮模式可编辑，不含粗搜。模式与轮数持久保存，取消不保存。
- 循环参数预算：粗搜确切数量+各轮最多3个中心的邻域保守总量。尚未扣除边界/重复/提前停止；超过100000拦截，减少轮数、范围或参与变量后重试。
- 运行进度：标明粗搜或细搜第N/最大轮数轮，百分比为当前阶段，不是总体百分比。
- 寻优统计：粗搜、每个已生成的细搜轮及细搜合计，列出实际调用、候选、失败、约束/线型淘汰、未处理、中心数、提议与重复数、轮前/轮后最低成本、改善比例及停止原因。合计行不是额外一轮。
- 参数值精度：铁芯直径、直线段、低压箔厚/宽从默认6位提高到15位有效数字，避免细化小数在查看候选时被明显截断；高压扁线原已使用15位。方案弹窗布局及计算公式不改。

## 运行规则

先完成原粗搜。细搜第1、2、3轮的连续尺寸步长分别为原步长的1/2、1/4、1/8；例如0.05 mm变为0.025、0.0125、0.00625 mm。以本次最细网格的整数坐标统一跨轮去重，先生成整轮唯一新增计划，再完整计算。各轮始终裁剪到原始上下界，固定或范围0的量不变；低压匝数/高压层数仍整数1档，圆线仍是冻结清单内相邻1档。

每轮开始前从所有已评估可行候选中选材料成本最低的3个中心（不足3个取实际数）；失败或不满足冻结约束的候选不能当中心。每轮产生的可行候选参与下一轮中心选择；已有最佳方案保留，成本不因新增候选而上升。两轮间无额外独立报价或价格来源变化。

多轮模式：仅完整处理且有新增组合的细搜轮，按未舍入成本计算 `(轮前最佳-轮后最佳)/轮前最佳×100%`。连续2轮严格小于0.01%时提前停止；达到或超过0.01%会重置连续低改善计数。最低成本为0时改善记0。无新增组合、达到最大轮数、粗搜无可行中心或人工停止另列原因，不混称全局收敛。未完成轮不用于低改善判定；人工停止仍只保留已处理候选，未生成的未来轮不计入计划。

保留单轮模式原网格、一轮细搜原半步行为。一轮模式不使用多轮低改善停止规则。所有模式原订单、标准、材质、线型、性能校核保护不变；不放宽约束、不补表外圆线，不推测其他形状。仍是有界局部搜索，不宣称全局最优或全部制造校核通过。

## 建议人工验收

1. 关闭旧程序，从桌面快捷方式重新打开。循环参数看到三种模式，单轮/一轮模式下最大细搜轮数控件禁用，多轮下启用，默认3。
2. 多轮设1轮，与原一轮模式采用相同输入、范围和标准比较：粗搜、细搜实际数量及已评估最佳成本应相同。单轮仍只遍历原网格。
3. 仅开启低压箔厚，±1步、步长0.05，其他变量固定：首轮粗搜3组合；若均可行则第1轮新增2个半步中点。允许后续轮产生更细小数，但受中心与约束影响不保证每轮都有候选。统计步长应依次0.025、0.0125、0.00625，尺寸不超过原上下界。
4. 在方案计算单查看铁芯/箔尺寸，细化小数不被旧6位显示精度截断，候选表材料合计最低值与统计最终最低值一致（价格显示有舍入）。逐轮最低成本不应上升，改善允许0。
5. 将最大轮数设5，观察停止原因：达到轮数、连续两轮低改善或没有新组合之一。不能把无改善第一轮直接当成“两轮低改善”；人工中止也不能被标为收敛。
6. 仅匝数/层数或表内圆线参与时，细搜可能无新组合并停止；不得出现小数匝数、层数或表外圆线直径。全部固定时仅粗搜1组合。严苛订单使粗搜无可行方案时，不进入细搜、不自动改标准。
7. 大范围暂停/继续/停止，核对每轮计划=已处理+未处理，引擎调用=可行+失败+约束淘汰，已处理=调用+线型预检。总量=粗搜+逐轮相加；细搜原始提议=重复跳过+唯一新增计划。跨轮不出现相同搜索输入重复入库。
8. 保存多轮及轮数，重开保留；改回原模式仍可运行。预算超限明确拦截；旧程序和快捷方式备份保留。

不新增或运行自动测试、测试程序及GUI自动化，不启动程序代验收。仅Release编译及独立静态审查；本地提交并部署独立预览，等用户验收后再上传和PR。

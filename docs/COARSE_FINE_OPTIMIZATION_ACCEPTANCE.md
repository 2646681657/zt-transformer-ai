# 粗搜＋一轮细搜人工验收

分支 `codex/coarse-fine-optimization`，基于已合并 PR50 的 dev。本批不改电磁引擎公式、主设计输入和方案计算单弹窗布局。

## 程序改动位置

- 计算主页 → 优化计算 → 循环参数设置：新增模式下拉，默认仍为“单轮网格（原模式）”，可选“粗搜＋一轮细搜”。模式保存后重开程序保留，取消不保存。
- 循环参数：显示首轮确切计划和两轮保守预算；预算尚未扣除重叠及边界裁剪，总预算超过100000时拦截，不静默截断。
- 开始运行计算：首轮仍遍历原网格；完成后取最低材料成本的3个可行方案（不足3个取实际数量），生成一轮细搜。进度标明粗搜或细搜，百分比为当前阶段，不是两轮总百分比。
- 寻优统计：分轮显示计划、已处理、实际引擎调用、可行、失败、约束剔除、线型预检、未处理和耗时；列出细搜中心、原始邻域提议、重复跳过和唯一新增计划，以及粗搜最低成本与最终改善。

## 规则及边界

连续尺寸（铁芯直径、直线段、低压箔厚/宽、高压扁线宽/厚）细搜步长为原步长一半，中心左右各1档。例如原0.05 mm细化为0.025 mm。低压匝数、高压总层数仍为整数1档；圆线只取本轮冻结清单内相邻1档，不插值、不取表外规格。邻域均裁剪到原始上下界；关闭参与或范围为0的量保持固定。

两轮和三个中心之间按同一整数坐标去重，包括粗搜计算失败或预检剔除的点；不重复调用引擎或入库。同一中心组合的订单、联结、标准、原材质等沿用冻结基准；所有新增组合调用完整现有引擎和原约束。扁线宽=厚预检保护、圆线精确查表保护不变。

粗搜无可行方案时不进入细搜、不放宽标准。仅整数/圆线参与或全部固定时，邻域可能全部是粗搜已处理点，此时说明“无新增组合”。停止粗搜时不生成细搜；停止细搜时保留已处理候选，最佳成本只代表已处理范围。细搜不替换更低成本的粗搜最佳方案。

本批是一轮局部细化，不是完整多轮迭代或全局最优证明。不保证一定改善，也不人为延长寻优时间；显示尺寸、价格可能有舍入，原始计算使用半步精度。非库存尺寸仍须人工核对制造可用性。

## 建议验收

1. 关闭旧程序，从桌面快捷方式重开。在循环参数中看到两种模式。先选单轮，确认原范围组合数、现有方案查看及打印链路不变。
2. 选两轮，固定其他变量，仅打开低压箔厚，步长0.05、±1步。粗搜应为3组合；若3个均可行，细搜新增计划应为2组合，即两侧半步中点（例如基准1.35时为1.325、1.375），不越过1.30～1.40。若可行中心不足3个，新增数量可能减少。被约束淘汰的中点不会入库。
3. 使用原四变量或同时启用箔尺寸，运行两轮。统计最终已评估最低成本不应高于同轮粗搜最低成本；改善可为0。方案列表不应出现同一个搜索输入重复入库，固定参数及订单指标不变。
4. 仅开启低压匝数/层数，或者有效圆线规格±1档：细搜不插入小数匝数、层数或表外直径。只有这些离散变量时，细搜无新增组合并说明原因。全部变量固定时只处理1组合。
5. 使用严格订单约束使粗搜没有可行方案，确认细搜调用0、无中心且明确说明未进入细搜，订单标准不自动修改；验收后恢复自己的订单标准。
6. 范围较大时人工暂停/继续/停止。进度阶段明确，已处理数量实际统计；实际引擎调用=可行+失败+约束剔除，已处理=调用+线型预检，计划=已处理+未处理。两轮总量=对应分轮相加；细搜原始提议=重复跳过+唯一新增计划。
7. 保存两轮模式，重开检查保留；改回单轮后只运行原网格。超过保守预算的配置应拦截，不能少算却声称全部完成。

不新增或运行测试程序，不做GUI自动化，不启动程序代验收；使用Release编译和独立静态审查。验收前仅本地提交，不上传或创建PR。
